관리자 설정

키오스크와 관리자 서류 화면에서 쓰는 관리자 비밀번호를 변경하고, 필요할 때 Notion 웹훅 키를 교체합니다.

인증 서버 연결을 확인하고 있어요.비밀번호를 바꿔도 Notion 버튼·자동화의 웹훅 키는 바뀌지 않습니다.

서버 연결 확인 중

인증 서버의 설정 상태를 확인하고 있어요.

처음 설치한 학원은 초기 비밀번호 0000으로 로그인한 뒤 바로 변경합니다. 비밀번호는 브라우저에 저장하지 않으며, 로그인은 12시간 후 만료됩니다.

앞뒤 공백 없이 8~128자. 초기 비밀번호 0000은 사용할 수 없습니다.

변경하면 키오스크·관리자 서류 화면의 로그인이 모두 해제되고 새 비밀번호로 다시 로그인합니다. Notion 웹훅 키는 그대로 유지됩니다.
  1. 새 웹훅 키를 만들면 한 번만 화면에 표시됩니다.
  2. 교체 기간에는 옛 키와 새 키가 모두 동작합니다. Notion 버튼·자동화의 키를 하나씩 바꿉니다.
  3. 옛 키로 들어오는 호출이 없어지면 교체를 완료합니다. 그때부터 옛 키는 거부됩니다.

유출이 의심될 때만 교체하세요. 관리자 비밀번호와 키오스크 로그인은 바뀌지 않습니다.

이 화면을 벗어나면 키를 다시 볼 수 없습니다.안전한 곳에 복사한 뒤, Notion 버튼·자동화의 x-admin-key 헤더(또는 본문 adminKey)를 이 값으로 바꿔 주세요. 채팅·문서·스크린샷에 남기지 마세요. 복사하기 전에 키를 잃었다면 교체를 취소하고 다시 시작하세요.
교체 방법 (공통) · 어디에 붙여 넣나요?

버튼

  1. 아래 DB 카드의 웹훅등록 보기 열기를 누릅니다. 그 DB의 버튼만 모아 둔 보기가 열립니다.
  2. 바꿀 버튼 열의 머리글(열 이름)을 클릭하고 자동화 편집을 누릅니다.
  3. 작업 웹훅 보내기에서 키 x-admin-key 옆 값 칸을 새 키로 바꾸고 저장합니다.
  4. 이 화면에서 그 항목을 체크합니다. 같은 DB의 다음 버튼으로 이어서 진행합니다.

자동화

  1. 카드의 DB 열기로 DB를 열고 오른쪽 위 번개 모양(자동화) 아이콘을 누릅니다.
  2. 목록에서 해당 자동화(예: 클래스 연결, 링크 비활성화)를 엽니다. 체크됨/체크 해제됨처럼 조건이 다른 자동화는 각각 따로 바꿉니다.
  3. 버튼과 같은 방법으로 웹훅 보내기 → 값 칸을 새 키로 바꾸고 저장합니다.
  4. 이 화면에서 체크합니다.
버튼을 눌러서 확인하지 않아도 됩니다.Notion은 버튼·자동화 설정을 외부에서 읽을 수 없어서, 바꿨는지는 직접 체크해야 합니다. 버튼을 누르면 실제 작업(보고서·알림톡 발송, 삭제, 종료 처리 등)이 실행되니 확인용으로 누르지 마세요. 평소 업무로 호출되면 각 항목 옆에 새 키 호출 확인 또는 옛 키 호출 있음이 자동으로 표시됩니다.

출석 수동 동기화를 쓰면 GitHub Secret ADMIN_SECRET도 새 키로 바꿔야 합니다.

교체 취소

새 키를 버리고 옛 키만 다시 사용합니다. 이미 새 키로 바꾼 버튼은 다시 옛 키로 돌려야 합니다.
