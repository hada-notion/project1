# v2.5.18 — 디자인 기준 재정비 (웹앱 디자인 규칙 기준)

- 날짜: 2026-10-12
- 이전 버전: v2.5.17
- 요약: 디자인 기준을 원래의 "웹앱 디자인 규칙"(학부모 리포트가 기준 화면)으로 다시 세웠다. 관리자 설정·출결 키오스크·학교 검색·법정 서류가 리포트와 같은 모양을 쓴다: 옅은 회색 캔버스(#F7F8FA), 테두리 없는 흰 카드와 옅은 그림자, 베이지 보조 버튼, 리포트식 전환 탭, 기기 기본 글꼴. 키오스크가 화면 크기에 맞춰 커지고 작아지는 기능을 고쳤다. 학부모 리포트는 바꾸지 않았다.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면(GitHub Pages)·문서. Supabase 함수·마이그레이션·Secrets·Notion 변경 없음.

## 항목 1. 디자인 기준과 공용 파일

- **유형**: AI 자동
- **선행 조건**: 운영 소유자의 전체 계획 승인. v2.5.17 적용.
- **대상 파일**
  - `docs/DESIGN.md`: 1부 "웹앱 디자인 규칙"(원래 기준, 그대로) + 2부 "관리 화면 공용 토큰·부품"(1부를 관리 화면에 적용하는 규칙).
  - 신규 `assets/hada-tokens.css`: 값(토큰)만 모은 파일. 색은 1부 색상표, 모서리·그림자는 리포트 실제 값.
  - 수정 `assets/hada-ui.css`: 토큰 파일을 불러오고, 카드·보조 버튼·전환 탭·스크롤바 규칙을 리포트 기준으로 맞춘다.
  - 수정 `attendance_kiosk.html`, `legal_documents.html`: 화면 전용 값을 새 기준에 맞춘다.
  - 수정 `tests/design-lint.cjs`: 토큰 파일 검사.
- **변경 내용 (보이는 것)**
  - 페이지 바탕: 베이지 → 옅은 회색(#F7F8FA). 카드: 흰 표면, 테두리 없음, 리포트와 같은 그림자, 모서리 14px.
  - 보조 버튼(하원·인쇄·Excel·로그아웃 등): 베이지(#F5EFE7) 바탕 + 진한 갈색 글자.
  - 법정 서류의 서류 종류 탭: 리포트의 전환 탭처럼 베이지 트랙 안에서 선택한 칸만 흰색.
  - 글꼴: Pretendard 지정 제거, 리포트와 같은 기기 기본 글꼴.
  - 키오스크: 카드가 화면 크기에 맞춰 함께 커지고 작아진다. 예전 식은 브라우저가 무시해서 항상 같은 크기였고, 짧은 가로 화면에서 위아래가 잘렸다. 로그아웃 아이콘은 44px 클릭 영역 안의 20px 아이콘.
- **환경별 값 (중요)**: `attendance_kiosk.html`·`legal_documents.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값을 유지**한다(이번에 바꾼 곳은 `<style>`뿐). 원본 파일을 가져온 뒤 운영 값으로 되돌리거나 `scripts/setup-new-academy.py`의 치환을 다시 적용하고 원문 비교로 확인한다.
- **검증**:
  1. `node tests/design-lint.cjs` 통과.
  2. Pages 반영 후 관리자 설정·학교 검색·법정 서류·키오스크를 PC와 휴대폰에서 열어 본다. 키오스크는 실제 태블릿에서 카드가 화면에 맞게 보이는지 확인한다.
- **실패 시 대처**: 이전 버전의 `assets/hada-ui.css`·화면 파일로 되돌린다. 서버·데이터 영향 없음.
