# v2.6.1 — Notion 사전 작업 (배포 전)

- 날짜: 2026-10-14
- 이전 버전: v2.5.11
- 요약: v2.6 코드가 쓰는 Notion 속성을 먼저 만들고, 이름을 맞추고, 지운 함수를 부르는 자동화를 정리한다. v2.5.11 코드는 이 속성들을 읽지 않으므로 지금 동작은 바뀌지 않는다.
- 매뉴얼 영향: 없음(매뉴얼은 v2.6.4)
- 변경 유형: Notion 스키마·수식·자동화. 코드·Supabase·Secrets 변경 없음.
- 전체 흐름·달라지는 것: [v2.6 개요](v2.6.md). Notion 작업 원문: [v2.6-노션-작업.md](v2.6-노션-작업.md)

---

## 항목 1. 스냅샷

- **유형**: AI 자동
- **선행 조건**: 운영 소유자가 v2.6 전체 계획(v2.6.1~v2.6.5)을 한 번 승인
- **무엇을**: 수업(학원)·출석(학원)·학습기록(학원)·등록(학원) DB의 속성 목록(이름·타입)과 수업 DB `생성 오류`, 학습기록 DB `단원` 수식 원문(읽을 수 있으면)을 운영 시스템 정보 이력에 남긴다. 받은 원본 커밋 전체 해시(원본 `main` 최신)도 적는다.
- **검증**: 시스템 정보에 "v2.6.1 사전 스냅샷" 기록이 있다.

## 항목 2. 속성 추가 (N-2, N-4, N-5)

- **유형**: AI 자동
- **선행 조건**: 항목 1
- **Notion 변경**(이름·타입·설명은 [Notion 작업 목록](v2.6-노션-작업.md)의 원문 그대로)
  - 수업(학원) DB: 체크박스 `보강` (N-2)
  - 출석(학원) DB: 텍스트 `메모` (N-4)
  - 학습기록(학원) DB: 텍스트 `주제` (N-5)
- **이미 있으면**: 타입이 같으면 건너뛰고, 다르면 멈추고 보고한다(이름을 바꾸거나 지우지 않는다).
- **검증**: 세 DB 스키마에 속성이 보이고 기존 속성·데이터는 그대로다.
- **실패 시 대처**: 추가한 속성만 지운다(v2.5.11 코드는 쓰지 않는다).

## 항목 3. 이름 바꾸기·롤업 (N-6, N-7)

- **유형**: AI 자동
- **선행 조건**: 항목 1
- **Notion 변경**
  - 등록(학원) DB 수식 `안내 링크` → `학생 페이지`(이름만, 수식 내용 그대로) (N-6)
  - 출석(학원) DB 롤업 `학생 페이지`(관계 `등록` → `학생 페이지`, 원본 표시) — 선택 (N-7)
- **검증**: 등록 페이지 `학생 페이지` 링크가 리포트를 연다.

## 항목 4. 수업 DB `생성 오류` 수식 교체 (N-3)

- **유형**: 운영자 직접 (Notion API가 이 수식을 받지 않아 화면에서 붙여 넣는다)
- **선행 조건**: 항목 2(`보강`)
- **운영자 안내문**
  - 왜 필요한가: 앞으로 만들 보강 수업이 "누락·초과"로 잘못 보이지 않게 한다.
  - 어디서: Notion 수업(학원) DB → `생성 오류` 속성 → 수식 편집
  - 무엇을: 기존 수식을 복사해 두고, 내용을 모두 지운 뒤 [Notion 작업 목록 N-3](v2.6-노션-작업.md)의 수식을 그대로 붙여 넣고 저장한다.
  - 끝났는지 확인하는 방법: 정규 수업 하나가 전과 같은 결과(예: `✅ 정상(6)`)를 보인다.
  - 흔한 오류와 대처: 저장이 안 되면 `보강` 속성이 있는지 본다. 결과가 이상하면 복사해 둔 수식으로 되돌리고 운영 AI에게 알린다.

## 항목 5. 최상위 페이지 제목 (N-1)

- **유형**: 운영자 직접
- **운영자 안내문**: 학원관리 Notion 최상위 페이지 제목을 학원 이름으로 바꾸고, 그 페이지가 학원관리 연결에 공유되어 있는지 확인한다. 키오스크 카드 아래에 이 이름이 표시된다(v2.6.2 뒤).

## 항목 6. 지운 함수를 부르는 자동화 정리 (N-8)

- **유형**: 운영자 직접(운영 AI는 Notion 자동화 원문을 읽지 못하면 확인을 운영자에게 안내한다)
- **운영자 안내문**: [Notion 작업 목록 N-8](v2.6-노션-작업.md)대로 등록 DB "클래스 연결"(`/sync-registration-timetable`) 자동화를 끄고, `/mark-report-source-dirty` 자동화는 Notion 자체 동작("학습정보 수정일 = 트리거 시각")으로 바꾸고, `/sync-student-report`·`/sync-school-schedules`를 부르는 것이 있으면 끈다.
- **끝났는지 확인하는 방법**: 각 DB 자동화 목록에 위 주소가 없다. 못 찾으면 보고하고 그대로 진행한다(서버에서 옛 함수를 지우기 전까지 영향 없음).
