# v2.5.44 — 관리 화면 상단 메뉴, 같은 탭 이동, 로그인 공유

- 날짜: 2026-10-12
- 이전 버전: v2.5.43
- 요약: 관리자 설정·법정 서류·학교 검색 상단에 같은 메뉴를 두고 같은 탭에서 오가게 했다. 지원 브라우저(Chrome·Edge)에서는 상단 바를 그대로 둔 채 본문만 바뀌어 보인다. 출결 키오스크만 새 탭으로 연다. 법정 서류와 학교 검색은 같은 탭 안에서 로그인을 공유한다.
- 매뉴얼 영향: 있음 → 웹 화면 안내에 "상단 메뉴(관리자 설정·법정 서류·학교 검색, 키오스크는 새 탭)"와 "법정 서류·학교 검색은 한 번 로그인하면 같은 탭에서 함께 쓰임"을 반영한다(항목 3).
- 변경 유형: 웹 화면(GitHub Pages). 함수·마이그레이션·Secrets·Notion 변경 없음.

---

## 항목 1. 상단 메뉴와 같은 탭 이동

- **유형**: AI 자동
- **선행 조건**: v2.5.43(공용 파일 버전 표시)
- **대상 파일**: `assets/hada-shortcuts.js`, `assets/hada-ui.css`, `admin_settings.html`, `school_search.html`, `legal_documents.html`, `docs/DESIGN.md`(2-4 "상단 메뉴")
- **변경 내용**
  - "바로가기" 버튼과 대화상자를 없애고 상단 바에 탭 [관리자 설정] [법정 서류] [학교 검색]과 [키오스크](새 탭)를 둔다. 지금 화면의 탭이 선택돼 보인다. 아이콘은 Feather Icons.
  - 화면 전환(`@view-transition`): 같은 탭 이동 때 상단 바를 고정한다. 지원하지 않는 브라우저는 일반 이동, 동작 줄이기 설정이면 전환 효과 없음.
  - 1080px 이하는 메뉴가 상단 바 아래 줄로, 700px 이하는 탭 아이콘을 숨기고 키오스크는 아이콘만.
- **환경별 값**: 없음

## 항목 2. 법정 서류·학교 검색 로그인 공유

- **유형**: AI 자동
- **선행 조건**: 없음
- **대상 파일**: `admin_auth.js`, `legal_documents.html`, `school_search.html`
- **변경 내용**
  - 로그인 결과를 이 탭의 sessionStorage(`hada_admin_browser_session_v1`)에 두고 두 화면이 함께 쓴다. 탭을 닫거나 어느 화면에서든 로그아웃하면 해제되고, 서버가 401을 주면 지우고 로그인 화면으로 간다.
  - 법정 서류는 예전에 키오스크와 같은 저장 칸(localStorage `admin_key`)을 써서, 같은 기기에서 둘 다 쓰면 서로의 로그인을 덮어쓰거나 지웠다. 이제 키오스크만 그 칸을 쓴다. 이전 버전에서 법정 서류가 남긴 값은 건드리지 않는다(키오스크 로그인일 수 있음).
  - 관리자 설정과 키오스크는 지금처럼 따로 로그인한다. (정정: 관리자 설정 로그인은 더 강한 권한이 아니라 같은 종류의 관리자 로그인이다. v2.5.46에서 관리자 설정도 공유하도록 바꿨다.)
- **환경별 값 (중요)**: `attendance_kiosk.html`·`legal_documents.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`, `school_search.html`의 `ENDPOINT`는 **운영 값을 유지**한다.
- **검증**: Pages 반영 후 법정 서류에 로그인 → 상단 [학교 검색] → 비밀번호 없이 학교 연결 화면이 열리는지, 로그아웃 후 다른 화면에서도 로그인을 다시 묻는지, [키오스크]가 새 탭으로 열리는지 본다.
- **실패 시 대처**: v2.5.43의 해당 파일들로 되돌린다. 데이터 영향 없음.

## 항목 3. 매뉴얼

- **유형**: 운영자 직접(원본은 배포 담당자 승인 후 반영)
- **변경 내용**: 웹 화면 안내의 "바로가기" 설명을 "상단 메뉴(관리자 설정·법정 서류·학교 검색은 같은 탭, 키오스크는 새 탭)"로 바꾸고, "법정 서류와 학교 검색은 한 번 로그인하면 같은 탭에서 함께 쓰이며 탭을 닫으면 해제"를 추가한다.
