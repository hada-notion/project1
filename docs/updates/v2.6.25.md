# v2.6.25 — 보고서·수강료 생성: 설정 문제를 ⚠️ 오류로 표시

- 날짜: 2026-10-17
- 이전 버전: v2.6.24
- 요약: 클래스 [보고서 생성]·[월 수강료 생성]이 설정 문제로 아무것도 만들지 못하면, 예전에는 로그만 남기고 생성 상태를 ✅ 완료로 표시했다(원본에서 `보고서 생성 대상`이 수강료 발송함에 연결돼 보고서가 안 만들어졌는데 ✅ 완료로 보였다). 이제 ⚠️ 오류로 표시하고 클래스 `마지막 오류`에 이유를 남긴다. 설정 문제는 다시 해도 같아서 큐 재시도는 하지 않는다. 수강료 생성은 연결된 발송함의 구분이 "수강료"인지도 확인한다.
- 매뉴얼 영향: 있음(오류 안내 문구)
- 변경 유형: 함수(`generate-report`·`generate-tuition` 큐 처리)
- **선행 조건: 없음.** 운영자가 할 일은 없다.

---

## 항목 1. 함수 반영

- **유형**: AI 자동(원본 `supabase/functions/_shared/webhookIngest.ts`, `generateReportTarget.ts`, `generateTuitionTarget.ts` 반영 시 자동 배포)
- **⚠️ 오류가 되는 경우와 안내 문구**

| 생성 | 경우 | 마지막 오류 |
| --- | --- | --- |
| 보고서·수강료 | 클래스에 발송함이 연결되지 않음 | 클래스의 "보고서 생성 대상"/"수강료 생성 대상"에 알림톡 발송함이 연결되지 않았습니다 … |
| 보고서 | 연결된 발송함 구분이 주간·월간 보고서가 아님 | 연결된 발송함의 구분이 "수강료"입니다. 구분이 "주간 보고서" 또는 "월간 보고서"인 발송함을 연결해 주세요. |
| 수강료 | 연결된 발송함 구분이 수강료가 아님 | 연결된 발송함의 구분이 "월간 보고서"입니다. 구분이 "수강료"인 발송함을 연결해 주세요. |
| 보고서·수강료 | 발송함 기간이 비어 있음 | 연결된 발송함에 "기간"이 입력되지 않았습니다. |
| 수강료 | 클래스 월간 수업 총량이 비어 있음 | 클래스의 "월간 수업 총량"이 비어 있습니다. 먼저 입력해 주세요. |

- 대상 학생이 없는 경우(기간에 수강 중인 등록 없음)는 오류가 아니라 지금처럼 ✅ 완료다.
- **검증(원본)**: 함수 테스트(설정 오류 → ⚠️ 오류·재시도 안 함 / 다른 오류는 큐 재시도 / 보고서 생성 대상이 수강료 발송함 / 수강료 생성 대상이 보고서 발송함·미연결), 전체 Deno 테스트, 타입 검사, 회귀 가드.

## 매뉴얼

- "보고서·수강료 생성 상태가 ⚠️ 오류면 클래스의 '마지막 오류'를 보고 연결된 발송함(구분·기간)이나 월간 수업 총량을 고친 뒤 다시 눌러 주세요."
