# v2.5.53 — 나이스 학사일정·학교 정보 출처 표시

- 날짜: 2026-10-12
- 이전 버전: v2.5.52
- 요약: 나이스 교육정보 개방 포털 이용약관 제11조는 공공데이터를 쓸 때 출처를 밝히도록 한다. 학부모 리포트 일정 달력과 학교 검색 화면에 "나이스 교육정보 개방 포털" 출처를 한 줄 넣었다.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면(GitHub Pages). 함수·마이그레이션·Secrets·Notion 변경 없음.

---

## 항목 1. 학부모 리포트 일정 달력

- **유형**: AI 자동
- **선행 조건**: 없음
- **대상 파일**: `student_report_part1.js`(`buildScheduleCalendarHtml`), `student_report.html`(`.schedule-source` 스타일 한 줄)
- **변경 내용**: 보고 있는 달에 "학사 일정" 분류 일정이 하나라도 있으면 달력 아래 오른쪽에 작은 회색 글씨로 "학사일정 출처: 나이스 교육정보 개방 포털"을 보여준다. 학사 일정이 없는 달에는 나오지 않는다. 다른 부분은 바꾸지 않았다.
- **환경별 값 (중요)**: `student_report_part1.js`의 `SUPABASE_URL`은 **운영 값을 유지**한다. 이번 변경은 `buildScheduleCalendarHtml` 안의 두 군데와 스타일 한 줄뿐이므로 파일 전체를 덮어쓰지 말고 그 부분만 옮긴다.
- **검증**: Pages 반영 후 학사일정이 있는 학생의 리포트에서 일정 화면을 열어 달력 아래 출처 줄이 보이는지, 학사일정이 없는 달로 넘기면 사라지는지 본다.
- **실패 시 대처**: v2.5.52의 두 파일로 되돌린다. 데이터 영향 없음.

- **변경 내용**: 학교 연결 카드 맨 아래에 "학교 정보 출처: 나이스 교육정보 개방 포털" 안내 한 줄(`.help.source-note`).

- **검증**: 로그인 후 학교 연결 카드 맨 아래에 출처 줄이 보이는지 본다.
