# v2.7.10 — 수업 삭제 시 그룹 진도 학습기록 정리

- 날짜: 2026-10-20
- 이전 버전: v2.7.9
- 요약: 수업 [삭제]가 그 수업의 그룹 진도 학습기록을 지우지 않고 수업 연결만 끊어, 수업·출석이 비어 있는 학습기록이 남았다(진도·리포트에 계속 잡힐 수 있음). 학습기록은 수업 기준이므로 그 수업에만 달린 그룹 진도 기록은 학습활동과 함께 지운다. 다른 수업에도 연결된 옛 기록만 이 수업 연결을 끊고 남긴다.
- 매뉴얼 영향: 없음
- 변경 유형: 코드(Edge Function 1개). 마이그레이션·Secrets·Notion 변경 없음.

## 항목 1. cascade-delete 수업 삭제의 그룹 진도 학습기록

- **유형**: AI 자동
- **선행 조건**: 없음
- **변경 이유·증상**: 원본 실동작 점검(2026-10-20)에서 그룹 진도 교재로 만든 학습기록이 수업 [삭제] 뒤에도 남는 것을 확인했다(수업·출석 관계가 빈 학습기록).
- **대상 코드**
  - `supabase/functions/_shared/cascadeDeleteTarget.ts`: `cascadeDelete`의 학습기록 하위 처리
  - 찾을 원문 (앵커):

    ```
    } else if (progressType === GROUP_PROGRESS_TYPE) {
    ```

- **변경 내용**: 원본 `main`의 `cascadeDeleteTarget.ts`, `cascadeDeleteLean_test.ts`, `learningRecordShare_test.ts`로 바꾼다. 그룹 진도 기록의 `수업` 관계에 지우는 수업 말고 다른 수업이 있으면 연결만 끊고, 없으면 하위로 지운다.
- **환경별 값**: 없음
- **필요한 Secret (이름만)**: 없음
- **Notion 변경**: 없음
- **마이그레이션 / 재배포**: 마이그레이션 없음. `cascade-delete`(와 같은 공용 파일을 쓰는 `process-sync-queue`) 재배포. 원본 `main` 병합 시 자동 배포 워크플로가 함께 배포한다.
- **검증**:
  1. `deno test --allow-env supabase/functions/_shared/cascadeDeleteLean_test.ts supabase/functions/_shared/learningRecordShare_test.ts` 통과.
  2. 운영에 이미 남은 기록 확인(선택): 학습기록 중 `수업`과 `출석`이 모두 빈 것. 있으면 내용을 보고 그 학습기록의 [삭제]로 지운다(원장님 확인).
- **실패 시 대처**: 두 파일을 이전 버전으로 되돌려 재배포한다. 업무 데이터는 바꾸지 않는다.
- **매뉴얼**: 변경 없음
