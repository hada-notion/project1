# v2.5.63 — 웹 화면 연결값을 학원별 설정 파일 하나로

- 날짜: 2026-10-13
- 이전 버전: v2.5.62
- 요약: 학부모 리포트·키오스크·법정 서류·학교 검색·관리자 설정이 Supabase 주소와 anon 공개 키를 각 파일 안에 따로 갖고 있었다. 이 값을 저장소 루트의 `hada_config.js` 한 파일로 모으고 모든 화면이 이 파일을 읽게 했다. 이제 화면 파일은 원본 최신본으로 통째로 바꿀 수 있고, 학원마다 다른 값은 `hada_config.js`만 지키면 된다. `admin_config.json`은 없앴다.
- 매뉴얼 영향: 없음(운영 업데이트 절차·새 학원 이식 체크리스트 문서만)
- 변경 유형: 웹 화면(GitHub Pages)·설치 스크립트·회귀 가드. 함수·마이그레이션·Secrets·Notion 변경 없음. 기능 변경 없음.

## 항목 1. 학원별 설정 파일 만들기 (운영 최초 1회)

- **유형**: AI 자동
- **선행 조건**: 없음. **항목 2보다 먼저** 한다(설정 파일 없이 화면을 바꾸면 화면이 "학원 연결 설정이 필요" 안내만 보여준다).
- **대상 파일**: 운영 저장소 루트의 `hada_config.js`(새 파일)
- **방법**: 원본 `hada_config.js`의 형식을 따르되 두 값은 **운영 값**으로 채운다. 운영 값은 지금 운영 저장소의 `student_report_part1.js`(또는 `attendance_kiosk.html`)에 있는 `SUPABASE_URL`·`SUPABASE_ANON_KEY`를 그대로 옮긴다. 원본 값을 복사하지 않는다.
  - `supabaseUrl`: `https://<운영 프로젝트 ref>.supabase.co` 형식(끝에 `/` 없음)
  - `supabaseAnonKey`: 운영 프로젝트의 anon 공개 키
- **환경별 값**: 이 파일이 환경별 값의 유일한 위치다. 이후 원본 업데이트를 적용할 때 **이 파일은 덮어쓰지 않는다.**
- **검증**: 두 값이 기존 운영 파일의 값과 같은지 비교한다(값은 채팅·문서에 쓰지 않고 "같다/다르다"만 보고).
- **실패 시 대처**: 파일을 지우면 화면이 안내 문구를 보여준다. 기존 화면 파일로 되돌리면 이전처럼 동작한다.

## 항목 2. 화면 파일 교체

- **유형**: AI 자동
- **선행 조건**: 항목 1
- **대상 파일**: `student_report.html`, `student_report_part1.js`, `attendance_kiosk.html`, `legal_documents.html`, `school_search.html`, `admin_settings.html`, `admin_settings.js`, `admin_auth.js` — 원본 최신본으로 **통째로** 바꾼다. 이 파일들에는 더 이상 운영 값이 없다.
- **삭제**: `admin_config.json`(관리자 설정이 이제 `hada_config.js`를 읽는다).
- **검증**: 각 화면을 열어 평소처럼 동작하는지 본다. 학부모 리포트는 학생 링크로 열리는지, 키오스크·법정 서류·학교 검색·관리자 설정은 로그인되는지. 설정 파일이 없거나 주소가 잘못되면 화면에 "학원 연결 설정" 안내가 나온다.
- **실패 시 대처**: 이전 버전의 화면 파일과 `admin_config.json`으로 되돌린다. 데이터 영향 없음.
