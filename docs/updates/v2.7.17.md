### 1-1. 교재·학습 / 7-4. 과제·평가 학습활동 생성

- 찾을 원문: "4. 과제는 학생별 `과제상태`를 `🔴 미제출` 또는 `🔵 제출`로 관리합니다."
- 바꿀 원문: "4. 과제는 학생별 `과제상태`를 `🔴 미제출`, `🟡 일부 제출`, `🔵 제출` 중에서 관리합니다. 선생님끼리 남길 내용은 학습활동 `메모`에 적습니다. 메모는 내부용이라 학부모 리포트에는 나오지 않습니다."
- 찾을 원문: "`전체 문항`을 넣기 전에는 `점수`가 비어 있습니다(0점이 아님)."
- 바꿀 원문: "`점수`는 `정답 문항 ÷ 전체 문항 × 100`이므로 두 값을 모두 넣어야 올바른 점수가 됩니다."
- 찾을 원문: "6. 수업·출석·학습기록·등록·보고서 페이지의 `학습활동` 탭은 학습·과제·평가를 `구분`으로 묶어 보여 줍니다. 과제 줄에는 과제상태·마감일, 평가 줄에는 점수만 보입니다."
- 바꿀 원문: "6. 수업·출석·등록·보고서 페이지의 `학습활동` 탭은 대시보드로, 위에서부터 `과제` / `평가` / `학습` 표 세 칸이 있습니다. 과제 칸에는 과제 마감일·과제상태, 평가 칸에는 전체 문항·정답 문항·오답 문항·점수, 학습 칸에는 내용이 보입니다. 등록·보고서 탭은 수업일 순으로 보여 주며, 등록 탭은 최근 4주만 보입니다." (뒤 문장 "오늘 마감인 과제를 체크할 때는 …과제검사 탭을 씁니다."는 그대로)

### 1-2. 보고서·수강료·교재비 / 10-0. 일일 보고서 보내기 (새 절)

- 첫 문단의 "보고서·수강료는 "발송함" 단위로 일괄 생성/발송하고, 교재비는 학생별로 개별 생성/발송합니다." → "일일 보고서는 수업·출석에서 바로 보내고, 주간·월간 보고서와 수강료는 "발송함" 단위로 일괄 생성/발송하며, 교재비는 학생별로 개별 생성/발송합니다."
- 10-1 앞에 새 절을 넣는다:

  ```
  ### 10-0. 일일 보고서 보내기

  일일 보고서는 출석 한 건(그날 학생 한 명)마다 보냅니다. 발송함을 만들 필요가 없고, 수업이 끝난 뒤 출석·학습기록·과제·평가를 입력하고 보냅니다.

  1. 수업 페이지의 `보고서 일괄 전송` 버튼을 누르면 그 수업의 출석 전체가, 출석 페이지의 `보고서 전송` 버튼을 누르면 그 학생만 보낼 차례에 들어갑니다.
  2. 잠시 뒤 한 명씩 차례로 보내지고, 출석의 `보고서 전송 상태`가 ✅ 완료가 되면 끝입니다. 다시 누르지 않고 기다립니다.
  3. 수업 페이지의 `출석` 탭에서 학생별 `보고서 전송`·`전송완료 체크`·`전송 내역`을 한눈에 확인합니다.
  4. 이미 보낸 학생은 다시 보내지 않습니다. 다시 보내려면 그 출석의 `전송완료 체크`를 해제한 뒤 `보고서 전송`을 누릅니다.
  5. ⚠️ 오류인 건은 출석의 `마지막 오류`와 알림톡 설정의 `일일 보고서` 행을 확인합니다.

  완료 확인(초록 콜아웃): 출석마다 `보고서 전송 상태`가 ✅ 완료이고 알림톡 전송 기록에 실패가 없으면 정상입니다.
  ```

- 2. 공통 화면 구성: "**교재 · 캘린더 · 학습기록 · 보고서** 4개 탭" → "**홈 · 교재 · 캘린더 · 학습기록 · 보고서** 5개 탭"

  ```
  ## 3. 홈 탭

  - 상단에 클래스 이름과 담당 선생님·수업 요일이 표시됩니다.
  - 오늘: 오늘 출석 상태(수업 전·출석·결석·보강·수업 없음), 남은 과제 개수, 다음 수업을 한눈에 보여줍니다.
  - 남은 과제: 아직 마감이 지나지 않은 미제출 과제를 마감이 가까운 순서로 3개까지 보여줍니다.
  - 진행 중인 교재: 교재별 진도율을 막대로 보여주고, 누르면 그 교재의 학습 기록으로 이동합니다.
  - 선생님 한마디: 가장 최근에 남긴 한마디를 보여줍니다.
  ```

## 확인이 남은 것 (원본)

- 학습활동 `점수`: `전체 문항`이 빈 행에서 화면에 빈칸으로 보이는지 0·오류로 보이는지 원본 화면에서 확인하지 않았다. 그래서 메뉴얼은 "두 값을 모두 넣어야 한다"로만 적었다.
