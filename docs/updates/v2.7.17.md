# v2.7.17 — 출석 페이지에서 진도교재 탭 빼기, 진도교재 패널에서 `과목` 숨김

- 날짜: 2026-10-24
- 이전 버전: v2.7.16
- 요약: 출석(학원) DB 페이지의 `진도교재` 탭을 지운다. 학습기록은 수업의 [학습기록 생성]으로만 만들고(출석의 [학습기록 생성]은 v2.6.21에서 없앴다), 그 버튼은 수업 `진도교재`(명단 학생의 진도교재 전부)에서 `오늘 학습`이 체크된 교재를 읽는다. 출석 탭에 남은 `오늘 학습` 체크는 할 일이 없을 뿐 아니라, 그룹 진도교재는 반 전체가 한 권을 쓰므로 학생 한 명의 출석에서 체크하면 반 전체 교재가 체크된다.
- 매뉴얼 영향: 없음(출석 페이지 탭 하나가 빠지고, 진도교재 패널에서 `과목`이 보이지 않음)
- 변경 유형: Notion 화면(출석 페이지 레이아웃 탭 1개 삭제, 진도교재 세부 정보 패널 속성 1개 숨김). 속성·수식·버튼·자동화·코드·Secrets 변경 없음.

---

## 항목 1. 출석 페이지 `진도교재` 탭 삭제

- **유형**: 운영자 직접(화면 작업, 원본 지원 브라우저로도 가능)
- **선행 조건**: 출석 페이지에 [학습기록 생성] 버튼이 없음(v2.6.21 이후). 아직 있으면 v2.7 묶음부터 적용한다.
- **바꾸는 방법**: 출석(학원) DB 페이지 하나를 연다 → 레이아웃 사용자 지정 → 탭 줄에서 `진도교재` 탭 → 탭 삭제 → [모든 페이지에 적용].
  - 탭(보기)만 지운다. 출석의 `진도교재` 관계, `출석 조정 정보` 같은 수식, 진도교재(학원) DB의 `오늘 학습`은 지우지 않는다.
- **최종 모양**: 출석 콘텐츠 탭은 `출석 정보` · `학습기록` · `과제검사` · `학습활동`. 자세한 모양은 [노션-레이아웃.md](../기준/노션-레이아웃.md)의 출석(학원) DB, 규칙은 [이름 규칙](../이름-규칙.md) 7장 5번.
- **바뀐 뒤 지문**: `출석(학원) DB / 탭 / 진도교재` 항목이 없어진다([노션-지문.json](../기준/노션-지문.json)).
- **검증**: 최신 `scripts/notion-scan.js`로 스캔해 출석의 탭 항목이 "같음"이고 `출석(학원) DB / 탭 / 진도교재`가 "추가"(운영에만 있음)로 나오지 않는다. 수업 페이지의 진도교재 탭에서 `오늘 학습` 체크 → [학습기록 생성]이 그대로 되는지 본다.
- **실패 시 대처**: 레이아웃 사용자 지정에서 탭을 다시 추가하거나 페이지 레이아웃 기록으로 되돌린다. 데이터는 바뀌지 않는다.

## 항목 2. 진도교재 세부 정보 패널에서 `과목` 숨김

- **유형**: 운영자 직접(화면 작업, 원본 지원 브라우저로도 가능)
- **선행 조건**: 없음
- **바꾸는 방법**: 진도교재(학원) DB 페이지 하나를 연다 → 레이아웃 사용자 지정 → 세부 정보 패널의 `교재 연결` 섹션에서 `과목`을 **항상 숨김**으로 옮긴다 → [모든 페이지에 적용].
  - 속성은 지우지 않는다. 표시 방식만 바꾼다.
- **최종 모양**: `교재 연결` 섹션은 `개별교재`·`반별교재`(둘 다 비어 있으면 숨김). 숨김은 `과목`·`학습기록`·`출석`·`생성 일시`·`수업`·`학습기록 생성 시작 시각`·`학습기록 생성 상태` 7개. [노션-레이아웃.md](../기준/노션-레이아웃.md)의 진도교재(학원) DB.
- **바뀐 뒤 지문**: `진도교재(학원) DB / 레이아웃 / 패널`.
- **검증**: 재스캔에서 이 항목이 "같음".
- **실패 시 대처**: 표시 방식을 "비어 있으면 숨김"으로 되돌린다. 데이터는 바뀌지 않는다.
