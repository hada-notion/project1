# v2.5.19 — 웹훅 키 교체 화면 복사 도구

- 날짜: 2026-10-13
- 이전 버전: v2.5.18
- 요약: 웹훅 키 교체 화면에서 새 웹훅 키를 교체가 끝날 때까지 계속 복사할 수 있고(화면 위에 붙어 있는 "새 웹훅 키" 막대), 체크리스트 항목마다 그 버튼·자동화의 웹훅 URL과 추가 헤더를 복사하는 버튼이 생겼다. 새로 배포하는 학원에서 URL과 키를 번갈아 붙여 넣을 때 클립보드에서 키가 사라지는 문제를 없앤다.
- 매뉴얼 영향: 없음(화면 안내에 포함)
- 변경 유형: 웹 화면(GitHub Pages). Supabase 함수·마이그레이션·Secrets·Notion 변경 없음.

---

## 항목 1. 관리자 설정 화면

- **유형**: AI 자동
- **선행 조건**: 운영 소유자의 전체 계획 승인. v2.5.18 적용.
- **대상 파일**: `admin_settings.html`, `admin_settings.js`, `docs/DESIGN.md`
- **변경 내용**
  - **새 웹훅 키 막대**: 교체 현황 화면 위쪽에 고정. 가려진 키(앞 4자·뒤 4자), "보기", "키 복사". 키는 **교체를 시작한 브라우저 탭의 sessionStorage에만** 두고, 교체 완료·취소·로그아웃·탭 닫기 때 지운다. 서버는 전과 같이 해시만 저장하므로 다른 탭·기기에서는 다시 볼 수 없다(그 경우 교체 취소 후 다시 시작).
  - **항목별 복사**: 체크리스트 각 항목에 "URL 복사"(그 학원 Supabase 주소 + 함수 + 하위 경로·쿼리)와, 필요한 항목에 "추가 헤더" 복사 버튼.
    - 교재 생성: 등록 `/create-individual`, 클래스 `/create-class`
    - 교재비 생성 `/from-class-carts`, 진도교재 담기 `/from-cart`
    - 다음주 수업 일괄 생성 `?mode=bulk`
    - 링크 재발급·비활성화·활성화: 헤더 `x-link-action` = regenerate / disable / enable
  - 키 표시 화면의 "다시 볼 수 없습니다" 확인 창을 없앴다(교체 중에는 다시 복사할 수 있으므로).
- **환경별 값**: 없음. URL은 그 학원 `admin_config.json`의 Supabase 주소로 만든다.
- **보안 판단**: 교체 기간 동안 새 키가 그 탭의 브라우저 저장소에 남는다. 화면은 외부 스크립트를 불러오지 않는 CSP가 걸려 있고, 공용 기기에서는 교체 후 로그아웃하도록 안내한다.
- **검증**: 모의 화면 검사(키 막대 가림·보기·복사, URL·헤더 복사 값, 교체 완료 후 저장소에서 키 삭제). Pages 반영 후 원본에서 "새 웹훅 키 만들기 → URL 복사 → 키 복사 → 교체 취소"로 확인한다.
