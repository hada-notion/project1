## 항목 1. 학부모 리포트

- **유형**: AI 자동
- **선행 조건**: v2.5.60
- **대상 파일**: `student_report_part1.js`(교재 상세 안내 문구 한 줄), `student_report_part2.js`(제목·라벨), `docs/DESIGN.md`(용어표)
- **변경 내용**
  - 탭 제목: 진도 교재 → 교재, 학습기록 타임라인 → 학습기록.
  - 안내 문구 해요체: 학습기록·교재 상세 "최근 순서로 보여줘요", 보고서 "일간·주간·월간 보고서를 볼 수 있어요", 일정 "학원 일정과 학교 일정을 확인할 수 있어요", 통합 시간표 "…보여줘요".
  - 홈: 곧 마감 → 남은 과제, 진도 → 교재 진도.
  - 캘린더 전환: 출결 현황 → 출석 현황.
  - 일간 보고서: 요약 카드 출석 → 출석 현황, 이날 마감 과제 → 과제 현황. 선생님 코멘트 → 선생님 한마디.
  - 주간·월간 보고서: 평가 기록 → 최근 평가 추이.
  - 과제 상태 글자: 제출 / 일부 제출 / 미제출로 통일(일간 배지 "부분완료", 캘린더 범례 "일부", 캘린더 막대·칩 "완료"를 바꿈).
  - 유지: 지난 과제·이번 과제·이번 평가, 과제이행률.
- **환경별 값 (중요)**: `student_report_part1.js`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값 유지**. part1은 교재 상세 안내 문구 한 줄만 바뀌었으므로 그 줄만 옮긴다.
- **검증**: 교재·학습기록 탭 제목, 캘린더 전환 "출석 현황", 일간 보고서 "출석 현황 / 과제 현황"과 "선생님 한마디", 주간 보고서 "최근 평가 추이"가 보이는지 본다.
- **실패 시 대처**: v2.5.61의 두 파일로 되돌린다. 화면 글자만 바뀌어 데이터 영향 없음.
