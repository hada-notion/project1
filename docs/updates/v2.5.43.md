## 항목 2. 공용 파일 버전 표시

- **유형**: AI 자동
- **선행 조건**: 없음
- **대상 파일**: `admin_settings.html`, `attendance_kiosk.html`, `school_search.html`, `legal_documents.html`, `assets/hada-ui.css`(`@import`), `tests/design-lint.cjs`, `docs/DESIGN.md`(2-6 작업 절차)
- **변경 내용**: `assets/hada-ui.css`, `assets/hada-tokens.css`, `assets/hada-shortcuts.js`, `admin_auth.js`, `admin_settings.js`를 부르는 주소에 `?v=<파일 내용 해시 8자리>`를 붙였다. 파일 내용이 바뀌면 주소가 바뀌어 브라우저가 새 파일을 바로 받는다. `node tests/design-lint.cjs --fix`가 버전을 갱신하고, 갱신을 빠뜨리면 `node tests/design-lint.cjs`가 실패한다.
- **환경별 값 (중요)**: `attendance_kiosk.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`, `school_search.html`의 `ENDPOINT`는 **운영 값을 유지**한다. 운영에 적용할 때 화면 파일의 `?v=` 표시도 원본과 같게 맞춘다(공용 파일 내용이 원본과 같으면 값도 같다).
- **검증**: Pages 반영 후 일반 새로고침만으로 관리자 설정의 첫 알림 줄이 흰 바탕인지 본다. 다음 공용 파일 패치부터는 강력 새로고침 없이 반영되는지 본다.
- **실패 시 대처**: v2.5.42의 네 화면 파일과 `admin_settings.js`, `assets/hada-ui.css`로 되돌린다. 데이터 영향 없음.
