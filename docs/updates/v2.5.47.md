- 날짜: 2026-10-12
- 이전 버전: v2.5.46
- 요약: 법정 서류 조회 결과 표의 머리 버튼이 여는 정렬·필터 창이 무거웠다(제목, 오름차순·내림차순·원래 순서 버튼 3개, 열 검색, 값 선택, 필터 해제, 닫기). [정렬] 한 버튼과 열 검색 칸만 남겼다. 표 머리 이름과 아이콘이 좁은 열에서 줄바꿈되던 것도 고쳤다.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면(GitHub Pages). 함수·마이그레이션·Secrets·Notion 변경 없음.

## 항목 1. 정렬·필터 창

- **유형**: AI 자동
- **선행 조건**: v2.5.45
- **대상 파일**: `legal_documents.html`
- **변경 내용**
  - [정렬] 한 버튼: 누를 때마다 오름차순 → 내림차순 → 원래 순서를 돈다. 다른 열을 정렬 중이면 이 열 오름차순부터. 버튼에 지금 상태(정렬 / 오름차순 / 내림차순)와 Feather 아이콘이 보인다.
  - 열 검색 칸: 입력하는 대로 그 열에 글자가 들어 있는 행만 보인다. 비우면 해제.
  - 없앤 것: 창 제목(열 이름), 값 선택, "이 열 필터 해제", "닫기". 창 바깥을 누르거나 Esc·Enter를 누르면 닫힌다. 표 아래 [정렬·필터 초기화]는 그대로.
  - 표 머리: 화면에서는 이름과 정렬 아이콘을 한 줄로(줄바꿈 없음). 인쇄 서식의 머리 줄바꿈 규칙은 그대로.
  - 검색 중인 열: v2.5.45의 필터(깔때기) 아이콘을 덧붙이지 않고, 머리 버튼에 베이지 바탕과 테두리를 둔다.
- **환경별 값 (중요)**: `legal_documents.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값을 유지**한다.
- **검증**: Pages 반영 후 수강생 대장을 조회해 "등록번호" 머리가 한 줄인지, 머리 버튼 → [정렬]을 세 번 눌러 오름차순 → 내림차순 → 원래 순서가 되는지, 검색 칸 입력으로 행이 걸러지는지, 바깥을 누르면 창이 닫히는지 본다.
- **실패 시 대처**: v2.5.46의 `legal_documents.html`로 되돌린다. 데이터 영향 없음.
