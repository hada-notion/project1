## 항목 1. 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`(`bookRow`의 feed 모양, 교재 탭·교재 상세), `class_room.html`(`.book-row.feed`), `docs/DESIGN.md`
- **동작**: 교재 탭·교재 상세 카드 = 테두리 없는 흰 그림자 카드(모서리 14, 안쪽 12/16), 위로 맞춤, 표지 64×86(표지가 없거나 그림이 안 열리면 갈색 그라데이션에 교재명), 제목은 줄바꿈, 화살표 없음, 카드 사이 10. 안내 "진행상황별로 교재를 볼 수 있어요", 구분 "진행중 n · 완료 n · 다음 n". 묶음(반 교재·개별·학생별)이 하나뿐이면 묶음 이름을 생략. 기록 만들기·기록 카드의 교재 고르기 카드는 고른 표시가 필요해 테두리 카드 그대로.
- **검증(모의 데이터)**: 수업 관리 화면 흐름 검사 390·768·1280 — 교재 카드 테두리 0·그림자·화살표 없음·표지 없을 때 교재명 표지, 안내·구분 글자, 교재 상세·기록 만들기 흐름 그대로. 디자인 규칙 검사, 회귀 가드.
- **미검증**: 운영 데이터(실제 북커버)·실기기.
- **실패 시 대처**: v2.5.101의 `class_room.js`·`class_room.html`로 되돌린다.
