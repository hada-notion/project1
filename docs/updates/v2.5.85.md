# v2.5.85 — 수업 관리 뒤로가기

- 날짜: 2026-10-14
- 이전 버전: v2.5.84
- 요약: 수업 관리는 한 페이지 안에서 화면만 바꿔 그리기 때문에 브라우저·휴대폰 뒤로가기를 누르면 페이지에서 나가 버렸다. 방문 기록(History API)에 동작을 남겨 앱처럼 직전 동작으로 돌아가게 했다. 열린 창·서랍을 먼저 닫고, 들어온 화면에서는 이전 화면으로, 하단 탭은 앱(안드로이드·인스타그램)처럼 쌓지 않는다.
- 매뉴얼 영향: 수업 관리 매뉴얼 작성 때 뒤로가기 동작 설명
- 변경 유형: 웹 화면만(Pages). 함수·Notion 변경 없음.

---

## 항목 1. 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`, `class_room.html`(스크립트 버전 표시), `docs/DESIGN.md`
- **동작**

  | 상황 | 뒤로가기 |
  |---|---|
  | ≡·📅 서랍, 기록 만들기·메모·보강 수업 만들기 창이 열려 있음 | 창만 닫힘 |
  | 교재 고르기 | 기록 만들기로(적던 내용 그대로) |
  | 학생 공간·기록 카드·보강 대기실·강사 선택 | 들어오기 전 화면(상단 ←도 같음) |
  | 서랍에서 다른 반·날짜 수업으로 옮김 | 이전에 보던 수업 |
  | 학습기록 탭 | 학생 목록 탭(탭을 여러 번 오가도 한 번) |
  | 학생 목록 탭 | 이전 화면 |
  | 처음 연 화면 | 페이지에서 나감(원래대로) |

  - 창을 닫는 ✕·바깥 누르기·Esc·저장 뒤 닫기도 같은 길로 닫아, 방문 기록과 화면이 어긋나지 않는다.
  - 저장하지 않은 편집이 있으면 뒤로가기 전에 묻는다. 앞으로 가기는 무시한다.
  - 주소는 바꾸지 않는다. 새로고침하면 지금처럼 오늘 수업이 열린다.
- **검증(모의 데이터)**: 수업 관리 화면 흐름 검사 390·768·1280 — 서랍 열고 뒤로(닫힘·페이지 유지), 학습기록 → 뒤로(학생 목록), 학생 공간 → 뒤로, 기록 만들기 → 교재 고르기 → 뒤로(적던 범위 유지) → 뒤로(창 닫힘), Esc로 닫기, 앞으로 가기 무시, 탭을 여러 번 오간 뒤 뒤로 한 번 학생 목록·한 번 더 이전 화면(강사 선택), 📅로 날짜를 옮긴 뒤 뒤로 두 번(직전 수업 → 그 전 수업), 기존 흐름 전체. 디자인 규칙 검사, 회귀 가드.
- **미검증**: 실제 휴대폰(안드로이드 뒤로 버튼, iOS 사파리 밀어서 뒤로)에서의 동작.
- **실패 시 대처**: v2.5.84의 `class_room.js`·`class_room.html`로 되돌린다.
