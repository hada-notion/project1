- 매뉴얼 영향: 없음
- 변경 유형: 화면(Pages `library.html`). 함수·Notion·DB 변경 없음.

## 항목 1. 화면 반영

- **유형**: AI 자동(원본 `library.html`로 바꾸면 Pages 반영. `hada_config.js`는 덮어쓰지 않는다)
- **선행 조건**: v2.6.6
- **변경 이유·증상**: 교보문고 외국도서는 ISBN이 `9791166371707 ( 1166371700 )`처럼 ISBN-10이 붙어 나온다. 숫자만 이어 붙여 23자리가 되어 라이브러리가 ISBN을 버렸고, 표지는 ISBN으로 만들기 때문에 함께 비었다(원본 "120-word READING 2" 실사용에서 확인).
- **동작**: [교재 가져오기]가 978·979로 시작하는 13자리만 읽고, 없으면 교보문고 표지 주소에 든 ISBN을 쓴다. 교보문고 표지 주소(458px 크기)도 함께 복사한다. 라이브러리는 ISBN이 있으면 지금처럼 교보문고 표지 규칙 주소, 없으면 복사된 표지 주소를 쓴다(`https://contents.kyobobook.co.kr/` 주소만).
- **검증(원본)**: 실제 교보문고 외국도서 페이지에서 ISBN `9791166371707`·표지 주소, 라이브러리 UI 검사(ISBN 없을 때 교보문고 표지 주소 사용, 다른 사이트 주소는 무시), 디자인 검사.
- **미검증**: 실제 즐겨찾기에서 다시 누른 결과(운영자 확인).

## 항목 2. 즐겨찾기 다시 끌어다 놓기

- **유형**: 운영자 직접(v2.6.6에서 이미 즐겨찾기를 만든 PC만)
- **운영자 안내문**: 즐겨찾기 막대의 [교재 가져오기]를 지우고(오른쪽 클릭 → 삭제), 라이브러리 화면을 새로고침(Ctrl+Shift+R)한 뒤 [라이브러리 추가] → "교보문고에서 가져오기 준비"의 [교재 가져오기]를 다시 끌어다 놓는다. 즐겨찾기에는 만들 때의 코드가 저장되어, 다시 놓아야 고친 코드가 쓰인다.
- **확인**: 외국도서 한 권에서 가져와 붙여넣으면 ISBN과 표지가 채워진다.
