# v2.5.90 — 수업 관리 첫 화면 넘김·통합 시간표를 리포트와 같게

- 날짜: 2026-10-14
- 이전 버전: v2.5.89
- 요약: 운영 화면 확인에서 나온 세 가지를 고쳤다. ① 첫 화면에서 시간표로 넘길 때 리포트처럼 칸 단위로 넘어가지 않았다. ② 시간표 크기가 리포트 통합 시간표와 달랐다. ③ 반마다 다른 색 규칙이 지켜지지 않았다(모두 같은 베이지). 이름·아이콘도 리포트와 같은 "통합 시간표"로 맞췄다.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면만(Pages). 공용 토큰 추가(색 8쌍·글자 1개). 함수·Notion 변경 없음.

## 항목 1. 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`, `class_room.html`, `assets/hada-tokens.css`(반별 색 `--class-1~8-bg/fg`, `--text-micro` 11px), `assets/hada-ui.css`·관리 화면 4개(토큰 버전 표시만), `docs/DESIGN.md`
- **동작**
  - 첫 화면과 통합 시간표가 화면 높이 한 칸씩이고 위아래로 넘기면 칸 단위로 멈춘다(리포트 `.scroll-container`·`.snap-section`과 같은 방식). [통합 시간표 보기 ⌄]·[⌃ 이전으로]로도 오간다.
  - 제목 "통합 시간표"와 아이콘은 리포트와 같다. 카드 폭(화면 폭에 따라 300~820px)·안쪽 여백·칸 간격 6·요일 12px·수업 칸 11px·안쪽 6/4는 리포트 통합 시간표와 같고, 수업 칸은 누르면 그 수업으로 가는 버튼이라 높이만 44px.
  - 반 색: 리포트 8색. 반 카드 이모지가 🟣🔵🟢🟠🔴🟡🟤⚪ 중 하나면 그 색(카드 동그라미와 시간표 칸 색이 같음), 아니면 리포트와 같은 반 이름 해시.
- **검증(모의 데이터)**: 수업 관리 화면 흐름 검사 390·768·1280 — 넘김 칸 두 개(높이 = 화면, `y mandatory`·`start`), [통합 시간표 보기]·[이전으로], 제목, 수업 칸 11px·반 색(🟡 → 노랑, 🟢 → 초록, 서로 다름), 기존 흐름 전체. 관리자 설정·키오스크·법정 서류·학교 검색 화면 검사(토큰 추가 영향 없음), 디자인 규칙 검사, 회귀 가드.
- **미검증**: 실제 휴대폰(iOS 사파리·안드로이드)에서의 넘김 느낌, 운영 데이터 화면.
- **참고**: 학부모 리포트는 반 이름 해시만 쓰므로, Notion 클래스 이모지를 해시와 다른 색으로 정해 둔 반은 리포트 시간표 색과 수업 관리 시간표 색이 다를 수 있다(리포트는 이번에 바꾸지 않음).
- **실패 시 대처**: v2.5.89의 `class_room.js`·`class_room.html`로 되돌린다(추가한 토큰은 그대로 둬도 된다).
