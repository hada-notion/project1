## 항목 1. 화면 사용 확인

- **유형**: 운영자 직접(운영 AI는 확인 순서를 안내하고 결과를 기록)
- **선행 조건**: v2.6.2·v2.6.3
- **운영자 안내문**: 실제 학생 데이터에 쓰는 확인은 시험 반·시험 학생으로 한다. 학부모 실발송은 하지 않는다.
  1. **출결 키오스크**(태블릿): 로그인 화면이 나오면 지금 쓰는 관리자 키(웹훅 키와 같은 값)로 로그인 → 카드 아래 학원 이름 → 오른쪽 위 톱니 설정에서 체크 방식·마지막 동기화가 보인다. 시험 학생 번호로 등원 1회(알림톡이 실제로 가므로 시험 연락처로).
  2. **수업 관리**(`class_room.html`, 선생님 휴대폰): 로그인 → 강사 선택 → 담당 클래스 → 반 상세 [홈·교재·캘린더·학습기록·학생]. 시험 반에서 캘린더 날짜 → 출석 하나 바꿔 저장 → Notion 출석 페이지에 반영. [+ 기록 만들기]로 시험 기록 하나(범위 입력 시 단원이 보이는지).
  3. **학부모 리포트**: 학생 한 명 [학생 페이지 동기화] 뒤 홈·교재·캘린더·학습기록·보고서 탭, 달력 카드 오른쪽 아래 [월–일] 버튼.
  4. **라이브러리**: [라이브러리 열기]에 교재가 시리즈별로 보이고 교재를 누르면 단원이 보인다. 책 검색([라이브러리 추가])은 키를 넣은 뒤(v2.6.5 항목 2).
  5. **법정 서류·학교 검색**: 로그인 후 조회 한 번.
  6. **Notion 버튼**: [학생 페이지 동기화] 하나(발송·삭제 버튼은 누르지 않는다).
- **끝났는지 확인하는 방법**: 위 여섯 가지 결과를 운영 AI에게 알려 기록한다. 안 되는 것은 화면 캡처와 시각을 남긴다.

## 항목 2. 매뉴얼 갱신 (N-14)

- **유형**: AI 자동(운영 매뉴얼 페이지 수정, 운영 소유자 승인 범위)
- **무엇을**: [Notion 작업 목록 N-14](v2.6-노션-작업.md)의 목록대로 원본 메뉴얼 최신 문구에 맞춘다. 운영 고유 내용은 지키고, 원본 ID·주소는 복사하지 않는다. 바꾸기 전 문단 원문은 시스템 정보 이력에 남긴다.
- **꼭 들어가야 할 사용법 변화**
  - 출석 정기 동기화가 꺼졌다: 학부모 리포트는 보고서 발송 직전과 [학생 페이지 동기화]를 누를 때만 최신이 된다.
  - 관리 화면 상단 메뉴·⋯·휴대폰 ☰, 같은 탭 로그인 공유.
  - 키오스크 설정(톱니), 키보드 입력.
  - 수업 관리 사용법(새 화면).
  - 라이브러리 사용법(새 화면), 학습기록 `주제`·`단원`·[단원 입력]·쉼표 범위.
  - 수업 `보강`(보강 수업), 출석 `메모`(내부용)와 `선생님 한마디`(학부모에게 보임)의 차이.

## 항목 3. 원장님·선생님 안내

- **유형**: 운영자 직접
- **운영자 안내문**(학원 안에서 직접 안내, 비밀번호·키는 채팅·Notion에 적지 않는다)
  - 선생님: 수업 관리 주소(`<학원 Pages 주소>/class_room.html`)를 휴대폰 홈 화면에 추가. 로그인 값은 관리 화면과 같다. 출석 체크는 캘린더에서 날짜 → [학생 목록], 또는 홈의 등원 칸. 기록 만들기에서 범위를 넣으면 단원이 자동으로 골라지고 직접 고칠 수 있다. 보강은 보강 대기실에서 보강 수업을 만든다.
  - 원장님: 학부모 리포트는 발송 직전과 [학생 페이지 동기화] 때 최신이 된다. 일정의 숨김·학부모 공개를 바꾼 뒤에도 해당 학생 동기화가 필요하다(v2.5.11과 같음).
  - 모두: 학부모 리포트·수업 관리 달력 카드 오른쪽 아래 [월–일] 버튼으로 첫 요일을 바꿀 수 있다(기기마다 저장).
