## 항목 1. 법정 서류 조회 화면

- **유형**: AI 자동
- **선행 조건**: v2.5.41(공용 알림 줄 종류), v2.5.44(상단 메뉴)
- **대상 파일**: `legal_documents.html`
- **변경 내용**
  - 알림 줄: 제목 아래에 화면 공통 알림 줄을 두고 상태를 보여 준다. 로그인 안내·조회 중·조회 전 안내는 흰 바탕, 조회 완료 초록, 출력 전 확인 사항이 있으면 노랑, 조회 실패 빨강. [조회] 옆에 붙던 "✓ 조회 완료…" 글자는 없앴다. 로그인 오류는 지금처럼 입력 칸 아래 빨간 글자.
  - 필터: 시작일·종료일·클래스·학생·검색·[조회]를 한 줄로(1280). 1080px 이하는 3칸, 휴대폰은 한 칸씩이고 [조회]는 가로 꽉 참.
  - "출력 전 확인": 화면 전용 노란 상자 대신 공용 주의 상자(`.status.warn`). 인쇄·엑셀에는 지금처럼 들어가지 않는다(엑셀은 시트 아래 안내 그대로).
  - 인쇄(PDF)·Excel 다운로드와 출력 안내를 결과 카드 위쪽으로 옮겼다. 인쇄 화면에는 나오지 않는다.
  - 표 머리 정렬·필터 버튼: "⇅ ↑ ↓ •" 글자 대신 Feather 아이콘(chevron-down / arrow-up / arrow-down, 필터 중이면 filter 추가).
  - 휴대폰 서류 종류 탭: 4개를 2×2 같은 폭으로, 이름은 한 줄.
- **환경별 값 (중요)**: `legal_documents.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값을 유지**한다.
- **검증**: Pages 반영 후 로그인 → 조회 → 알림 줄 색(확인 사항 있으면 노랑, 없으면 초록), [조회] 위치, 결과 카드 위 인쇄·엑셀, 표 머리 아이콘을 본다. 인쇄 미리보기에 서식만 나오는지 본다.
- **실패 시 대처**: v2.5.44의 `legal_documents.html`로 되돌린다. 데이터 영향 없음.
