# v2.7.15 — 학습활동 탭을 대시보드(과제·평가·학습)로

- 날짜: 2026-10-20
- 이전 버전: v2.7.14
- 요약: 수업·출석·등록·보고서 페이지의 `학습활동` 탭을 리스트/갤러리 + `구분` 그룹에서 **대시보드 표 세 칸(과제 / 평가 / 학습)**으로 바꾼다. 칸마다 필요한 열만 보여 과제는 마감·상태, 평가는 문항·점수를 표로 본다. 학습활동 `평가점수값` 수식은 `점수`와 같은 값이라 지우고, `점수`는 빈값 처리 조건 없이 계산한다.
- 매뉴얼 영향: 없음(화면 모양만 바뀜)
- 변경 유형: Notion 화면(페이지 탭 4개)·수식 1개 수정·수식 1개 삭제. 코드·마이그레이션·Secrets 변경 없음. 원본 스캔 도구(`scripts/notion-scan.js`·`notion-spec.py`)는 대시보드를 정확히 읽도록 고쳤다(운영 적용 없음, 스캔할 때 최신본을 쓴다).

## 항목 1. 학습활동 탭 4개를 대시보드로

- **유형**: 운영자 직접(화면 작업, 원본 지원 브라우저로도 가능)
- **선행 조건**: 없음
- **최종 모양**: [노션-레이아웃.md](../기준/노션-레이아웃.md)의 수업·출석·등록·보고서 "대시보드 탭 `학습활동`". 공통 규칙은 [이름 규칙](../이름-규칙.md) 7장 4번.
  - 탭 `학습활동` = 대시보드. 공통 필터 "`○○`에 이 페이지 포함"(수업은 `수업`, 출석은 `출석`, 등록은 `등록`, 보고서는 `보고서`). 등록은 공통 필터에 `수업일` 지난 4주도 둔다.
  - 1줄 `과제` 표: 빠른 필터 `구분` = 과제. 2줄 `평가` 표: `구분` = 평가, `점수` 평균. 3줄 `학습` 표: `구분` = 학습. 각 칸의 열·정렬은 레이아웃 문서 그대로.
- **바꾸는 방법**: 그 DB 페이지 → 레이아웃 사용자 지정 → `학습활동` 탭을 두 번 눌러 보기 메뉴 → 레이아웃 → **대시보드**. 기존 보기가 첫 칸이 되므로 칸을 복제해 세 칸을 만들고, 칸 이름·빠른 필터 `구분`·보이는 열을 맞춘다. "이 페이지" 조건은 대시보드 공통 필터로 옮기고 칸 안에서는 지운다. [모든 페이지에 적용]으로 저장.
  - 리스트/갤러리에서 대시보드로 바꾸면 예전 보기의 필터·빠른 필터가 화면에 보이지 않는 값으로 남는다. 동작에는 쓰이지 않으며, 최신 스캔 도구는 이 값을 읽지 않는다.
- **바뀐 뒤 지문**: `수업(학원) DB / 탭 / 학습활동`, `출석(학원) DB / 탭 / 학습활동`, `등록(학원) DB / 탭 / 학습활동`, `보고서(학원) DB / 탭 / 학습활동` ([노션-지문.json](../기준/노션-지문.json)).
- **검증**: 최신 `scripts/notion-scan.js`로 스캔해 위 4개가 "같음". 수업·출석 페이지 하나씩 열어 칸마다 그 페이지의 활동만, 구분별로 나뉘어 보이는지 본다.

## 항목 2. 학습활동 `점수` 수식 바꾸기, `평가점수값` 지우기

- **유형**: 운영자 직접(커넥터로 수식을 바꿀 수 있으면 AI 자동)
- **선행 조건**: 항목 1(리스트 보기에서는 빈값 조건이 있어야 평가 줄에만 점수가 보였다)
- **학습활동(학원) DB `점수`**
  - 바꾸기 전: `if(empty(prop("전체 문항")) or prop("전체 문항") <= 0, empty(), prop("정답 문항") / prop("전체 문항") * 100)`
  - 바꾼 뒤: `prop("정답 문항") / prop("전체 문항") * 100`
  - 지문 항목: `학습활동(학원) DB / 수식 / 점수`
- **학습활동(학원) DB `평가점수값`**(수식, `if(prop("구분").first()=="평가", prop("점수"), 0)`)을 지운다. 다른 수식·롤업이 쓰지 않는다(원본에서 확인). 패널 숨김 목록에서도 빠진다(`학습활동(학원) DB / 레이아웃 / 패널`).
- **영향**: 문항 수를 아직 넣지 않은 평가의 `점수`가 빈값 대신 0(또는 계산 불가 값)으로 나올 수 있다. 등록 `대시보드` 탭의 `평가 현황` 차트 두 개(평균 `점수`)에 그 평가가 들어가 평균이 낮아질 수 있으니 평가를 만들면 문항 수를 바로 넣는다. 수업 `평가 결과`·출석 평가 요약은 `점수 > 0`·문항 수 조건을 쓰므로 바뀌지 않는다. 서버 함수는 `점수`를 읽지 않는다.
- **검증**: 재스캔에서 두 항목이 "같음", `평가점수값`이 "추가"(운영에만 있음)로 나오지 않는다.
