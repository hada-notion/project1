# v2.5.11 — 일정 숨김·학부모 공개 분리

기준: hada-notion/project1, main, f9be7fc327d752ef78fea811027dc2353199e5e1.
이전 버전: v2.5.10. 날짜: 2026-10-08. 변경 유형: 스키마·코드·매뉴얼.
배포·Notion 적용·실사용 검증은 각 운영에서 실제 결과를 확인해 기록한다. 파일의 버전명만으로 운영 적용 완료를 의미하지 않는다.
정확한 변경 전·후 원문은 같은 버전의 `docs/updates/v2.5.11-code.patch`를 사용한다.

## 변경 범위
- 일정 DB에 checkbox `학부모 공개` 추가, 기본 해제. 기존 숨김/관계/메모/업무 데이터 보존.
- 신규 NEIS 일정 생성에만 숨김=true, 학부모 공개=false. 기존 일정 업데이트는 두 값 모두 보존.
- 학생 리포트 일정은 숨김=false, 학부모 공개=true인 학원 일정/학사 일정/휴원만 캐시에 저장. 날짜·학생/클래스/학교/학년 관련성 규칙 유지.
- 정책값 없는 기존 캐시의 일정은 공개 API에서 빈 목록으로 반환. 학생 프로필·수업·출석 등 다른 데이터는 유지.
- 숨김은 표시 여부에만 관여하며 휴원·수업 생성 제외 로직은 변경하지 않음.
- 신규 Secret, 마이그레이션, 토큰 재발급, 발송, 기존 일정 일괄 수정 없음.

## 적용 순서
1. 실제 수정할 저장소·브랜치와 쓰기 권한 확인. 운영 환경이면 이 패치를 운영 저장소에 적용한다. 원본 저장소에 반영하려면 배포 담당자의 원본 변경 승인을 확인한다.
2. 일정 DB의 checkbox `학부모 공개` 존재, `숨김` checkbox 유지, 기본 템플릿의 학부모 공개 해제를 확인한다. 내부 캘린더에는 숨김=false 필터, 전체 학사일정 보기에는 숨김 필터를 넣지 않는다.
3. 기준 커밋과 실제 코드가 다르면 정확한 패치 원문을 먼저 비교한다. `git apply --check docs/updates/v2.5.11-code.patch` 성공 후에만 적용한다.
4. 기존 CI의 104개 테스트·전체 함수 타입검사·회귀 가드 실행. 승인된 기존 GitHub/Supabase 배포 경로 사용. 실제 반영 커밋 및 CI 결과를 기록한다.
5. 기존 일정은 자동으로 공개하지 않는다. 운영자가 필요한 일정만 숨김 해제/학부모 공개 체크한다. 직원회의·청소는 숨김 해제/공개 해제.
6. 새 공개 API는 정책 없는 기존 캐시 일정을 비공개 처리한다. 공개 일정 재표시를 위해 해당 등록의 학생 페이지 동기화를 실행하고 화면을 새로고침한다. 관련 학생이 여러 명이면 영향받는 등록 모두 갱신한다.
7. 숨김·학부모 공개를 편집한 이후에도 해당 등록의 동기화와 학부모 화면 새로고침이 필요하다. 이 패치는 일정 편집 자동화/즉시 캐시 무효화를 새로 만들지 않는다. 이미 열린 브라우저에 받은 데이터는 원격 회수할 수 없다.
8. 신규 학사일정 기본값·재동기화 값 보존·직원회의 제외·공개 행사 표시·학교/학년 관련성·공개 해제 후 재동기화 제거를 실제 환경에서 검수한다. 학생 대상 알림톡 발송은 테스트에 포함하지 않는다.
9. 검수·배포 완료 후 시스템 정보/사용 매뉴얼의 배포 대기 경고를 제거하고 실제 결과를 기록한다. Notion 부분 적용을 코드 배포 완료로 기록하지 않는다.

## 실패·복구
- 패치 적용/타입검사/CI 실패 시 배포 중단. 원문 불일치를 임의 치환하지 않는다.
- 실행 코드 복구 시 기준 커밋의 변경 대상 파일로 되돌린 뒤 기존 배포 경로로 재배포한다. 구버전 API는 공개 정책을 적용하지 않으므로 비공개 일정 재노출 위험을 별도로 검토한다.
- 새 속성을 삭제하면 선택해 둔 공개 값이 유실되므로 자동 삭제하지 않는다. 기존 일정 데이터는 변경하지 않았으므로 업무 데이터 복원은 해당 없음.

## 로컬 검증
- 104개 테스트 통과(NEIS/일정 공개 28개 및 기존 CI 76개).
- 실제 Notion 쓰기·출결·학부모 발송 없이 모의 입력으로 검증.
- 배포된 함수 원문 직접 비교, 실제 학교 버튼, 학부모 HTML 및 다른 운영 적용은 별도 검증 대상.

## Notion 사용 안내 최종 문구(코드 배포 확인 후)

- `숨김`을 체크하면 내부 운영 캘린더와 학부모 리포트에서 제외합니다. 전체 학사일정 보기에는 원본을 유지합니다.
- 학부모 리포트에는 숨김 해제·학부모 공개 체크된 학원 일정/학사 일정/휴원 중 해당 학생과 관련된 일정만 표시합니다. 할일은 공개하지 않습니다.
- 직원회의·청소는 학원 일정으로 유지하고 숨김 해제/학부모 공개 해제로 관리합니다.
- 학사일정은 처음 가져올 때 숨김 체크/학부모 공개 해제로 생성합니다. 필요한 일정만 숨김을 해제하고 안내할 일정만 공개를 체크합니다. 재동기화는 두 값을 보존합니다.
- 공개 여부를 변경하면 관련 등록별 학생 페이지 동기화 후 학부모 화면을 새로고침합니다. 자동·즉시 반영으로 안내하지 않습니다.
- 숨김은 표시 여부만 바꾸며 휴원·수업 생성 제외 조건은 유지합니다.
