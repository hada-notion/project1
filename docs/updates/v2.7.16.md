- 날짜: 2026-10-21
- 이전 버전: v2.7.15
- 요약: 학부모 리포트 일일 보고서의 "최근 평가 추이"가 평가 한 건마다 점을 찍어, 같은 날 평가가 두 번이면 같은 날짜(예: 10.21)가 두 번 나왔다. 이제 날짜별로 묶어 그날 점수(정답 ÷ 전체 문항)의 평균 한 점을 찍고, 평가가 있던 최근 3일을 보여 준다. 점을 누르면 그날 평가가 모두 나온다. 주간·월간 보고서의 추이(기간 평균)는 그대로다.
