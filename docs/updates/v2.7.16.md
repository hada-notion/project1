# v2.7.16 — 일일 보고서: 평가 추이 하루 평균, 지난·이번 과제 겹침 수정

- 날짜: 2026-10-21
- 이전 버전: v2.7.15
- 요약: 학부모 리포트 일일 보고서의 "최근 평가 추이"가 평가 한 건마다 점을 찍어, 같은 날 평가가 두 번이면 같은 날짜(예: 10.21)가 두 번 나왔다. 이제 날짜별로 묶어 그날 점수(정답 ÷ 전체 문항)의 평균 한 점을 찍고, 평가가 있던 최근 3일을 보여 준다. 점을 누르면 그날 평가가 모두 나온다. 주간·월간 보고서의 추이(기간 평균)는 그대로다. 또 과제 마감 값에 시각이 붙어 있어(`2026-10-21T17:00…`) 이날 마감인 과제가 "지난 과제"와 "이번 과제"에 함께 나오던 것과, 주간·월간 과제 목록 창에서 기간 마지막 날 마감 과제가 빠지던 것을 고친다.
- 매뉴얼 영향: 없음
- 변경 유형: 학부모 리포트 화면 스크립트 2개와 그 버전 표시. Edge Function·마이그레이션·Secrets·Notion 변경 없음.

  - 찾을 원문 (앵커): `student_report_part2.js`의 `function computeRecentTestPoints` 위 주석 "일일 보고서: 최근 평가가 있던 날 count일", `function findNextHomeworkItems` 안 `const day = (v) => String(v || "").slice(0, 10)`. 둘 다 있으면 적용된 것이다.
