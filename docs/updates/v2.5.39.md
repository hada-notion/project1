# v2.5.39 — 키오스크 설정(체크 방식·지금 동기화·로그아웃)과 오늘 준비 보완

- 날짜: 2026-10-12
- 이전 버전: v2.5.38
- 요약: 키오스크 오른쪽 위 로그아웃 아이콘을 **설정(톱니)**으로 바꾼다. 설정에서 등하원 체크 방식(1일 1회 / 매번 기록)을 고르고, 마지막 출석 동기화 시각을 보고 **지금 동기화**할 수 있으며, 로그아웃한다. 체크 방식 변경과 지금 동기화는 관리자 비밀번호를 한 번 더 확인한다. 두 방식 모두 같은 버튼을 2분 안에 다시 누르면 무시한다. 오늘 준비 표가 Notion과 어긋나 "이미 처리"로 막히던 문제와, 처리 중 Enter로 두 번 처리될 수 있던 문제를 고쳤다.
- 매뉴얼 영향: 있음 → 키오스크 사용법에 "설정(톱니): 체크 방식·지금 동기화·로그아웃"을 추가한다(항목 3).
- 변경 유형: Supabase 함수(`kiosk-checkin`, `list-students`), 공용 모듈, 웹 화면. 마이그레이션·Secrets·Notion 변경 없음.

## 항목 1. 서버

- **유형**: AI 자동
- **선행 조건**: v2.5.37 적용(오늘 출석 준비 표)
- **대상 파일**: 신규 `supabase/functions/_shared/kioskPolicy.ts`(+ `_test.ts`), `supabase/functions/_shared/afterResponse.ts`. 수정 `supabase/functions/kiosk-checkin/index.ts`, `supabase/functions/list-students/index.ts`, `supabase/functions/_shared/kioskToday.ts`, `.github/workflows/deploy-supabase-functions.yml`(테스트 추가)
- **변경 내용**
  - `kiosk-checkin`: 요청 `mode`(once/every, 기본 once)에 따라 이미 찍힌 스템프를 처리한다. once는 덮어쓰지 않고 "이미 처리", every는 새 시각으로 덮어쓰고 알림톡. 두 방식 모두 같은 버튼 2분 안 재입력은 `recent`로 무시(알림톡 없음). 바꿀 때는 `_shared/kioskPolicy.ts`만 고친다.
  - once에서 준비 표가 "이미 처리"라고 하면 Notion 출석 페이지를 한 번 더 읽어 확인한다(Notion에서 스템프를 지웠으면 다시 기록).
  - 어느 경로(준비 표/Notion 직접)로 기록하든 오늘 준비 표의 시각·출석 페이지를 함께 맞춘다. 새로 만든 보강 출석도 다음부터 빠른 경로로 처리된다.
  - `list-students?kiosk=1&sync=1`: 키오스크 설정의 "지금 동기화". 응답 전에 오늘 준비를 다시 만든다(1분 안에 이미 했으면 생략). 키오스크 세션으로 부를 수 있는 기존 경로라 권한 범위는 그대로다.
  - 정리: 응답 뒤 처리 공용화(`afterResponse.ts`), 날짜 계산 통일(`kstDate`), 수강 중 상태 공용 상수, 쓰이지 않는 함수 제거, "학생 목록 변경" 응답 하나로.
- **환경별 값**: 없음

## 항목 2. 키오스크 화면

- **유형**: AI 자동
- **선행 조건**: 항목 1
- **대상 파일**: `attendance_kiosk.html`
- **변경 내용**
  - 오른쪽 위 아이콘: 로그아웃 → 설정(톱니). 설정 창: 등하원 체크 방식(1일 1회/매번 기록, 이 기기에 저장, 기본 1일 1회), 출석 동기화(마지막 시각, 지금 동기화), 로그아웃(확인창).
  - 체크 방식 변경·지금 동기화는 관리자 비밀번호 확인 후(설정 창을 닫으면 다시 확인). 보안 모드에서는 확인과 함께 키오스크 세션을 새로 받는다.
  - 등원·하원 요청에 체크 방식을 함께 보낸다. 2분 안 재입력은 "방금 HH:mm에 등원 처리되었습니다"로 안내.
  - 처리 중이거나 설정 창이 열려 있으면 키보드 입력을 받지 않는다(처리 중 Enter로 두 번 처리되지 않게).
  - "출석 동기화 중"일 때 30초 뒤 자동 재확인은 한 번만.
- **환경별 값 (중요)**: `attendance_kiosk.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값을 유지**한다.
- **검증**:
  1. 키오스크에서 톱니를 눌러 설정 창이 열리는지, 체크 방식을 바꾸려 하면 비밀번호를 묻는지 본다.
  2. "매번 기록"에서 같은 학생 등원을 2분 지나 다시 누르면 새로 기록·알림, 2분 안이면 "방금" 안내인지 본다.
  3. Notion에서 등원 스템프를 지운 뒤(1일 1회) 다시 등원하면 기록되는지, "지금 동기화" 후 시각이 바뀌는지 본다.
- **실패 시 대처**: v2.5.38의 `attendance_kiosk.html`과 v2.5.37의 함수로 되돌린다. 출결 데이터 영향 없음.
