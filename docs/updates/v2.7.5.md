## 항목 1. 수업 `학습기록 계획` 수식 2곳 고치기

- **유형**: 운영자 직접
- **선행 조건**: v2.7.1 N-11(`학습기록 계획` 추가)을 이미 했을 때만. 아직 안 했으면 이 항목은 건너뛰고, 고쳐진 `docs/updates/v2.7-노션-작업.md` N-11 원문을 그대로 넣는다.
- **변경 이유·증상**: 오늘 학습이 체크된 진도교재가 있어도 `학습기록 계획`이 `{"v":1,"items":[]}`로 나오고, [학습기록 생성]을 눌러도 학습기록이 생기지 않는다. 원인은 `replaceAll("[\"\\]", "")`의 정규식이 Notion에서 닫히지 않은 문자 묶음으로 읽혀, 클래스·교재 이름과 상관없이 오류가 나는 것이다.
- **Notion 변경**: 수업(학원) DB 수식 속성 `학습기록 계획`
  - 찾을 원문(2곳, `cls` 줄과 `"t"` 줄):

    ```
    .replaceAll("[\"\\]", "")
    ```

  - 바꿀 원문(2곳 모두):

    ```
    .replaceAll("[\"\\\\]", "")
    ```

  - 나머지 글자는 그대로 둔다. 바꾼 뒤의 전체 원문은 `docs/updates/v2.7-노션-작업.md` N-11과 같다.
- **운영자 안내문**
  - 왜 필요한가: 이 수식이 비어 있으면 [학습기록 생성]이 아무것도 만들지 않는다.
  - 어디서: 수업(학원) DB → 아무 수업 페이지 → 숨긴 속성 `학습기록 계획` → 속성 편집 → 수식 편집
  - 무엇을:
    1. 수식에서 `"[\"\\]"`를 찾아 `"[\"\\\\]"`로 바꾼다(역슬래시 2개 → 4개). 두 군데다.
    2. 창을 닫아 저장한다.
  - 끝났는지 확인하는 방법: 오늘 학습이 체크된 진도교재가 있는 수업에서 `학습기록 계획`에 `"t":"[학습] 교재명(반) 날짜"`가 나온다.
  - 흔한 오류와 대처: 수식 편집기에 붙여 넣을 때 역슬래시 개수가 바뀌지 않았는지 다시 연다. "replaceAll 호출 중 오류"가 보이면 아직 2개다.
- **검증**:
  1. 수식 미리보기에 오류가 없고, 위 확인 방법대로 `items`에 교재가 나온다.
  2. 테스트 수업에서 [학습기록 생성] → 학습기록이 생기고, 그 기록의 [학습활동 생성] → 학생 수만큼 학습활동이 생긴다.
- **실패 시 대처**: 바꾸기 전 수식으로 되돌리면 이전과 같은 상태(학습기록이 안 만들어짐)다. 데이터에는 영향이 없다.
- **매뉴얼**: 변경 없음
