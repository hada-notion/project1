## 항목 1. 공용 디자인 파일과 관리자 설정 화면

- **유형**: AI 자동
- **선행 조건**: 운영 소유자의 전체 계획 승인. v2.5.14 적용(관리자 설정 화면이 같은 버전이어야 한다).
- **대상 파일** (원본에서 그대로 가져온다)
  - 신규: `assets/hada-ui.css`(토큰·공용 부품), `assets/brand/hada-wordmark.png`(HADA 로고), `docs/DESIGN.md`(규칙), `tests/design-lint.cjs`(디자인 규칙 검사)
  - 수정: `admin_settings.html`(공용 스타일 사용, 상단 로고, 대시보드 두 칸, 모든 화면 같은 폭), `admin_settings.js`(폼 화면 가운데 정렬 표시만)
- **변경 내용**
  - 모든 화면의 바깥 폭을 같게 하고, 대시보드는 관리자 비밀번호 | Notion 웹훅 키 두 칸(좁은 화면에서 위아래)으로 보여 준다. 로그인·변경 폼은 가운데 정렬.
  - 상단 "하다 학원관리" 앞에 HADA 로고.
  - 색·글자·간격은 `assets/hada-ui.css` 토큰만 사용. 화면 HTML에 `style="..."` 속성을 두지 않는다.
  - Content-Security-Policy에 `style-src 'self'`(공용 스타일 파일)와 `img-src 'self'`(로고·안내 이미지)가 포함된다. 원본 파일 그대로 쓰면 된다.
- **환경별 값**: 없음(`admin_config.json`은 바꾸지 않는다).
- **검증**:
  1. `node tests/design-lint.cjs` 통과.
  2. Pages 반영 후 관리자 설정에 로그인해 로고, 두 칸 대시보드, 웹훅 키 교체 화면이 보이는지 확인한다.
- **실패 시 대처**: 이전 버전의 `admin_settings.html`·`admin_settings.js`로 되돌리면 된다. 서버·데이터 영향 없음.

## 항목 2. 출결 키오스크 화면

- **유형**: AI 자동
- **선행 조건**: 항목 1(공용 스타일·로고 파일이 있어야 한다).
- **대상 파일**: `attendance_kiosk.html`
- **변경 내용**
  - 공용 디자인 사용: 등원 = 갈색 주 버튼, 하원 = 흰 보조 버튼, 결과 표시는 상태색 토큰, 화면 위와 로그인 카드에 HADA 로고, 등원·하원·로그인 중 회전 표시와 "확인 중…".
  - 화면 크기에 맞춰 카드 전체가 커지는 방식은 그대로(`<html class="device">`).
  - **어두운 모드 제거**: 기기가 다크 모드여도 밝은 화면으로 보인다(브랜드는 밝은 테마 하나).
  - 학생 찾기·같은 번호 학생 선택·출석 처리·로그인 로직은 바꾸지 않았다. 화면 전환만 `style.display` 대신 `hidden` 속성을 쓴다.
- **환경별 값 (중요)**: 이 파일 안의 `SUPABASE_URL`과 `SUPABASE_ANON_KEY`는 **운영 값을 유지**한다. 원본 파일을 통째로 덮어쓰면 원본 주소로 바뀌므로, 원본 파일을 가져온 뒤 두 줄만 운영의 기존 값으로 되돌리거나 `scripts/setup-new-academy.py`의 치환 규칙을 다시 적용한다. 적용 후 두 값이 운영 값인지 원문 비교로 확인한다.
- **검증**:
  1. `node tests/design-lint.cjs` 통과.
  2. 키오스크 기기(태블릿)에서 새로고침 → 로그인 → 번호 입력 화면이 화면 안에 다 들어오는지 확인한다.
  3. 실제 등원 처리는 운영 소유자가 정한 시험용 번호로만 한다(학부모 알림이 발송된다). 시험이 어려우면 화면 확인까지만 하고 보고한다.
- **실패 시 대처**: 이전 버전의 `attendance_kiosk.html`로 되돌린다(운영 값 유지 확인). 서버·데이터 영향 없음.
