# v2.4 — 시험범위(학원) DB를 시험정보(학원) DB로 명칭 변경

- 날짜: 2026-10-04
- 이전 버전: v2.3.1
- 요약: "시험범위(학원) DB"가 실제로는 시험 연결·응시 학생·상태 등 범위 밖의 정보까지 관리한다는 점을 반영해, DB 이름을 "시험정보(학원) DB"로 바꿨습니다. 코드·스키마·속성·버튼 동작 변경은 없습니다. (※ 이 변경은 원래 v2.2로 배포됐으나, 이후 v2.2 번호가 업데이트 진행 방식 개선 패치로 재사용되면서 지침이 누락되어 v2.4로 다시 배포합니다. 원본 워크스페이스에는 이미 적용되어 있으며, 아직 이 명칭 변경을 받지 못한 운영 워크스페이스만 대상입니다.)
- 매뉴얼 영향: 있음 → 아래 "매뉴얼" 항목 참고
- 유형: 전 항목 **AI 자동**

> 작성 규칙은 `docs/updates/_TEMPLATE.md` 참고.

## 항목 1. 시험범위(학원) DB 명칭 변경

- **유형**: AI 자동
- **선행 조건**: 없음
- **변경 이유·증상**: "시험범위"라는 이름이 이 DB가 실제로 관리하는 내용(시험 연결, 학교·학년·과목·단원목록, 시험일, 응시학생 등록 버튼·현황, 상태)을 정확히 설명하지 못함.
- **대상 Notion**
  - DB 역할: 시험 일정(시험 DB)과 연결되어 학교·학년·과목·단원목록·시험일을 가지고, "응시학생 등록" 버튼으로 성적(DB) 행을 생성하는 DB. 현재 이름이 "시험범위(학원) DB".
  - 식별 방법: "시험" DB와 관계가 있고, "응시학생 등록"·"시험일정 추가" 버튼이 있으며, "상태"/"처리 시작 시각"/"마지막 오류"/"실시간 처리 상태" 속성을 가진 DB를 찾는다. 이미 "시험정보(학원) DB"라는 이름이면 이 항목은 건너뛴다(이미 적용됨).
- **변경 내용 (찾을 원문 → 바꿀 원문)**

  ```
  데이터베이스 이름: 시험범위(학원) DB → 시험정보(학원) DB
  데이터소스 이름: 시험범위(학원) DB → 시험정보(학원) DB
  ```

  속성명, 버튼명, 관계, 수식, 선택지 옵션은 변경하지 않는다.

- **환경별 값**: 없음
- **필요한 Secret (이름만)**: 없음
- **마이그레이션 / 재배포**: 없음
- **검증**:
  1. 대상 DB와 데이터소스 이름이 "시험정보(학원) DB"로 바뀌었는지 확인한다.
  2. 속성·버튼·관계·수식이 변경 전과 동일한지 확인한다 (이름만 바뀐 것이므로 멘션·링크는 자동으로 새 이름을 따라간다).
- **실패 시 대처**: 이름을 "시험범위(학원) DB"로 되돌리면 원상복구된다.
- **매뉴얼**: 운영 메뉴얼에서 이 DB 이름을 직접 텍스트로 언급하는 곳을 "시험정보(학원) DB"로 갱신한다 (멘션은 자동 반영되므로 제외).
  - "시스템 운영(큐·예약 실행·문제 해결)" 페이지의 상태값 표: `시험범위(학원) DB — 상태` → `시험정보(학원) DB — 상태`
  - "구조도" 페이지 mermaid 다이어그램의 `시험범위` 노드 라벨 → `시험정보`
  - "버튼 → Edge Function 웹훅 매핑" 페이지 요약표의 `시험범위(학원)` → `시험정보(학원)`
  - "공개 DB" 페이지의 "시험" 분류 설명 문구에 "시험정보(시험범위·응시 학생)"처럼 보완 설명을 추가해도 좋다 (선택).
