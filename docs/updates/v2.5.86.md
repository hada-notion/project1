# v2.5.86 — 학부모 리포트 뒤로가기

- 날짜: 2026-10-14
- 이전 버전: v2.5.85
- 요약: 학부모님은 알림톡 링크로 리포트에 들어온다. 리포트는 한 페이지 안에서 화면만 바꿔 그리기 때문에 뒤로가기를 누르면 리포트에서 나가 카카오톡으로 돌아가 버렸다. 수업 관리(v2.5.85)와 같은 규칙으로, 방문 기록(History API)에 동작을 남겨 직전 동작으로 돌아가게 했다.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면만(Pages). 함수·Notion 변경 없음.

---

## 항목 1. 화면

- **유형**: AI 자동
- **대상 파일**: `student_report_part2.js`(끝에 "뒤로가기" 블록 추가), `student_report.html`(스크립트 버전 표시만), `docs/DESIGN.md`
- **동작**

  | 상황 | 뒤로가기 |
  |---|---|
  | 메뉴·일정·시험·과제 창, 기간 고르기, 사진 크게 보기 | 창만 닫힘 |
  | 교재 상세 | 등록 상세(보던 탭) |
  | 캘린더에서 날짜를 골라 접힘 | 월 보기로 펼침 |
  | 등록 상세의 홈이 아닌 탭 | 홈 탭(탭을 여러 번 오가도 한 번) |
  | 등록 상세 홈 탭 | 첫 화면(학생 소개) |
  | 첫 화면 | 리포트에서 나감(원래대로) |

  - 창을 ✕나 바깥 누르기로 닫아도 방문 기록을 맞춘다. 메뉴에서 다른 등록을 고르면 메뉴 칸이 그 화면 칸이 된다(뒤로 한 번에 첫 화면).
  - 앞으로 가기는 무시한다. 주소는 바꾸지 않는다(링크 토큰·새로고침 동작 그대로).
  - 학부모 리포트는 요청한 부분만 고친다: 기존 함수 본문은 그대로 두고, 열고 닫는 함수와 `renderApp`을 감싸는 블록만 더했다.
- **검증(모의 데이터)**: 리포트 뒤로가기 검사 390·1280 — 홈 → 첫 화면, 탭 세 번 이동 후 뒤로 한 번 홈, 캘린더 날짜 접힘 → 월 보기, 교재 상세 → 교재 탭, 메뉴·기간 고르기·사진·일정·시험·과제 창 닫힘, ✕로 메뉴를 닫은 뒤에도 뒤로가 한 단계씩, 첫 화면 메뉴에서 등록 선택 → 뒤로 한 번 첫 화면, 앞으로 가기 무시, 페이지 유지. 기존 리포트 화면 검사(390·768·1280·가로 812), 디자인 규칙 검사, 회귀 가드.
- **미검증**: 실제 휴대폰(카카오톡 안 브라우저, 안드로이드 뒤로 버튼, iOS 사파리 밀어서 뒤로)에서의 동작.
- **실패 시 대처**: `student_report_part2.js` 끝의 "뒤로가기 (v2.5.86)" 블록을 지우면 이전과 같다.
