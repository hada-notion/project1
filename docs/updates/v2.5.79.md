# v2.5.79 — 수업방 화면 구조(상단 수업 선택·날짜 이동, 하단 + 기록 만들기)

- 날짜: 2026-10-13
- 이전 버전: v2.5.78
- 요약: 수업방을 Threads처럼 "지금 수업 한 화면"으로 바꿨다. 상단 바는 [≡ 수업 선택 | 가운데 클래스 이모지·이름과 날짜·시간 | 📅 날짜 이동], 하단 탭은 [학생 목록 | + 기록 만들기 | 학습기록]이다. 따로 있던 수업 목록 화면과 탭은 없앴다. 처음 열면 오늘 수업 중 지금 진행 중인 수업(없으면 다음 수업, 그것도 없으면 마지막 수업)이 바로 열리고, 오늘 수업이 없으면 안내만 보인다. ≡ 창에서 다른 날·다른 수업, 보강 대기실, 강사 바꾸기를 고른다. 📅는 이 반의 수업 날만 칠한 날짜 이동 캘린더다(‹ › 직전·다음 수업, [오늘], 월 전체 보기). + 기록 만들기는 한 장에서 구분·클래스·교재·주제·범위·내용을 적고 만든 뒤 바로 기록 화면으로 간다.
- 매뉴얼 영향: 수업방 매뉴얼 작성 때 새 화면 구조(≡ · 📅 · +) 설명
- 변경 유형: 함수 + 웹 화면. Notion 변경 없음.

## 항목 1. 함수 `class-room`

- **유형**: AI 자동(병합 시 자동 배포)
- **대상 파일**: `supabase/functions/_shared/classRoom.ts`, `supabase/functions/_shared/classRoom_test.ts`
- **바뀐 점**:
  - `class-sessions`(새): 수업 하나를 받아 같은 반의 앞뒤 수업(기준일 9주 전 ~ 5주 뒤, 보강 수업 제외, 최대 90개)을 돌려준다. `around`(YYYY-MM-DD)를 주면 그 날짜를 기준으로 읽는다(월 전체 보기에서 다른 달로 갈 때). 수업별 출석 요약도 함께 돌려주지만 화면은 쓰지 않는다. 반이 없는 보강 수업은 빈 목록.
  - `create-records`: `range`(200자)·`content`(2000자)를 받아 새로 만든 기록에만 범위·내용을 넣는다(이미 있는 기록은 그대로). 글자가 아니면 400.
  - `session`: 수업 응답에 클래스 이모지(`classEmoji`)를 더했다(상단 바 가운데 제목).
- **검증**: `deno check`, Deno 테스트 191개(수업방 15개: 같은 반·보강 제외·출석 요약·`around` 형식 오류 400·범위 밖 빈 목록, 범위·내용 저장과 글자가 아닌 값 400, 클래스 이모지).

## 항목 2. 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`, `class_room.html`, `student_report.html`(캘린더 주 한 줄 비율 한 줄 삭제 — 월 규칙을 따름), `docs/DESIGN.md`
- **바뀐 점**:
  - 상단 바 [≡ | 클래스 이모지·이름 / 날짜·시간 | 📅]. 학생 공간·기록 카드는 기존 ← 경로 그대로. 수업 페이지 ↗는 학생 목록·학습기록 제목 줄 오른쪽으로 옮겼다.
  - 하단 탭 [학생 목록 | + 기록 만들기 | 학습기록]. 오늘 수업이 없는 화면에서는 학생 목록·학습기록을 누를 수 없고 +는 "Notion에서 수업 페이지를 먼저 만들어 주세요" 안내만 한다.
  - ≡ 수업 선택 창: 주 한 줄(내 수업 있는 날 칠함, ‹ › 주, [오늘]) → 그날 수업(지금 진행 중이면 "지금", 등원 n/전체, 시간) → 보강 대기실 → 강사 바꾸기.
  - 📅 날짜 이동: 이 반 수업 날은 칠하고 보고 있는 날은 진하게, 오늘은 빨간 테두리, 다른 날은 흐리게·비활성. ‹ › 직전·다음 수업, [오늘], 월 전체 보기 ↔ 주로 접기. 보던 탭은 그대로.
  - + 기록 만들기 한 장: 구분 · 클래스(보고 있는 날짜의 내 수업) · 교재(진행 중 교재: 반 교재 / 개별 "n명 모두"·학생 한 명 / 학생별 / 교재 없이) · 주제(교재 없이는 필수) · 범위 · 내용. 오늘이 아닌 날이면 "오늘 수업이 아닙니다. ○/○ 수업으로 기록을 만들까요?"를 묻는다. 만든 기록이 하나면 바로 그 기록 화면, 여럿이면 학습기록 목록.
  - 수업을 옮길 때 교재 목록을 수업마다 새로 읽는다(전에는 처음 연 수업의 교재가 남을 수 있었다).
  - 알림이 화면 반 폭으로 줄어 여러 줄로 깨지던 것을 글자 폭만큼 넓혔다(수업방만).
- **검증(모의 데이터)**: 수업방 화면 흐름 검사 390·768·1280(오늘 수업 없는 강사 안내·비활성·+ 안내, ≡ 창 강사 바꾸기 후 오늘 수업 바로 열림, ≡ 창 주 이동·오늘·수업 고르기, 📅 칠한 칸·출석 숫자 없음·‹ 직전 수업에서 학습기록 탭 유지·오늘이 아닌 날 확인 문구·월 전체 ↔ 주로 접기·› 복귀, 출석·과제 검사 편집 저장, 학생 공간, + 기록 만들기(개별 교재 2명 모두·범위 전달, 교재 없이 주제 필수 오류 후 생성), 점수 저장, ≡ 창 보강 대기실·보강 수업 만들기, 가로 넘침·글자 잘림·버튼 44px), 디자인 규칙 검사, 회귀 가드, `git diff --check`.
- **미검증**: 실제 Notion 데이터로 첫 화면 수업 고르기(진행 중·다음·마지막), ≡ 창과 📅 날짜, 기록 만들기 범위·내용 저장. 실제 휴대폰 화면.
- **실패 시 대처**: v2.5.78의 `class_room.js`·`class_room.html`로 되돌린다. 함수는 조회와 선택 입력만 더했으므로 그대로 두어도 된다.
