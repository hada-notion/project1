## 항목 1. 검색·목차·표지 출처 바꾸기

- **유형**: AI 자동(`main` 병합 시 함수·Pages 반영)
- **대상 파일**: `supabase/functions/_shared/bookSources.ts`(새 파일), `supabase/functions/_shared/textbookSearch.ts`, `supabase/functions/_shared/textbookSearch_test.ts`, `supabase/functions/_shared/textbookToc.ts`(주석), `supabase/functions/textbook-api/index.ts`(주석), `library.html`, `assets/hada-shortcuts.js`(설명 문구), `docs/DESIGN.md`, `docs/새-학원-이식-체크리스트.md`
- **동작**:
  - 검색: 교재명이면 국립중앙도서관(제목)과 카카오(제목)를 함께 찾아 한 목록으로. 같은 ISBN13은 한 번만, 값은 국립중앙도서관 우선(빈 칸만 카카오로). ISBN13이면 두 곳에서 그 책 한 권. 한쪽이 실패해도 다른 쪽 결과는 보여 준다.
  - 목차: 국립중앙도서관 목차(`BOOK_TB_CNT`)가 있으면 지금 규칙(`1-1.` / `1.`)대로 단원을 나눈다. 없으면 창에 "목차를 가져오지 못했어요" 안내와 [교보문고에서 보기](ISBN 검색, 새 탭)를 보여 주고, 목차를 복사해 붙여넣거나 [단원 추가]로 넣는다.
  - 북커버: 교보문고 ISBN 주소(메뉴얼 7-6 규칙) → 안 열리면 국립중앙도서관 표지·카카오 표지(https) → 그것도 없으면 넣지 않는다. 화면에 보인 표지를 그대로 넣는다.
  - [직접 추가]는 v2.5.119와 같다.
  - 키 값은 로그·응답에 쓰지 않는다. 키가 하나도 없으면 "책 검색 키가 없습니다" 503.
- **검증(모의 데이터)**: 함수 테스트 12개(두 출처 합치기·국립중앙도서관 우선·표지 순서·목차 유무·키 없음/한쪽 키·한쪽 출처 실패·표지 선택 등록), 전체 테스트·타입 검사·회귀 가드·디자인 검사, 라이브러리 UI 검사 6개 크기(표지 대체, 목차 없음 → 교보문고 링크, 등록 시 표지 선택 전송).
- **미검증**: 실제 국립중앙도서관 응답 모양(키 승인 대기 중, JSON `docs` 배열로 가정)과 목차 글 형식, 국립중앙도서관 표지 주소의 https 열림, 실제 카카오 응답, 실제 Notion 등록.
- **실패 시 대처**: 키를 넣은 뒤 검색이 안 되면 함수 로그의 "국립중앙도서관 오류"·"카카오 응답 오류" 문구를 확인한다. 되돌릴 때는 v2.5.119 파일로 되돌리되, 알라딘은 2026-10-30 이후 동작하지 않는다.

## 항목 2. 키 넣기

- **유형**: 운영자 직접(학원마다 따로 발급, 원본 키를 나눠 쓰지 않음)
- **순서**:
  1. 국립중앙도서관(nl.go.kr) 회원가입 → ISBN 서지정보 Open API 사용 신청 → 승인(1~2 영업일) 후 인증키 확인.
  2. 카카오 디벨로퍼스(developers.kakao.com)에서 앱을 만들고 REST API 키 확인(책 검색은 별도 심사 없음).
  3. Supabase → Edge Functions → Secrets에 `NL_CERT_KEY`, `KAKAO_REST_KEY` 등록. 하나만 있어도 동작한다.
  4. 예전 `ALADIN_TTB_KEY`는 지워도 된다(코드에서 더 읽지 않음).
- **확인**: [라이브러리 추가]에서 교재명 하나와 ISBN 하나를 검색해 결과·표지가 나오는지, 목차 있는 책은 단원이 나뉘는지 본다. 키 값은 채팅·문서에 쓰지 않는다.

## 매뉴얼

7-6 라이브러리 안내에서 바꿀 문장:

> [라이브러리 추가]는 국립중앙도서관과 카카오에서 교재명이나 ISBN 13자리로 찾습니다. 목차가 있으면 단원을 자동으로 나누고, 없으면 [교보문고에서 보기]에서 목차를 복사해 붙여넣습니다. 북커버는 교보문고 표지를 넣고, 없으면 국립중앙도서관·카카오 표지를 넣습니다.
