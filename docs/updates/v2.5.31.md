# v2.5.31 — 출결 키오스크 화면 다듬기

- 날짜: 2026-10-12
- 이전 버전: v2.5.30
- 요약: 출결 키오스크 카드가 태블릿 세로 화면보다 길어 페이지가 스크롤되던 문제와, 휴대폰 폭에서 학원 이름이 등원·하원 버튼과 겹치던 문제를 고쳤다. 오류 결과 모달이 화면 가운데에 뜨지 않던 문제도 고쳤다. 지우기 키를 선형 아이콘으로, 학생 선택 화면의 제목 중복과 "취소" 버튼, 로그인 입력칸 테두리를 다듬었다. 출석 처리 로직은 그대로다.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면(GitHub Pages)·문서. 함수·마이그레이션·Secrets·Notion 변경 없음.

## 항목 1. 키오스크 화면 반영

- **유형**: AI 자동
- **선행 조건**: v2.5.18 적용(공용 디자인 파일).
- **대상 파일**: `attendance_kiosk.html`(`<style>`과 화면 표시 코드), `assets/hada-tokens.css`, `assets/hada-ui.css`, `docs/DESIGN.md`
- **변경 내용**
  - 카드 크기: `--device-w`를 `min(86vw, 52vh, 640px)`, `--device-font`를 `max(10px, min(3.82vw, 2.31vh, 28.4px))`로. 카드 최소 높이는 폭 ÷ 0.6. 카드와 바깥 여백이 화면 안에 들어온다. 짧은 가로 화면에서는 내용만큼 카드가 늘어난다.
  - 로그아웃 아이콘 클릭 영역: 화면 높이 600px 이상에서 최소 44px(`--hit-min`).
  - 결과 모달: 종류 클래스를 `result-success`/`result-info`/`result-error`로 바꿔 공용 `.error` 여백과 겹치지 않게 함(오류 모달이 왼쪽 위로 치우치던 문제).
  - 기기 모드에서 스크롤바 자리를 비우지 않음(모달 배경이 화면 끝까지 덮임).
  - 숫자판: "⌫" 글자 → 선형 지우기 아이콘, "전체지우기" → "전체 지우기".
  - 학생 선택 화면: 선택하는 동안 위쪽 "출결 체크/전화번호 입력" 안내를 숨김, "취소"를 보조 버튼 모양으로.
  - 로그인: 입력칸 포커스 테두리를 브랜드 색 한 줄로, 빈 오류 칸이 아래 여백을 차지하지 않게.
- **환경별 값 (중요)**: `attendance_kiosk.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값을 유지**한다(이번에 바꾼 곳은 `<style>`, 화면 마크업, 결과 모달·학생 선택 표시 코드뿐). 원본 파일을 가져온 뒤 운영 값으로 되돌리고 원문 비교로 확인한다.
- **검증**:
  1. `node tests/design-lint.cjs` 통과.
  2. Pages 반영 후 키오스크를 강력 새로고침(Ctrl+F5)하고, 학원 태블릿에서 카드가 스크롤 없이 한 화면에 들어오는지, 등원·하원 결과 모달이 가운데에 뜨는지 본다.
- **실패 시 대처**: 이전 버전의 `attendance_kiosk.html`·`assets/hada-tokens.css`·`assets/hada-ui.css`로 되돌린다. 서버·데이터 영향 없음.
