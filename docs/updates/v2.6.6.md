# v2.6.6 — 라이브러리: 교보문고에서 가져오기(키 없이)

- 날짜: 2026-10-15
- 이전 버전: v2.6.5
- 요약: 학원마다 책 검색 API 키를 발급받지 않아도 교재를 쉽게 넣도록, PC 브라우저 즐겨찾기 [교재 가져오기]로 교보문고 책 페이지의 정보를 복사해 라이브러리 [직접 추가]에 붙여넣는다.
- 매뉴얼 영향: 있음 → 교재·학습 7-6 라이브러리 안내(아래 "매뉴얼")
- 변경 유형: 화면(Pages `library.html`), 함수(`textbook-api` 쪽수). Notion·DB·Secrets 변경 없음.

---

## 항목 1. 화면·함수 반영

- **유형**: AI 자동(운영 저장소에 원본 `library.html`, `supabase/functions/_shared/textbookSearch.ts`, `supabase/functions/textbook-api/index.ts`를 반영하면 함수·Pages 자동 배포. `hada_config.js`는 덮어쓰지 않는다)
- **선행 조건**: v2.6.2
- **동작**
  - 라이브러리 [라이브러리 추가] → "직접 추가" 카드: `[직접 추가] [가져온 정보 붙여넣기]`, 접기 "교보문고에서 가져오기 준비(PC, 처음 한 번)"와 즐겨찾기로 끌어다 놓는 [교재 가져오기].
  - [교재 가져오기]는 교보문고 책 상세 페이지(`product.kyobobook.co.kr/detail/…`)에서만 동작한다. 읽는 것: 페이지의 구조화 데이터(교재명·ISBN13·출판사·판매가), 취소선 정가, "기본정보"의 쪽수, "이 책의 시리즈"(보일 때), 목차(페이지에 없으면 그 페이지가 쓰는 교보문고 목차 요청). 한 권만, 사람이 누를 때만 읽고 복사한다(자동 수집 없음).
  - [가져온 정보 붙여넣기]는 클립보드를 읽고(브라우저가 허용을 물으면 허용), 못 읽으면 붙여넣기 칸을 연다. 직접 추가 창에 교재명·ISBN·정가·쪽수·표지(교보문고 표지 규칙 주소)가 채워지고, 시리즈·출판사는 라이브러리 선택지와 맞추며(같은 이름 → 교보문고 이름에 들어 있는 가장 긴 선택지, 시리즈는 교재명으로도), 목차는 지금의 [목차 나누기]로 단원이 된다.
  - 함수 `register-custom`이 `pages`(전체 페이지)를 받아 라이브러리 DB "전체 페이지"에 넣는다.
- **검증(원본)**: 실제 교보문고 페이지 두 권(쎈 중등 수학 1-1: 정가 18,000·286쪽·목차 13줄을 스크롤 없이 가져옴, EBS 수능특강 독서: 목차 없음 안내)에서 같은 함수 실행, 라이브러리 UI 검사(즐겨찾기 주소가 줄바꿈 없이도 문법 맞음, 잘못된 붙여넣기 안내, 칸 채움·시리즈/출판사 맞춤·목차 요청, 저장 요청에 정가·쪽수·표지, 6개 폭), 함수 테스트(쪽수 저장).
- **미검증**: 실제 Chrome·Edge 즐겨찾기 막대에서 누르기(복사 허용 동작), 다른 교보문고 페이지 형식(전자책·외국 도서·세트).
- **실패 시 대처**: 교보문고 페이지 구조가 바뀌어 비어 나오면 지금처럼 [직접 추가]에 손으로 넣는다. 원본이 함수를 고치면 학원은 즐겨찾기를 한 번 다시 끌어다 놓는다.

## 항목 2. 즐겨찾기 준비

- **유형**: 운영자 직접(선택, PC 한 대에 한 번)
- **운영자 안내문**
  - 왜 필요한가: 책 검색 키 없이 교보문고에서 교재 정보를 가져온다.
  - 어디서: PC의 Chrome·Edge에서 라이브러리 화면 → [라이브러리 추가] → "직접 추가" 카드의 "교보문고에서 가져오기 준비"
  - 무엇을: 1. [교재 가져오기]를 즐겨찾기 막대로 끌어다 놓는다(막대가 없으면 Ctrl+Shift+B). 2. 교보문고에서 책을 찾아 상세 페이지를 열고 즐겨찾기 [교재 가져오기]를 누른다. 3. "복사했어요"가 뜨면 라이브러리에서 [가져온 정보 붙여넣기] → 시리즈·출판사·단원 확인 → [라이브러리에 추가].
  - 끝났는지 확인하는 방법: 교재 한 권이 라이브러리에 들어가고 단원목록이 생긴다.
  - 흔한 오류와 대처: "교보문고 책 상세 페이지에서 눌러 주세요" → 검색 결과가 아니라 책을 눌러 연 페이지에서 누른다. 붙여넣기가 안 되면 칸이 열리니 Ctrl+V. 원본이 [교재 가져오기]를 고쳤다고 안내하면 즐겨찾기를 지우고 다시 끌어다 놓는다.

## 매뉴얼

교재·학습 7-6 라이브러리 안내에 추가:

> 책 검색 키가 없으면 교보문고에서 가져와요(PC). 라이브러리 [라이브러리 추가] → "직접 추가" 카드의 [교재 가져오기]를 즐겨찾기 막대로 끌어다 놓고, 교보문고 책 상세 페이지에서 그 즐겨찾기를 누른 뒤 라이브러리에서 [가져온 정보 붙여넣기]를 누르면 교재명·ISBN·가격·쪽수·표지·목차가 채워져요. 시리즈·출판사·단원을 확인하고 [라이브러리에 추가]를 누르세요.
