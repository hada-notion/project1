## 항목 1. 공용 알림 줄 종류

- **유형**: AI 자동
- **선행 조건**: 없음
- **대상 파일**: `assets/hada-ui.css`, `docs/DESIGN.md`(2-4 부품 "알림 줄")
- **변경 내용**: `.notice.info`(흰 바탕, 평소 안내·진행 중), `.notice.success`(초록, 저장·연결 완료)를 추가했다. 기본 `.notice`(노랑)와 `.notice.error`는 그대로라 다른 화면 모양은 바뀌지 않는다.
- **환경별 값**: 없음

## 항목 2. 학교 검색 화면

- **유형**: AI 자동
- **선행 조건**: 항목 1
- **대상 파일**: `school_search.html`
- **변경 내용**
  - 로그아웃: 학교 선택 상자 옆 → 상단 바(바로가기 옆), 로그인한 뒤에만 보인다. 좁은 화면에서는 "관리자 전용" 표시를 숨긴다.
  - 알림 줄: 평소 안내·검색 결과는 흰 바탕, 연결 완료는 초록, 오류는 빨강.
  - 검색 결과: 왼쪽에 학교 이름·주소·[학교 홈페이지 ↗], 오른쪽에 [이 학교로 연결](좁은 화면은 아래로). 이름이 이미 종류로 끝나면("○○고등학교 · 고등학교") 종류를 다시 붙이지 않는다.
  - 연결 후: 연결한 학교 이름·주소와 [Notion 학교 페이지 열기 ↗](새 탭), [다른 학교 다시 찾기].
  - 입력 칸 이동: 화면을 열면 비밀번호, 로그인 후 지역, 검색 후 첫 결과의 연결 버튼, 로그아웃 후 비밀번호.
- **환경별 값 (중요)**: `school_search.html`의 `ENDPOINT`(Supabase 주소)는 **운영 값을 유지**한다.
- **검증**: Pages 반영 후 Notion 학교 페이지의 ‘학교 검색’ 링크로 열어 로그인 → 검색 → 연결까지 해 보고, 상단 로그아웃·초록 완료 줄·[Notion 학교 페이지 열기]를 확인한다.
- **실패 시 대처**: v2.5.40의 `school_search.html`, `assets/hada-ui.css`로 되돌린다. 데이터 영향 없음.
