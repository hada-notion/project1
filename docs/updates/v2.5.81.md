# v2.5.81 — 수업방 구분 탭 아이콘·내용 글머리

- 날짜: 2026-10-13
- 이전 버전: v2.5.80
- 요약: 기록 만들기의 구분 탭 [학습 | 과제 | 평가]에 기록 박스와 같은 분류 아이콘을 넣었다. 내용 칸(기록 만들기·기록 카드)에서 줄 맨 앞에 "- " 또는 "* "를 치면 Notion처럼 "  • "(스페이스 두 개 + 점 + 스페이스) 글머리로 바뀐다. 글머리 줄에서 Tab은 한 단계 들여쓰기("      ◦ " → "          ▪ "), Shift+Tab은 내어쓰기다. Enter를 누르면 다음 줄도 같은 단계 글머리로 시작하고, 빈 글머리 줄에서 Enter를 누르거나 글머리 바로 뒤에서 Backspace를 누르면 한 단계 내어쓰고 첫 단계면 글머리가 지워진다.
- 매뉴얼 영향: 수업방 매뉴얼 작성 때 내용 칸 글머리 입력 설명
- 변경 유형: 웹 화면만(Pages). 함수·Notion 변경 없음.

---

## 항목 1. 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`, `class_room.html`(아이콘 색·스크립트 버전 표시), `docs/DESIGN.md`
- **동작**: 글머리는 글자("  • ")로 저장된다. Notion 학습기록 "내용" 속성과 학부모 리포트에도 점으로 보인다(Notion 글머리 목록 블록이 아님). 한글 조합 중에는 바꾸지 않는다.
- **검증(모의 데이터)**: 390·768·1280 화면 흐름 검사 — 구분 탭 아이콘 3개, 내용 칸에 "- 연립방정식 ⏎ 활용 ⏎ ⏎ * 정리 ⏎ ⌫ 끝" "- 연립방정식 ⏎ Tab 활용 ⏎ Tab 문장제 ⏎ Shift+Tab 검산 ⏎ ⏎ 정리 ⏎ ⌫ 끝" 입력 결과 "  • 연립방정식 /       ◦ 활용 /           ▪ 문장제 /       ◦ 검산 /   • 정리 / 끝", 글머리 줄 Tab에서 입력 칸에 머무름, 그 값이 기록 만들기 요청에 그대로 실림, 기존 흐름 전체·넘침·44px.
- **미검증**: 실제 휴대폰 키보드(특히 한글 입력 중 Enter)에서의 글머리 동작. 휴대폰 키보드에는 Tab이 없어 들여쓰기는 PC·외장 키보드에서만 된다.
- **실패 시 대처**: v2.5.80의 `class_room.js`·`class_room.html`로 되돌린다.
