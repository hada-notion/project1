# v2.5.61 — 출석 "선생님 한마디"가 리포트에 들어가지 않던 문제

- 날짜: 2026-10-13
- 이전 버전: v2.5.60
- 요약: 출석 동기화가 출석 페이지의 선생님 한마디를 오타 속성 이름 "선생님 한마때"로 읽고 있었다. 출석(학원) DB의 실제 속성은 "선생님 한마디"라 값이 늘 비어, 출석 페이지에 쓴 선생님 한마디가 학부모 리포트(홈·일간 보고서)에 나오지 않았다. 이름을 고치고 회귀 가드에 검사를 넣었다.
- 매뉴얼 영향: 없음
- 변경 유형: Supabase 함수(공용 코드 `attendanceSyncShared.ts`, `reportDirtySync.ts`). 마이그레이션·Secrets·Notion 변경 없음.

---

## 항목 1. 함수 코드

- **유형**: AI 자동
- **선행 조건**: 없음
- **대상 파일**: `supabase/functions/_shared/attendanceSyncShared.ts`(58행 속성 이름), `supabase/functions/_shared/reportDirtySync.ts`(출석 변경 감시 속성 목록에서 오타 이름 제거), `scripts/check-known-regressions.sh`(오타 이름이 다시 들어오면 실패)
- **환경별 값**: 없음
- **검증**: 함수 배포 후, 선생님 한마디가 적힌 출석이 있는 학생의 리포트에서 오른쪽 위 새로고침을 누르고 홈·일간 보고서에 그 한마디가 보이는지 본다. 이미 저장된 출석 기록은 새로고침(또는 학생 페이지 동기화) 때 다시 읽혀 채워진다.
- **실패 시 대처**: v2.5.60의 두 파일로 되돌린다. 데이터 영향 없음(빈 값이 채워질 뿐).
