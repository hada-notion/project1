# v2.6.21 — 수업에 진도교재 직접 연결, 출석 [학습기록 생성] 제거

- 날짜: 2026-10-16
- 이전 버전: v2.6.20
- 요약: 수업(학원) DB에 진도교재 **단방향 관계** `진도교재`를 두고, 출석 조정이 명단 학생들의 진도교재 전부로 함께 맞춘다(수업 마지막 쓰기 한 번에, Notion 호출 늘지 않음). 수업 페이지 진도교재 탭을 롤업 대신 이 관계로 보여 주어 가볍게 한다. 기록 기준을 고정한다 — **학습기록은 수업 기준**(만들기는 수업의 [학습기록 생성]만, 학습기록의 `출석`·`등록`은 대상 학생 표시), **학습활동은 출석 기준**. 그래서 출석 [학습기록 생성] 버튼을 없앤다.
- 매뉴얼 영향: 있음 → 아래 "매뉴얼"
- 변경 유형: 함수(`fix-attendance` 출석 조정 처리), 관리자 설정 웹훅 체크리스트, Notion 관계 1개·수식 1개·보기 1개·버튼 제거(운영자 직접).
- **선행 조건: v2.6.17(출석 조정 정보 수식 — 보강 합치기).**
- **순서: 항목 1(함수) 배포 → 항목 2(관계) → 항목 3(수식) → 항목 4(보기).** 관계 없이 수식을 먼저 바꾸면 출석 조정이 없는 속성에 쓰려다 오류가 난다.

---

## 항목 1. 함수 반영

- **유형**: AI 자동(원본 `supabase/functions/_shared/fixAttendanceTarget.ts`, `admin_settings.js`·`admin_settings.html` 반영 시 자동 배포)
- **동작**: 출석 조정 계획에 `"books":[…]`가 있으면 수업의 `진도교재`를 그 목록으로 맞춘다(중복 제거, 최대 100개). 명단·완료 상태와 같은 한 번의 쓰기. `books`가 없으면(수식을 아직 안 바꾼 운영) 건드리지 않는다. 형식이 틀리면 예전 방식으로 처리한다.
- **관리자 설정**: 웹훅 체크리스트에서 출석 [학습기록 생성]을 뺀다(39개).
- **검증(원본)**: 함수 테스트(books 해석·중복 제거·형식 오류, 마지막 쓰기 한 번에 진도교재, books 없으면 안 씀), 전체 Deno 테스트, 타입 검사, 회귀 가드, 관리자 보안 테스트, 디자인 규칙 검사, 화면 검사.

## 항목 2. 수업(학원) DB에 `진도교재` 단방향 관계

- **유형**: 운영자 직접(원본은 커넥터로 추가함)
- 속성: 이름 `진도교재`, 관계 → 진도교재(학원) DB, **"진도교재(학원) DB에 표시" 끔(단방향)**. 진도교재 쪽에 수업이 쌓이지 않게 하려는 것이다(교재 하나에 수업 수백 개가 붙으면 무겁고, 서버가 관계를 읽을 때 25개까지만 받는다).

## 항목 3. 수업(학원) DB 수식 `출석 조정 정보` 교체 (항목 1·2 뒤)

- **유형**: 운영자 직접
- v2.6.17 수식에 `bookIds` 한 줄과 `"books"` 출력을 더했다(나머지 같음). 명단 중 수강 기간인 학생(보강은 명단 전원)의 진도교재 전부.

```
if(empty(prop("수업일시")),
  "{\"v\":1,\"skip\":\"수업일시 없음\"}",
  lets(
    isMakeup, prop("보강"),
    sessionDateTime, prop("수업일시"),
    day, formatDate(prop("수업일시"), "YYYY-MM-DD"),
    roster, prop("등록"),
    sessRecs, prop("학습기록"),
    atts, prop("출석"),
    active, if(isMakeup, roster, roster.filter(lets(reg, current,
      if(empty(reg.prop("등록일")), true, reg.prop("등록일") <= sessionDateTime) and
      if(empty(reg.prop("종료일")), true, sessionDateTime < dateAdd(reg.prop("종료일"), 1, "days"))
    ))),
    activeIds, active.map(id(current)),
    bookIds, active.map(current.prop("진도교재")).flat().map(id(current)).unique(),
    attRegIds, atts.map(current.prop("등록").map(id(current)).join("")),
    addItems, active.filter(not attRegIds.includes(id(current))).map(lets(
      reg, current,
      unl, reg.prop("출석").filter(empty(current.prop("수업")) and formatDate(current.prop("수업일시"), "YYYY-MM-DD") == day and if(isMakeup, current.prop("출석 상태") == "🔵 보강", true)),
      recs, reg.prop("학습기록").filter(sessRecs.includes(current)),
      "{\"reg\":\"" + id(reg) + "\",\"att\":\"" + if(empty(unl), "", id(unl.first())) + "\",\"rec\":[" + recs.map("\"" + id(current) + "\"").join(",") + "]}"
    )),
    delAtts, if(isMakeup, [], atts.filter(lets(a, current, i, index, rid, a.prop("등록").map(id(current)).join(""), rid != "" and (not activeIds.includes(rid) or attRegIds.slice(0, i).includes(rid))))),
    extraIds, if(isMakeup, attRegIds.filter(current != "" and not activeIds.includes(current)).unique(), []),
    rosterIds, if(isMakeup, activeIds.concat(extraIds), activeIds),
    "{\"v\":1," + if(isMakeup, "\"mk\":1,", "") + "\"day\":\"" + day + "\",\"add\":[" + addItems.join(",") + "],\"del\":[" + delAtts.map("\"" + id(current) + "\"").join(",") + "]" +
      if(rosterIds.length() == roster.length() and extraIds.empty(), "", ",\"roster\":[" + rosterIds.map("\"" + current + "\"").join(",") + "]") +
      ",\"books\":[" + bookIds.map("\"" + current + "\"").join(",") + "]}"
  )
)
```

- **확인**: 정규 수업 값 끝에 `,"books":["…", …]`가 붙는다. [출석 조정]을 누르면 수업의 `진도교재`에 명단 학생들의 진도교재가 채워진다(그룹 진도 교재는 반에 하나라 학생 수와 상관없이 1개).

## 항목 4. 수업 페이지 "진도교재" 탭 바꾸기

- **유형**: 운영자 직접
- 탭을 수업의 `진도교재` 관계 보기로 바꾸고 필터는 **진행상태 = 진행 중**(학생이 여럿이면 등록으로 묶어 보기). 새 탭이 잘 나오면 예전 롤업 보기와 그 롤업 속성을 정리한다.
- 이미 만들어진 수업은 [출석 조정]을 한 번 누르면 채워진다(앞으로 만들어지는 수업은 자동).

## 항목 5. 출석 [학습기록 생성] 버튼 지우기

- **유형**: 운영자 직접(출석(학원) DB)
- **이유**: 학습기록은 수업 기준이다. 수업의 [학습기록 생성]이 명단 학생 전원의 `오늘 학습` 교재를 훑어 그룹 진도는 수업 출석 전원에, 개별 진도는 그 학생 출석에만 기록을 만든다. 출석에서 따로 만들면 같은 기록이 두 번 생기거나 빠질 수 있다. 출석 페이지의 학습기록 탭(출석 관계 보기)은 그대로 쓴다.

## 매뉴얼

- 기록 기준: "학습기록은 수업에서 만들어요(수업 [학습기록 생성]). 개별 진도 기록도 수업에서 그 학생 몫으로 만들어져요. 학습활동(과제·평가 결과)은 학생마다 출석에 붙어요."
- 수업 진도교재 탭: "이 수업 학생들의 진행 중인 교재가 보여요. 출석 조정이 돌 때 함께 맞춰져요."
