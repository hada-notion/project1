# v2.5.60 — 학부모 리포트 소제목 규칙·일간 보고서 세션 구성

- 날짜: 2026-10-13
- 이전 버전: v2.5.59
- 요약: 탭마다 소제목 크기·위치·아이콘이 제각각이던 것을 4단계 규칙으로 맞췄다(`DESIGN.md` 1부 4장). 홈의 오늘·곧 마감·진도·선생님 한마디는 카드 밖 15px 제목 + 아이콘, 캘린더 선택일은 날짜 묶음 모양. 보고서 탭은 제목을 카드 안에 두는 예외로 하고, 일간 보고서를 주간·월간과 같은 느낌의 세션으로 다시 짰다: 출석 / 이날 마감 과제 카드 → 학습 → 과제(지난·이번) → 평가(이번 평가·최근 평가 추이) → 선생님 코멘트. 항목 아이콘은 교재 표지, 본문은 접지 않고 다 보여준다.
- 매뉴얼 영향: 있음(학부모 리포트 보고서 설명이 있다면 함께)
- 변경 유형: 웹 화면(GitHub Pages). 함수·마이그레이션·Secrets·Notion 변경 없음.

## 항목 1. 학부모 리포트

- **유형**: AI 자동
- **선행 조건**: v2.5.59
- **대상 파일**: `student_report.html`(스타일), `student_report_part1.js`(교재 상세 "학습기록" 제목 한 줄), `student_report_part2.js`(홈·일간 보고서)
- **변경 내용**
  - 소제목 4단계: 1 탭 제목(17px) / 2 섹션 제목(15px 굵게, 아이콘 16px, 카드 밖) / 3 묶음 라벨(13px 옅은색) / 4 카드 안 작은 라벨. 보고서 탭만 2단계 제목을 카드 안에 둔다.
  - 일간 보고서: 출석·이날 마감 과제를 주간·월간 출석률 카드처럼 큰 배지로 가운데 정렬. 학습(교재별 기록, 표지 + 본문 전체), 과제(지난 과제 = 이날 마감, 이번 과제 = 출제일 기준 기존 "다음과제"), 평가(이번 평가 + 최근 평가 추이 그래프), 선생님 코멘트.
  - 주간·월간 보고서 제목 아이콘 크기를 16px로 맞춤(구조는 그대로).
- **환경별 값 (중요)**: `student_report_part1.js`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값 유지**. part1은 교재 상세 제목 한 줄만 바뀌었으므로 그 줄만 옮긴다.
- **검증**: 일간 보고서에서 학습·과제·평가가 세션별 카드로 나오고 본문이 펼쳐진 채 보이는지, 홈 섹션 제목이 카드 밖에 아이콘과 함께 보이는지 본다.
- **실패 시 대처**: v2.5.59의 세 파일로 되돌린다.
