# v2.5.60 — 학부모 리포트 소제목 규칙·일간 보고서 세션 구성

- 날짜: 2026-10-13
- 이전 버전: v2.5.59
- 요약: 탭마다 소제목 크기·위치·아이콘이 제각각이던 것을 4단계 규칙으로 맞췄다(`DESIGN.md` 1부 4장). 홈의 오늘·곧 마감·진도·선생님 한마디는 카드 밖 15px 제목 + 아이콘, 캘린더 선택일은 날짜 묶음 모양. 보고서 탭은 세션마다 흰 박스 안에 제목을 두고, 그 안을 박스 끝까지 차는 베이지 띠로 나눴다(교재·묶음마다 띠 하나). 일간 보고서는 출석 / 이날 마감 과제 카드 → 학습 → 과제(지난·이번) → 평가(이번 평가·최근 평가 추이) → 선생님 코멘트로 다시 짰고, 주간·월간도 같은 박스를 쓴다. 기록 본문은 라벨 아래 선을 없애고 수업 자료와 학습 결과 사이에만 선을 둔다(학습기록 탭·교재 상세 공통).

## 항목 1. 학부모 리포트

- **유형**: AI 자동
- **선행 조건**: v2.5.59
- **대상 파일**: `student_report.html`(스타일), `student_report_part1.js`(교재 상세 "학습기록" 제목 한 줄), `student_report_part2.js`(홈·일간 보고서)
- **변경 내용**
  - 소제목 4단계: 1 탭 제목(17px) / 2 섹션 제목(15px 굵게, 아이콘 16px, 카드 밖) / 3 묶음 라벨(13px 옅은색) / 4 카드 안 작은 라벨. 보고서 탭은 세션 박스 안에 2단계 제목.
  - 일간 보고서: 출석·이날 마감 과제를 주간·월간 출석률 카드처럼 큰 배지로 가운데 정렬. 학습(교재마다 베이지 띠, "교재 · 범위" 제목 + 본문 전체), 과제(지난 과제 = 이날 마감, 이번 과제 = 출제일 기준 기존 "다음과제"), 평가(이번 평가 + 최근 평가 추이), 선생님 코멘트.
  - 주간·월간 보고서: 평가 기록·선생님 한마디를 같은 세션 박스로.
  - 기록 본문(보고서·학습기록 탭·교재 상세): 라벨 아래 선 제거, 기록 쪽과 활동 쪽 사이에만 선.
- **환경별 값 (중요)**: `student_report_part1.js`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값 유지**. part1은 교재 상세 제목 한 줄만 바뀌었으므로 그 줄만 옮긴다.
- **검증**: 일간 보고서에서 학습·과제·평가가 세션별 카드로 나오고 본문이 펼쳐진 채 보이는지, 홈 섹션 제목이 카드 밖에 아이콘과 함께 보이는지 본다.
- **실패 시 대처**: v2.5.59의 세 파일로 되돌린다.
