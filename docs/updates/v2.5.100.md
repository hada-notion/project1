# v2.5.100 — 수업 관리 캘린더를 리포트 캘린더와 같은 결로

- 날짜: 2026-10-14
- 이전 버전: v2.5.99
- 요약: 수업 관리 캘린더와 학부모 리포트 캘린더가 같은 구조인데도 다른 화면처럼 보였다(수업 없는 날을 흐리게, 고른 날 진한 갈색 채움, 미입력 노란 채움, 옅은 사각형 범례 4개). 리포트 캘린더 코드의 칸 모양·빗금·범례를 따르도록 맞췄다. 반 전체 상태라 범례 단어("모두 출석·결석 있음")는 수업 관리 그대로. 리포트의 "이번 달 수업" 진행 막대는 수업 관리에 맞지 않아 넣지 않기로 했다(목업 확인 후 결정).
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면만(Pages). 함수·Notion 변경 없음.

---

## 항목 1. 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`(칸 상태·범례), `class_room.html`(캘린더 칸·범례 CSS), `docs/DESIGN.md`
- **동작**
  - 수업 없는 날: 흐리게(opacity) 하지 않고 옅은 글자색만, 누를 수 없음.
  - 수업 날: 모두 출석 초록·결석/보강 있음 빨강(변경 없음), 출석 미입력인 지난 수업은 빗금(리포트와 같음), 앞으로의 수업·오늘 아직 다 찍지 않은 수업은 테두리만.
  - 보고 있는 수업: 진한 갈색 채움 대신 갈색 테두리(상태 색은 그대로 보임). 오늘은 빨간 테두리.
  - 범례: 진한 점 두 개 "● 모두 출석 ● 결석 있음"만.
- **검증(모의 데이터)**: 수업 관리 화면 흐름 검사 390·768·1280 — 오늘 미입력 수업은 테두리(빗금 아님)·고른 날 표시, 범례 두 개, 수업 없는 날 흐리지 않음, 고른 날 채우지 않음, 기존 흐름 전체. 디자인 규칙 검사, 회귀 가드. 한 달 수업 모의 데이터 캡처(390·1280).
- **미검증**: 운영 데이터·실기기.
- **실패 시 대처**: v2.5.99의 `class_room.js`·`class_room.html`로 되돌린다.
