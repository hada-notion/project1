## 항목 1. 검색과 직접 추가

- **유형**: AI 자동(`main` 병합 시 함수·Pages 반영)
- **대상 파일**: `supabase/functions/_shared/textbookSearch.ts`, `supabase/functions/textbook-api/index.ts`, `supabase/functions/_shared/textbookSearch_test.ts`, `library.html`, `docs/DESIGN.md`
- **동작**:
  - 검색: 검색어가 ISBN13(하이픈·띄어쓰기 허용)이면 알라딘에서 그 책 한 권, 아니면 알라딘 국내도서·외국도서를 함께 찾아 한 목록으로(국내 먼저, 같은 ISBN13은 한 번만). 국내/외국을 고르는 칸은 없다.
  - [직접 추가]: 빈 교재로 창이 열린다. 교재명(필수), ISBN13·표지 이미지 주소(https)·출판사(선택), 단원(목차 붙여넣기·[단원 추가]). 같은 ISBN13이 이미 있으면 등록하지 않는다. 출판사·시리즈는 기존 선택지와 같을 때만 넣는다.
  - 서점 상품 페이지를 읽는 기능은 넣지 않았다(ISBN이 있는 책은 대부분 알라딘에 있고, 서점 화면이 바뀌면 깨지기 쉬움). 직접 추가할 때 표지 주소는 메뉴얼 7-6 북커버 규칙(교보문고·한국교과서협회·키다리영어샵)을 따른다.
- **검증(모의 데이터)**: 함수 테스트(국내·외국 함께·중복 한 번, ISBN 검색, 직접 추가 필수·선택값·https 표지·중복 409), 전체 테스트·타입 검사·회귀 가드·디자인 검사, 라이브러리 UI 검사 6개 크기(ISBN 검색, 직접 추가 창·필수값 오류·등록).
- **미검증**: 실제 알라딘 외국도서 결과, 실제 Notion 등록.
- **실패 시 대처**: v2.5.118 파일로 되돌린다.
