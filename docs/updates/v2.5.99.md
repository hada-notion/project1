# v2.5.99 — 키오스크 등원 시각을 리포트까지 연결

- 날짜: 2026-10-14
- 이전 버전: v2.5.98
- 요약: 키오스크가 Notion 출석에 찍는 등원·하원 시각은 출석 동기화가 Notion 출석을 읽을 때 이미 함께 받아 오지만, Supabase 출석 원자료(`attendance_records`)에는 저장하지 않고 버리고 있었다(기존 `check_in`·`check_out` 칸은 이름과 달리 "수업일시" 시작·끝 시각). 새 칸에 담아 리포트 캐시와 학부모 리포트까지 이어 붙였다. 수업 관리(Notion 직접 읽음)와 리포트가 같은 값(등원스템프)을 쓴다.
- 매뉴얼 영향: 학부모 리포트 일간 보고서 설명(출석 칸 아래 등원 시각)
- 변경 유형: DB 마이그레이션 + 함수(출석 동기화·리포트 캐시) + 웹 화면(학부모 리포트). Notion 구조 변경 없음.

---

## 항목 1. DB: 출석 원자료에 등원·하원 시각 칸

- **유형**: AI 자동(`main` 병합 시 "Deploy Supabase Functions"가 마이그레이션을 먼저 적용하고 함수를 배포)
- **대상 파일**: `supabase/migrations/20261014030000_attendance_stamps.sql`
- **변경**: `attendance_records`에 `arrived_at`·`left_at`(timestamptz, 비어 있을 수 있음) 추가. `add column if not exists`라 다시 적용해도 안전. 접근 권한(RLS, 서비스 역할만)은 그대로.
- **검증**: 로컬 PGlite에서 출석 테이블 생성 → 이번 마이그레이션 두 번 적용 → 등원 시각 넣고 읽기 확인. 관리자 보안 SQL 검사 118개 통과.
- **미검증**: 운영 DB 적용(병합 후 Actions 로그로 확인).

---

## 항목 2. 함수: 출석 동기화·리포트 캐시

- **유형**: AI 자동
- **대상 파일**: `supabase/functions/_shared/attendanceSyncShared.ts`(`buildAttendanceRow`), `supabase/functions/_shared/reportCacheBuilder.ts`(출석 줄에 `arrived`·`left`), `supabase/functions/_shared/attendanceSyncShared_test.ts`(새 테스트), `.github/workflows/deploy-supabase-functions.yml`(새 테스트 실행 추가)
- **변경**: Notion 출석 페이지 → 출석 원자료 행을 만들 때 "등원스템프"·"하원스템프" 시각을 함께 저장. 리포트 캐시의 출석 줄(`attendance_rows`)에 `arrived`·`left`를 더함. 기존 값·동작은 그대로.
- **언제 채워지나**: 이 버전 이후 그 학생 리포트가 다시 계산될 때(학부모 새로고침, 일일 보고서 발송 전 최신화, 동기화 대기열) 그 등록의 출석이 Notion에서 다시 읽혀 채워진다. 그전까지 지난 날짜는 출석 칸 아래 줄이 비어 있다(화면은 정상).
- **검증**: 새 테스트(등원·하원 시각 저장, 수업 시각은 그대로, 시각 없으면 비움, 등록 없으면 건너뜀). 전체 함수 테스트 196개, 모든 함수 `deno check`, 회귀 가드.
- **미검증**: 운영 Notion 출석으로 실제 저장(병합 후 학부모 리포트 새로고침으로 확인).
- **실패 시 대처**: v2.5.98의 두 함수 파일로 되돌리고 `main`에 병합(자동 재배포). 추가한 칸은 남아 있어도 다른 동작에 영향 없음.

## 항목 3. 학부모 리포트 일간 보고서

- **유형**: AI 자동
- **대상 파일**: `student_report_part1.js`(출석 줄 `arrived`·`left` 서울 시각으로), `student_report_part2.js`(일간 세 칸), `student_report.html`, `docs/DESIGN.md`
- **동작**: 출석 칸 아래 "16:52 등원"(하원 시각은 칸이 좁아 넣지 않음), 과제·평가 칸 아래 "n건". 아래 줄은 비어도 한 줄 높이를 지켜 세 칸 높이가 같다. 평가 배지는 1건 "90점", 2건 이상 "평균 90점".
- **검증(모의 데이터)**: 보고서 요약 검사 390·1280 — 출석 칸 "16:52 등원"(하원 시각 없음), 세 칸 높이 같음, 평가 2건 "평균 85점 2건"·1건 "90점 1건", 등원 기록 없는 날 빈 줄. 기존 리포트 화면 검사 2종.
- **미검증**: 운영 데이터·실기기(목업: `daycards-compare.png` A안).
