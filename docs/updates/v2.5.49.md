## 항목 1. 정렬·간격·줄바꿈

- **유형**: AI 자동
- **선행 조건**: v2.5.48
- **대상 파일**: `assets/hada-ui.css`, `assets/hada-tokens.css`, `admin_settings.html`, `legal_documents.html`, `docs/DESIGN.md`
- **변경 내용**
  - 관리자 설정 휴대폰: 새 웹훅 키 막대가 붙어 다니며 화면을 가리지 않게 제자리에 두고, 이름 / 키 값(한 줄 전체) / [보기·키 복사] 순으로 쌓는다. 키가 한 글자씩 세로로 늘어지던 문제 해결. 아래쪽 [로그아웃]과 버튼 줄(새로고침·교체 완료)은 가로 꽉.
  - 날짜 칸: 기기·브라우저 기본 모양(데스크탑 달력 아이콘, 휴대폰 아래 화살표·가운데 정렬) 대신 선택 상자와 같은 글자 위치(왼쪽 16)와 Feather calendar(오른쪽 16, 20×20). 기본 달력 버튼은 아이콘 자리에 투명하게 겹쳐 눌러도 달력이 열린다.
  - 줄바꿈: 한국어는 띄어쓰기 단위, 칸보다 긴 낱말만 끊는다(`overflow-wrap:break-word` 추가).
  - 법정 서류 태블릿: [조회]가 칸 너비를 채운다. 휴대폰 카드 안쪽 여백 24 → 20.
- **환경별 값 (중요)**: `attendance_kiosk.html`·`legal_documents.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`, `school_search.html`의 `ENDPOINT`는 **운영 값을 유지**한다.

## 항목 2. Feather 아이콘 통일

- **유형**: AI 자동
- **선행 조건**: 없음
- **대상 파일**: `assets/hada-ui.css`, `assets/hada-tokens.css`, `admin_settings.js`, `admin_settings.html`, `school_search.html`, `attendance_kiosk.html`
- **변경 내용**
  - 새 탭 링크의 "↗" 글자 → Feather arrow-up-right(`.icon-ext`, 글자색을 따름): 웹훅 등록·DB 열기, 학교 홈페이지, Notion 학교 페이지 열기.
  - 접기 제목(교체 방법, 교체 취소)의 기본 ▶ → Feather chevron-right(펼치면 아래로).
  - 검색 칸의 기본 지우기(×) 아이콘 숨김.
  - 관리자 설정 체크리스트: 체크박스 조건 → check-square / square, 트리거 "＋ / ∠" 글자 → plus / edit-2, 안내 그림의 "←" → arrow-left.
  - 관리자 설정의 Notion 버튼·자동화 종류 표시는 Notion 모양 기존 아이콘을 그대로 쓴다(예외).
  - 키오스크 결과 안내 아이콘(info·error) → Feather info / alert-circle 원본.
- **검증**: Pages 반영 후 휴대폰에서 관리자 설정 웹훅 교체 화면(키 막대), 법정 서류 날짜 칸(글자 왼쪽, 달력 아이콘이 선택 상자 화살표와 세로 한 줄), 각 화면 링크·접기 아이콘을 본다. 실제 안드로이드·아이폰의 날짜 칸 모양은 기기에서 확인이 필요하다.
- **실패 시 대처**: v2.5.48의 해당 파일들로 되돌린다. 데이터 영향 없음.
