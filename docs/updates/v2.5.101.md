# v2.5.101 — 리포트 캘린더 날짜 기록을 독립 카드로

- 날짜: 2026-10-14
- 이전 버전: v2.5.100
- 요약: 학부모 리포트 캘린더에서 날짜를 누르면 그날 학습·과제·평가가 한 카드 안에 구분선으로 이어져 보였고, 학습기록 탭 카드와 표시 규칙도 달랐다(과제 마감 줄 모양 등). 학습기록 탭의 카드 코드를 공용 함수로 빼서 캘린더 날짜 목록도 같은 독립 카드로 그리게 했다.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면만(Pages). 함수·Notion 변경 없음.

---

## 항목 1. 화면

- **유형**: AI 자동
- **대상 파일**: `student_report_part2.js`(`logCardHtml`·`logItemOfStudy/Homework/Test` 공용 함수, 학습기록 탭·캘린더 날짜 목록), `student_report.html`(`.cal-day-logs`, 스크립트 버전 표시), `docs/DESIGN.md`
- **동작**: 캘린더 날짜 목록의 기록마다 학습기록 탭과 같은 독립 카드(아이콘·구분, 교재 · 범위, 알약, 단원·내용, 과제는 "• 마감:"만, 본문·사진이 있을 때만 ⌄ 펼치기). 기록이 없는 날은 지금처럼 "이날 기록된 학습·과제·평가가 없어요." 카드. 학습기록 탭 카드는 내용 그대로 공용 함수로 옮겼다(아이콘 그림도 같음).
- **검증(모의 데이터)**: 보고서 요약 검사(`check-report-cards.cjs`)에 캘린더 날짜 목록 추가 — 기록마다 독립 카드(공용 카드 안이 아님)·학습/과제/평가 모두·과제는 마감만·평가 점수 알약, 학습기록 탭 과제 마감만. 기존 리포트 화면 검사 2종(첫 화면·탭, 뒤로가기), 회귀 가드.
- **미검증**: 운영 데이터·실기기.
- **실패 시 대처**: v2.5.100의 `student_report_part2.js`·`student_report.html`로 되돌린다.
