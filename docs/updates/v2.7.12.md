# v2.7.12 — 웹훅 체크리스트 링크 3개를 원본 템플릿과 같게

- 날짜: 2026-10-20
- 이전 버전: v2.7.11
- 요약: 관리자 설정 웹훅 체크리스트가 링크 재발급·링크 비활성화·링크 활성화를 "주소에 `?action` 없이 + 추가 헤더 `x-link-action`"으로 안내했다. 원본 템플릿은 "주소 끝 `?action=…` + 헤더 `x-admin-key` 하나"다. 게다가 "헤더" 복사 버튼은 값만 복사해 키 이름이 빈 헤더가 생길 수 있었다. 체크리스트가 `?action=`까지 들어간 주소를 복사하고 "헤더" 버튼은 없앤다.
- 매뉴얼 영향: 없음
- 변경 유형: 관리자 설정 화면(`admin_settings.js`·`admin_settings.html`). Edge Function·마이그레이션·Secrets·Notion 구조 변경 없음.

---

## 항목 1. 관리자 설정 화면 교체

- **유형**: AI 자동
- **선행 조건**: 없음
- **대상 코드**: `admin_settings.js`, `admin_settings.html`을 원본 `main` 최신본으로 바꾼다. `hada_config.js`는 덮어쓰지 않는다.
  - 찾을 원문 (앵커): `admin_settings.js`의 `{header:['x-link-action','regenerate']`. 없으면 이미 적용된 것이다.
- **Notion 변경**: 없음. 이미 `x-link-action` 헤더 방식으로 넣은 학원도 서버가 받으므로 그대로 동작한다. 원본 기준(지문)과 맞추려면 등록 DB 세 곳을 주소 끝 `?action=regenerate` / `?action=disable` / `?action=enable`로 바꾸고 `x-link-action` 헤더 줄을 지운다(선택). 키 이름이 빈 헤더 줄이 있으면 지운다.
- **검증**: 관리자 설정 체크리스트에서 링크 3개 항목의 "웹훅" 복사 값이 `…/toggle-report-link?action=…`로 끝나고 "헤더" 버튼이 없다.
- **실패 시 대처**: 두 파일을 이전 버전으로 되돌린다.
