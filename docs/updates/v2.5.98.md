## 항목 1. 학부모 리포트

- **유형**: AI 자동
- **대상 파일**: `student_report_part1.js`(`showTestPeriodModal` 추가), `student_report_part2.js`(평가 칸 누르기, 학습기록 탭 과제 줄, 뒤로가기 창 목록), `student_report.html`(스크립트 버전 표시)
- **동작**
  - 일간 "평가 현황"(그날 평가가 있을 때)·주간/월간 "평가 평균"(기간에 평가가 있을 때)을 누르면 평가 상세 모달에 그날·그 기간 평가 목록(교재 · 범위, 점수 알약 "90점 (18/20)", 단원·내용, 기간이면 "날짜:" 줄). 과제 칸 모달과 같은 카드 모양. 뒤로가기·✕·바깥 누르기로 닫힘.
  - 학습기록 탭(날짜로 묶음)의 과제 카드는 "• 마감:"만 보인다. 기간 과제 모달·일간 "지난 과제"·"이번 과제"는 그대로(날짜로 묶이지 않음).
- **검증(모의 데이터)**: 보고서 요약 검사(`check-report-cards.cjs`) 390·1280 — 일간 평가 칸 누르면 모달·내용·뒤로가기로 닫힘, 월간 평가 평균 누르면 모달("날짜:" 줄), 학습기록 탭 과제 카드에 출제 없음·마감 있음. 기존 리포트 화면 검사 2종(첫 화면·탭, 뒤로가기), 회귀 가드.
- **미검증**: 운영 학생 데이터·실제 휴대폰.

## 항목 2. 수업 관리

- **유형**: AI 자동
- **대상 파일**: `class_room.js`, `class_room.html`, `docs/DESIGN.md`
- **동작**
  - 상단 경로: 강사 이름 → 첫 화면, 반 이름 → 그 반 홈 탭, 교재 상세의 "교재" → 교재 탭. 마지막 글자(지금 화면)는 누르지 않는다. 그 화면이 방문 기록에 있으면 뒤로가기를 여러 번 한 것처럼 돌아가(방문 기록이 쌓이지 않음), 없으면(Notion 수업 링크로 연 경우 등) 바로 연다.
  - 기록 카드(학습기록 탭·홈·캘린더·교재 상세 — 모두 날짜·수업으로 묶인 곳)의 과제는 "• 마감:"만 보인다.
- **검증(모의 데이터)**: 수업 관리 화면 흐름 검사 390·768·1280 — 교재 상세 경로 "교재" → 교재 탭, 반 이름 → 홈, 강사 이름 → 첫 화면(방문 기록이 비워짐 = 뒤로 돌아감), 마지막 글자는 버튼 아님, 기록 카드에 출제 줄 없음·"• 마감:"만, 기존 흐름 전체. 디자인 규칙 검사.
- **미검증**: 실제 휴대폰.
- **실패 시 대처**: 두 화면 모두 v2.5.97 파일로 되돌린다.
