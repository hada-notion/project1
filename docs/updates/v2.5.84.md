# v2.5.84 — 브라우저 탭 아이콘

- 날짜: 2026-10-14
- 이전 버전: v2.5.83
- 요약: 학부모 리포트(📋 이모지)를 빼면 탭 아이콘이 없어 브라우저 기본 지구본으로 보이던 화면들에 아이콘을 넣었다. 바탕 없이 브랜드 진한 갈색 선 아이콘이고, 기기가 다크 모드면 밝은 베이지 선으로 보인다. 관리자 설정 settings, 법정 서류 file-text, 학교 검색 search, 키오스크 check-square, 수업 관리 edit-3, 학부모 리포트 clipboard. 키오스크 화면 위 아이콘(원 안 체크)도 check-square로, 상단 메뉴의 폰 폭 아이콘도 키오스크 check-square·수업 관리 edit-3으로 맞췄다.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면만(Pages). 함수·Notion 변경 없음.

## 항목 1. 화면

- **유형**: AI 자동
- **대상 파일**: `admin_settings.html`, `legal_documents.html`, `school_search.html`, `attendance_kiosk.html`, `class_room.html`, `student_report.html`(탭 아이콘 한 줄만), `assets/hada-shortcuts.js`(메뉴 아이콘, 스크립트 버전 표시), `docs/DESIGN.md`
- **동작**: 아이콘은 각 HTML 안에 SVG로 들어 있어 파일이 따로 없다. 브라우저가 탭 아이콘을 저장해 두는 경우 새 아이콘이 바로 안 보일 수 있다(새로고침이나 탭을 다시 열면 바뀜).
- **검증(모의 데이터)**: 6개 화면의 탭 아이콘을 밝은·어두운 바탕에 16·32px로 그려 확인, 키오스크 화면 위 아이콘, 관리자 설정·법정 서류·학교 검색·키오스크·수업 관리·리포트 화면 검사, 디자인 규칙 검사, 회귀 가드.
- **미검증**: 실제 브라우저 탭(크롬·사파리·휴대폰)에서의 표시.
- **실패 시 대처**: 각 HTML의 `<link rel="icon">` 한 줄을 지우면 이전과 같다.
