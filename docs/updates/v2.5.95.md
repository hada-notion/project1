# v2.5.95 — 수업 관리 학습기록 카드 = 리포트 카드 규칙

- 날짜: 2026-10-14
- 이전 버전: v2.5.94
- 요약: 같은 학습기록이 학부모 리포트와 수업 관리에서 다르게 보였다. 수업 관리는 기록의 "내용"(예: 선과제 테스트)을 펼쳐야만 보여 줬고, 단원·마감 날짜·제출 상태도 없었다. 리포트 학습기록 카드와 같은 규칙으로 고쳤다: 단원·내용·출제/마감은 카드에 바로 보이고, 펼치기는 Notion 페이지 본문만.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면(Pages) + 함수(class-room 읽기 값 추가, 리포트 캐시 본문 변환 코드 위치 이동). Notion 구조·DB 변경 없음.

---

## 항목 1. 함수

- **유형**: AI 자동(`main` 병합 시 "Deploy Supabase Functions"가 자동 배포)
- **대상 파일**: `supabase/functions/_shared/classRoom.ts`, `supabase/functions/_shared/classRoom_test.ts`, `supabase/functions/_shared/feedBody.ts`(새 파일), `supabase/functions/_shared/reportCacheBuilder.ts`, `scripts/check-known-regressions.sh`
- **변경**
  - class-room `session`·`class-records`의 학습기록마다 `unit`(단원), `homework`(과제: 제출 수·전체·마감일 — 학습활동 "과제상태"·"과제 마감일"), `score`(평가: 평균 점수·인원), `body`(페이지 본문 블록, `class-records`는 최근 20개만)를 더했다. Notion은 읽기만 한다.
  - 리포트 캐시(`reportCacheBuilder.ts`)의 학습기록 본문 변환(`blocksToFeedBody`·`readPageBodyBlocks`)을 **내용 한 글자도 바꾸지 않고** `feedBody.ts`로 옮겨 리포트와 수업 관리가 함께 쓴다(옮기기 전후 비교 일치 확인). 회귀 가드의 "PDF/파일 블록·blockId" 검사도 새 파일 위치로 옮기고, 리포트 캐시가 그 파일을 쓰는지 검사를 더했다.
- **검증(모의 데이터)**: `classRoom_test.ts` 20개 통과(단원·내용·본문, 과제 제출 1/2·마감일 서울 날짜, 평가 평균 80, 수업 화면 기록에도 같은 값). 전체 함수 테스트 195개, 모든 함수 `deno check`, 회귀 가드, 학부모 리포트 화면 검사.
- **미검증**: 운영 데이터로 응답(본문 블록 읽기 시간, 사진 주소), 리포트 캐시 생성 실환경(코드 이동만이라 동작 같음).
- **실패 시 대처**: v2.5.94의 함수 파일·회귀 가드로 되돌리고 `main`에 병합(자동 재배포).

## 항목 2. 수업 관리 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`, `class_room.html`, `docs/DESIGN.md`("기록 카드")
- **카드**: [분류 아이콘·구분] [교재 · 범위] [알약: 과제 "제출 n/전체"(모두 제출 파랑·아니면 빨강), 평가 "평균 n점", 보강] / 아래 줄(항상 보임): 단원 "• 1-1. …"(단원 번호마다 한 줄) → 내용(줄바꿈 그대로) → 과제 "• 출제: 날짜"·"• 마감: 날짜" / ⌄ 펼치기는 페이지 본문이 있을 때만, 펼치면 본문(글·목록·사진·파일·표)만. 학습기록 탭·홈·캘린더 학습 기록·교재 상세 모두 같은 카드.
- **검증(모의 데이터)**: 수업 관리 화면 흐름 검사 390·768·1280 — 단원 두 줄·내용이 펼치지 않아도 보임, ⌄로 본문만(내용은 펼침 칸에 없음, 굵게 유지), 과제 카드 "제출 1/3"·출제·마감, 본문 없는 기록은 ⌄ 없음, 기존 흐름 전체. 디자인 규칙 검사.
- **미검증**: 운영 데이터·실제 휴대폰 화면(본문 사진 크기).
- **실패 시 대처**: v2.5.94의 `class_room.js`·`class_room.html`로 되돌린다.
