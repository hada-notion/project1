# v2.5.82 — 관리자 비밀번호로 통일, 수업 관리 이름·메뉴, 키오스크 로그인 유지

- 날짜: 2026-10-14
- 이전 버전: v2.5.81
- 요약: 모든 웹 화면을 관리자 비밀번호 하나로 쓴다. 선생님 공용 "수업용 비밀번호"(v2.5.65)를 삭제하고, 수업방은 관리자 비밀번호로 로그인한다(12시간). 수업방 이름을 "수업 관리"로 바꾸고 관리 화면(관리자 설정·법정 서류·학교 검색) 상단 메뉴에 [수업 관리] 링크(새 탭)를 키오스크 옆에 넣었다. 키오스크 로그인은 30일 제한 없이 관리자 비밀번호를 바꿀 때까지 유지된다.
- 매뉴얼 영향: 있음(관리자 설정 화면의 수업용 비밀번호 칸 삭제, 수업 관리 로그인, 키오스크 로그인 유지 기간)
- 변경 유형: 마이그레이션 1개 + Supabase 함수(`admin-security`, 공용 `adminSecurity.ts`, `class-room` 설명) + 웹 화면(관리자 설정, 수업 관리, 공용 상단 메뉴). Secrets·Notion 변경 없음.

---

## 항목 1. 마이그레이션과 함수

- **유형**: AI 자동(병합 시 자동 배포)
- **선행 조건**: v2.5.65 마이그레이션 `20261014010000_class_password.sql`이 적용돼 있어야 한다.
- **대상 파일**: `supabase/migrations/20261014020000_unify_admin_password.sql`, `supabase/functions/admin-security/index.ts`, `supabase/functions/_shared/adminSecurity.ts`, `supabase/functions/class-room/index.ts`(설명)
- **변경 내용**
  - 서버 작업 `class-owner`·`class-login`·`class-set`과 세션 종류 `class`를 없앴다. 남아 있던 수업용 로그인은 지워지고(선생님 기기의 수업방 로그인이 끝남), 보안 상태의 수업용 비밀번호 칸 5개를 삭제한다.
  - 수업 관리는 관리자 비밀번호로 로그인해 일반 관리자 세션(12시간)을 받는다. 관리자 세션은 원래 `class-room`을 부를 수 있었다.
  - 키오스크 세션은 시간으로 끝나지 않는다. 관리자 비밀번호 변경(모든 세션 해제), 키오스크의 로그아웃, 기기의 사이트 데이터 삭제 때만 끝난다. 이미 로그인된 키오스크도 그대로 유지된다.
  - 옛 수업방 화면(브라우저 캐시)이 `scope: 'class'`로 로그인하면 관리자 비밀번호 기준의 일반 관리자 로그인으로 처리된다.
- **검증**: `node tests/admin-security-sql.cjs`(PostgreSQL 118개: 수업용·30일 키오스크 세션이 있는 DB에 마이그레이션 적용 → 수업용 세션 삭제·키오스크 무기한·칸 삭제·`class` 세션 거부, 수업용 서버 작업 거부, 새 키오스크 로그인 무기한), Deno 테스트 191개(관리자 세션의 수업 관리 허용, `class` 종류는 어디도 못 엶, `class-set` 거부, 수업 관리 로그인이 관리자 로그인).
- **실패 시 대처**: 화면만 v2.5.81로 되돌리면 수업방은 수업용 로그인을 시도하지만 서버가 관리자 비밀번호로 처리하므로 관리자 비밀번호로 들어갈 수 있다. 마이그레이션은 칸 삭제가 있어 되돌리려면 v2.5.65 마이그레이션을 다시 적용하고 수업용 비밀번호를 새로 정해야 한다.

## 항목 2. 화면

- **유형**: AI 자동
- **대상 파일**: `admin_settings.html`·`admin_settings.js`(수업용 비밀번호 카드·화면 삭제, 안내 문구), `class_room.html`·`class_room.js`(이름 "수업 관리", 관리자 비밀번호 로그인), `assets/hada-shortcuts.js`·`assets/hada-ui.css`(메뉴에 [수업 관리], 폰 폭 아이콘), `admin_auth.js`(설명), 버전 표시가 바뀐 각 화면, `docs/DESIGN.md`, `docs/버튼-웹훅-매핑.md`, `docs/키오스크-처리-흐름.md`
- **변경 내용**
  - 상단 메뉴: [관리자 설정 | 법정 서류 | 학교 검색] [↗ 키오스크] [↗ 수업 관리]. 수업 관리는 새 탭으로 열린다. 700px 이하에서는 새 탭 링크가 각자의 아이콘(키오스크 태블릿, 수업 관리 책)만 보인다.
  - 수업 관리 주소는 그대로 `class_room.html`이다(Notion 수업 페이지 링크 `?session=`도 그대로).
  - 수업 관리 로그인 화면: "관리자 비밀번호를 입력하세요. 이 기기에서 12시간 동안 다시 묻지 않아요."
- **배포 순서**: 함수·마이그레이션과 화면이 함께 배포된다. 그 사이에 옛 수업방이 열려 있어도 관리자 비밀번호로 로그인할 수 있다.
- **검증(모의 데이터)**: 관리자 설정 1280·390(수업용 카드 없음, 메뉴 링크 순서·새 탭), 관리자 설정·법정 서류·학교 검색·키오스크 화면 검사(375 포함 넘침 없음, 메뉴 5개·아이콘 7개), 수업 관리 화면 흐름 검사(로그인 요청에 범위 없음), 디자인 규칙 검사, 회귀 가드.
- **미검증**: 실제 운영에서 마이그레이션 적용 후 키오스크가 로그인 상태로 유지되는지, 선생님 기기의 수업방이 로그인 화면으로 돌아가 관리자 비밀번호로 들어가지는지.

## 항목 3. 선생님 안내

- **유형**: 운영자 직접
- **방법**: 배포 뒤 선생님 기기의 수업방(이제 "수업 관리")은 로그인 화면으로 돌아간다. 관리자 비밀번호로 로그인하도록 안내한다(학원 안에서 직접, 채팅·Notion에 비밀번호를 적지 않는다). 12시간마다 다시 로그인한다.
- **주의**: 관리자 비밀번호를 아는 사람은 관리자 설정(비밀번호·웹훅 키 변경)과 법정 서류(원부·영수증 등 개인정보)도 열 수 있다.

## 항목 4. 키오스크 태블릿을 잃어버렸을 때

- **유형**: 운영자 직접
- **방법**: 키오스크 로그인은 시간으로 끝나지 않으므로, 태블릿을 잃어버리거나 다른 사람 손에 넘어가면 관리자 설정에서 관리자 비밀번호를 바꾼다. 모든 기기의 로그인(키오스크·관리 화면·수업 관리)이 해제되고, 남은 기기는 새 비밀번호로 다시 로그인한다. 키오스크 로그인으로는 등원·하원 체크만 할 수 있다.
