# v2.6.31 — 삭제(cascade-delete)를 누른 페이지 한 번으로

- 날짜: 2026-10-17
- 이전 버전: v2.6.30
- 요약:
  - 삭제가 하위 페이지(출석·학습기록·학습활동·교재배부·교재결제)에 `삭제 체크`를 켜지 않는다. 켜면 7개 DB의 "삭제 체크" 자동화가 하위마다 웹훅을 또 보내, 서버가 이미 지우고 있는 페이지를 다시 읽고 대기열 표시를 쓰고 큐에 다시 넣었다. 이제 누른 페이지 하나에서 하위까지 끝낸다.
  - 하위 페이지는 조회 결과를 그대로 써서 다시 읽지 않고, 🔄 작업중·✅ 완료 표시 없이 휴지통으로만 보낸다. 누른 페이지는 지금처럼 🔄 작업중을 보이고, 마지막에 ✅ 완료 쓰기와 휴지통 보내기를 한 번에 한다.
  - 자동화 본문에 `삭제 상태`가 실려 오면 그 값으로 "이미 처리 중"을 판단해 페이지를 다시 읽지 않는다.
  - 수업 1개(출석 6, 출석마다 학습활동 2, 그룹 진도 학습기록 2)를 지울 때 Notion 호출 약 150 → 약 40, 큐 항목 하위 수만큼 → 1개(코드를 읽어 센 추정).
  - 그대로인 것: 그룹 진도 학습기록은 지우지 않고 연결만 끊고, 다른 학생도 쓰는 학습기록은 이 학생만 뺀다. 수업 관리 복사본도 함께 지운다. 중간에 실패하면 큐가 누른 페이지부터 다시 하고, 이미 휴지통에 간 하위는 조회에서 빠져 남은 것만 지운다.
- 매뉴얼 영향: 없음(버튼 쓰는 법 그대로)
- 변경 유형: 함수(`_shared/cascadeDeleteTarget.ts`, `_shared/notionClient.ts`, `cascade-delete/index.ts`). Notion 변경 없음.
