# v2.6.3 — 배포 후 Notion 정리 (학습기록 단원·라이브러리 이름)

- 날짜: 2026-10-14
- 이전 버전: v2.6.2
- 요약: 새 코드가 올라간 뒤에 해야 하는 Notion 작업. 학습기록 단원을 단원목록 관계 하나로 바꾸고 [단원 입력] 버튼을 달고 기존 기록을 채운 뒤 예전 단원 수식을 지운다. 라이브러리 이름을 원본과 맞춘다.
- 매뉴얼 영향: 있음(v2.6.4에서 함께)
- 변경 유형: Notion 스키마·버튼·업무 데이터(학습기록 단원 관계 채우기). 코드·Supabase 변경 없음.
- Notion 작업 원문: [v2.6-노션-작업.md](v2.6-노션-작업.md) N-9~N-13

---

## 항목 1. 학습기록 단원 관계 (N-9)

- **유형**: AI 자동
- **선행 조건**: v2.6.2 배포·확인 완료(먼저 하면 v2.5.11 코드가 단원을 못 읽는다)
- **Notion 변경**: 학습기록(학원) DB
  1. 수식 `단원` → 이름 `단원(수식)`, 페이지에서 숨김
  2. (1이 끝난 뒤) 관계 `단원` 추가 → 대상 단원목록(학원) DB, 양방향 이름 `학습기록`, 설명·배치는 N-9 원문
- **이미 관계가 있으면**: 이름이 `선택 단원`이면 `단원`으로 바꾼다(코드는 둘 다 읽는다). 대상 DB가 다르면 멈추고 보고한다.
- **검증**: 학습기록 페이지 본문 탭 `주제` → `범위` → `단원` → `내용`. 수업 관리에서 기록을 열면 범위 아래 단원 고르기가 보인다.

## 항목 2. [단원 입력] 버튼 (N-10)

- **유형**: 운영자 직접(운영 AI가 버튼 동작을 만들 수 없으면)
- **선행 조건**: 항목 1
- **운영자 안내문**
  - 왜 필요한가: Notion에서 학습기록 범위를 넣고 한 번 누르면 단원이 채워진다.
  - 어디서: 학습기록(학원) DB → 속성 추가 → 버튼 `단원 입력` → 동작 "웹훅 보내기"
  - 무엇을: URL `https://<학원 Supabase 주소>/functions/v1/fill-record-units`, 헤더 `x-admin-key`에 다른 버튼과 같은 Notion 웹훅 키. 저장.
  - 입력할 값의 이름: Notion 웹훅 키(`ADMIN_SECRET`과 같은 값, 채팅에 붙이지 않는다)
  - 끝났는지 확인하는 방법: 범위가 있는 기록 하나에서 눌러 `단원`이 채워진다.
  - 흔한 오류와 대처: 401이면 헤더 키가 다르다. 단원을 찾지 못하면 라이브러리 화면에서 그 교재의 단원·시작쪽을 먼저 넣는다.

## 항목 3. 기존 기록 단원 채우기 (N-11)

- **유형**: AI 자동(업무 데이터 대량 변경 — 16-4 승인 재확인)
- **선행 조건**: 항목 2
- **무엇을**: `범위`가 있고 `단원` 관계가 빈 학습기록 건수를 먼저 보고하고 승인받은 뒤, 기록마다 `fill-record-units`를 한 번씩 부른다(웹훅 키는 서버 Secrets에서만 읽는다). 교재에 단원이 없는 기록은 건너뛰고 건수를 보고한다. 기록이 적으면 운영자가 버튼을 눌러도 된다.
- **검증**: 대상·채움·건너뜀 건수가 맞다. 학생 한 명의 [학생 페이지 동기화] 뒤 리포트 단원이 그대로 보인다.

## 항목 4. 예전 단원 수식 삭제 (N-12)

- **유형**: AI 자동 + 운영자 확인(운영 AI가 수식 원문을 읽지 못하면 운영자가 화면에서 확인)
- **선행 조건**: 항목 3
- **무엇을**: N-12의 수식 목록이 `단원(수식)`을 쓰지 않는지 확인하고 지운다. 쓰는 수식이 있으면 N-12의 빈 자리에 원문을 붙이고 관계 `단원` 기준으로 고친 뒤 지운다.
- **검증**: 학습기록 DB에 `단원(수식)`이 없고, 진도교재 `진행도`·출석 `일일 학습 현황` 등이 오류 없이 보인다.

## 항목 5. 라이브러리 이름 맞추기 (N-13, 권장)

- **유형**: AI 자동
- **선행 조건**: v2.6.2
- **Notion 변경**: 진도교재·교재배부·단원목록·과목 DB의 관계 `정규교재` → `라이브러리`, DB 제목 `정규교재(학원) DB` → `라이브러리(학원) DB`, 메뉴 페이지 이름. 학습기록 `교재`는 그대로.
- **검증**: 진도교재 `북커버`·`진행도`가 그대로 보이고, 라이브러리 화면 [라이브러리 열기]에 교재가 시리즈별로 보인다.
- **안 하면**: 코드는 옛 이름도 읽어 동작은 같다. 관리자 설정 웹훅 체크리스트(보안 모드)의 라이브러리 카드 DB 링크만 못 찾는다.
