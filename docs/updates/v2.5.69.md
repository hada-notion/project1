# v2.5.69 — 수업방 PC 화면과 칸 머리 정리

- 날짜: 2026-10-14
- 이전 버전: v2.5.68
- 요약: 수업방을 PC에서도 편하게 쓰도록 1081px 이상에서 넓게 편다. 오늘 수업은 수업 카드 2열과 오른쪽 보강 대기실 칸, 수업은 왼쪽 학생 목록과 오른쪽 학습기록 / 학생 공간 / 기록 카드 두 칸이다(하단 탭 없음, 두 칸 첫 카드 높이 같음, 저장 막대는 편집 중인 칸 아래, 대화상자는 가운데). 모든 폭에서 칸 머리를 리포트처럼 제목·집계 안내·탭 3줄로 줄여 본문을 올렸고, 학습기록에 [전체 · 학습 · 과제 · 평가] 탭을 넣었다. 학생 공간은 위(과제·평가, 보기)와 아래([메모 | 선생님 한마디] 탭, 편집)로 나눴다. 공용 토큰 `--side-w`(360px)를 추가했다. 이어서 정렬·간격·비율을 측정해 맞췄다: PC 모든 화면 같은 바깥 폭(왼쪽 선 고정), 두 칸 같은 폭·가운데 구분선, 제목 줄 32px 고정으로 첫 카드 시작선 통일, 칸 머리 버튼을 탭과 같은 32px 알약으로, 편집·↗ 자리 통일, 오늘 수업 3줄 머리와 [어제|오늘|내일|날짜] 탭(날짜 칩이 8px 처지던 문제 해결), 빈 상태 카드 안, 목록 줄 높이 통일, 저장 막대 16px 안쪽, 알림이 탭·저장 막대를 가리지 않게, 상단 바 아이콘 그림을 본문 선에.
- 매뉴얼 영향: 수업방 매뉴얼 작성 때 PC 두 칸 배치와 학생 공간 메모·한마디 탭 반영
- 변경 유형: 웹 화면만(Pages). 함수·Notion 변경 없음.

## 항목 1. 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.html`, `class_room.js`, `assets/hada-tokens.css`(토큰 1개 추가, 다른 화면 값은 그대로), 공용 CSS 버전 표시가 바뀐 화면들(`admin_settings.html`·`attendance_kiosk.html`·`school_search.html`·`legal_documents.html`, 내용 변화 없음), `docs/DESIGN.md`
- **동작 변화**: 저장·만들기 요청은 그대로다. 학생 공간에서 메모와 선생님 한마디는 탭으로 하나씩 보이며, 편집 중 탭을 바꿔도 입력한 내용은 저장 전까지 남는다. PC에서는 한 칸을 편집하는 중 다른 칸의 [편집]을 누르면 바뀐 내용을 버릴지 먼저 묻는다.
- **측정 결과(모의 데이터)**: 첫 제목은 모든 화면·폭에서 상단 바 아래 20px, 첫 카드는 학생 목록·학습기록·학생 공간(PC)·기록 카드 모두 191px, PC 본문 왼쪽 선은 모든 화면 58px(1280px), 두 칸 폭 558/558.
- **검증**: 디자인 검사, 화면 흐름 검사(모의 데이터, 390·768·1280: 넘침·글자 잘림·44px·저장 요청, 1280에서 하단 탭 없음·두 칸 첫 카드 높이 같음·저장 막대가 편집 칸 아래·선택 학생 강조, 학습기록 분류 탭, 메모·한마디 각각 저장), 다른 화면 UI 검사, 회귀 가드.
- **미검증**: 실제 Notion 데이터로 수업방을 연 확인(수업용 비밀번호 설정 후 원본 테스트 수업으로 진행 예정).
- **실패 시 대처**: v2.5.68의 `class_room.html`·`class_room.js`로 되돌린다. 추가 토큰은 다른 화면이 쓰지 않는다.
