## 항목 1. Notion 변경 — 학교(학원) DB에 "학교 검색" formula 속성 추가

- **유형**: AI 자동
- **선행 조건**: 없음
- **변경 이유·증상**: "교육청 코드"/"학교 코드" 속성은 있어도, 그 값을 찾아 채우기 위한 검색 링크가 없으면 운영자가 코드를 직접 알아내 입력해야 합니다.
- **대상 코드**: 없음 (Notion 스키마 변경)
- **Notion 변경**: "학교(학원) DB"에 아래 속성이 이미 있으면 건너뛰고, 없으면 추가합니다.
  - formula **학교 검색** (결과 타입: 텍스트), 수식:

    ```
    link("학교 검색·연결", "https://hada-notion.github.io/project1/school_search.html?pageId=" + id())
    ```

  - 뷰: 기존 뷰 또는 "학교 검색·연결" 뷰에 이 속성을 표시하면 운영자가 바로 클릭해 찾을 수 있습니다(선택 사항).
- **환경별 값**: 없음 (URL은 공용 GitHub Pages 주소, 환경별로 바뀌지 않음)
- **필요한 Secret (이름만)**: 없음
- **마이그레이션 / 재배포**: 없음
- **검증**:
  1. 학교 DB에 "학교 검색" 속성이 존재하는지 확인한다.
  2. 테스트용 학교 페이지에서 "학교 검색" 링크를 열어 school_search.html로 정상 연결되는지 확인한다.
- **실패 시 대처**: 속성이 없어도 기존 기능(학사일정 동기화 등)에는 영향이 없습니다. 재시도만 하면 됩니다.
- **매뉴얼**: 변경 없음
