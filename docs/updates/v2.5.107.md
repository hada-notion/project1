- **동작**: 옅은 글자 `#8B95A1` → `#68727F`. 흰 바탕 대비 3.04 → 4.88, 캔버스 2.86 → 4.59, 연한 카드 2.87 → 4.61(글자 기준 4.5 이상). 키오스크 입력 안내·학원 이름, 리포트 하단 탭·날짜 라벨·요일, 수업 관리 빈 상태 문구 등 모든 화면의 옅은 글자가 조금 진해진다. 리포트 빈 상태 문구 등의 `#aaa`·`#bbb`도 같은 색으로.
- **검증(모의 데이터)**: 규칙 점검(`RULES=1`)에서 관리 화면 4개의 글자 대비 부족 0건(Notion 화면 흉내 그림 제외), 리포트·수업 관리 검사.
