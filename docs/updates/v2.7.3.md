# v2.7.3 — 배포 후 Notion 작업 (버튼·자동화)

- 날짜: 2026-10-17
- 이전 버전: v2.7.2
- 요약: 상태 속성·버튼·자동화 이름과 `실시간 처리 상태` 수식을 표준 이름(`docs/이름-규칙.md`)으로 맞추고, 버튼과 자동화를 v2.7 방식으로 바꾼다. 서버 대신 Notion이 하거나(서버 0번), 한 건씩 큐로 보내고, 수식 계획을 본문에 실어 서버는 쓰기만 하게 한다. 시험정보로 가는 관계 이름 `시험범위`를 `시험정보`로 바꾼다.
- 매뉴얼 영향: 있음(v2.7.4)
- 변경 유형: Notion 버튼·자동화·속성 이름(운영자 직접). 코드 변경 없음.
- **선행 조건: v2.7.2 배포 확인.** 버튼을 바꾸기 전에 그 버튼이 쓰는 속성·수식(v2.7.1)이 있어야 한다.

---

## 순서와 원칙

- 묶음 하나씩 끝내고 그 묶음의 "확인"을 본 뒤 다음으로 간다. 아직 안 바꾼 버튼은 예전 웹훅으로 계속 동작한다.
- 한 묶음 안에서는 **속성 → 수식 → 자동화 → 버튼** 순서. 버튼을 먼저 바꾸면 받을 자동화가 없어 아무 일도 일어나지 않는다.
- 웹훅 주소와 키는 관리자 설정 → 웹훅 체크리스트의 각 항목에서 복사한다(값을 문서·채팅에 쓰지 않는다). 주소 끝의 경로(`/queue` 등)를 빠뜨리지 않는다.
- 상태를 ⚪ 대기로 바꾸는 자동화는 끝에 ✅ 완료(또는 비우기) 동작을 꼭 넣는다.
