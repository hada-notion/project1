# v2.6.28 — 클래스 [월 수강료 생성]을 Notion 자동화로 (서버 호출 0)

- 날짜: 2026-10-17
- 이전 버전: v2.6.27
- 요약: 클래스 [월 수강료 생성]이 서버 없이 Notion 자동화로 수강료를 만든다. 버튼이 "발송함 기간 안에 수강 중이고 그 달 수강료가 아직 없는 등록"의 `수강료 생성 상태`를 ⚪ 대기로 바꾸면, 등록 DB 자동화가 수강료 페이지(청구명·청구기간·등록·실제 수업량·발송함·알림톡 설정·일괄전송 선택)를 만들고 ✅ 완료로 바꾼다. 예전 서버 방식(7명 기준 약 20 호출)과 같은 값이다(원본 대조). 클래스 월간 수업 총량이 비었거나 발송함 구분이 "수강료"가 아니면 아무도 고르지 않는다(v2.6.25와 같은 조건).
- 매뉴얼 영향: 있음 → 아래 "매뉴얼"
- 변경 유형: Notion 속성 1개·버튼 1개·자동화 1개(운영자 직접), 관리자 설정 웹훅 체크리스트(표시만). 서버 코드 변경 없음. 예전 `generate-tuition` 웹훅도 그대로 동작한다.

## 항목 1. 등록(학원) DB 속성

- **유형**: 운영자 직접(원본에는 있음)
- 선택 속성 `수강료 생성 상태`: ⚪ 대기 / ✅ 완료. 등록 페이지에서는 숨긴다.

## 항목 2. 등록(학원) DB 자동화 "수강료 생성"

- **유형**: 운영자 직접
- 트리거: `수강료 생성 상태`가 `⚪ 대기`로 편집됨
- 동작 1: 수강료(학원) DB에 페이지 추가

| 속성 | 값 |
| --- | --- |
| 청구명 | 아래 수식 |
| 청구기간 | `context("페이지 실행").prop("클래스").first().prop("수강료 생성 대상").first().prop("기간")` |
| 등록 | 페이지 실행 |
| 실제 수업량 | `context("페이지 실행").prop("클래스").first().prop("월간 수업 총량")` |
| 알림톡 발송함 | `context("페이지 실행").prop("클래스").first().prop("수강료 생성 대상")` |
| 알림톡 설정 | 알림톡 설정(학원) DB의 "수강료 안내" 행 |
| 일괄전송 선택 | 체크 |

청구명("26.10 학생 수강료")
```
lets(
  batch, context("페이지 실행").prop("클래스").first().prop("수강료 생성 대상").first(),
  formatDate(dateStart(batch.prop("기간")), "YY.MM") + " " + context("페이지 실행").prop("학생이름(등록)").format() + " 수강료"
)
```
- 동작 2: 페이지 실행 편집 — `수강료 생성 상태` = `✅ 완료`
- **동작 2를 빠뜨리지 않는다.** 빠지면 상태가 ⚪ 대기로 남아, 다음 달에 버튼이 같은 값으로 바꿔도 자동화가 돌지 않아 그 학생 수강료가 만들어지지 않는다(원본 시험에서 확인). 이미 ⚪ 대기로 남은 등록은 상태를 비운 뒤 다시 누른다.

## 항목 3. 클래스(학원) [월 수강료 생성] 버튼

- **유형**: 운영자 직접. 웹훅 보내기를 지우고:
  - 변수 `대상등록`
```
lets(
  batch, context("이 페이지").prop("수강료 생성 대상").first(),
  startN, toNumber(formatDate(dateStart(batch.prop("기간")), "YYYYMMDD")),
  endN, toNumber(formatDate(dateEnd(batch.prop("기간")), "YYYYMMDD")),
  monthN, toNumber(formatDate(dateStart(batch.prop("기간")), "YYYYMM")),
  ready, if(empty(context("이 페이지").prop("월간 수업 총량")), false, format(batch.prop("구분")) == "수강료"),
  context("이 페이지").prop("등록").filter(
    ready
    and empty(current.prop("등록일")) == false
    and toNumber(formatDate(current.prop("등록일"), "YYYYMMDD")) <= endN
    and if(empty(current.prop("종료일")), true, toNumber(formatDate(current.prop("종료일"), "YYYYMMDD")) >= startN)
    and current.prop("월별 수강료").filter(
      if(empty(current.prop("청구기간")), false, toNumber(formatDate(dateStart(current.prop("청구기간")), "YYYYMM")) == monthN)
    ).length() == 0
  )
)
```
  - 페이지 편집 — `var("대상등록")`: `수강료 생성 상태` = `⚪ 대기`
- 발송함 `기간`은 그 달 1일~말일로 넣는다.
- **확인**: 그 달 수강료가 없는 수강생에게만 하나씩 생기고, 다시 눌러도 늘지 않는다.
- 수식 주의는 v2.6.27 "수식 주의"와 같다(`or` 대신 `if(empty(…))`, 날짜는 숫자로 비교).

## 매뉴얼

- 월 수강료 생성: "클래스의 [월 수강료 생성]을 누르면 '수강료 생성 대상' 발송함의 달에 수강한 학생 중 그 달 수강료가 없는 학생에게만 수강료가 바로 생겨요. 아무것도 안 생기면 클래스의 월간 수업 총량과 연결한 발송함(구분: 수강료, 기간)을 확인해 주세요."
