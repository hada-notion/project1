# v2.7 — v2.6.5 이후 원본 변경을 한 번에 (개요)

- 날짜: 2026-10-17
- 이전 버전: v2.6.5 (v2.6 묶음, 운영에 마지막으로 나간 버전)
- 요약: 원본에서 v2.6.6~v2.6.32로 나눠 고친 것을 운영 적용 단위로 다시 묶었다. 중간에 넣었다 바꾼 단계는 빼고, v2.6.5와 지금의 차이만 적었다. v2.6.6~v2.6.32 지침 파일은 지웠다(세부 경과는 Git 이력).
- 중심 내용: **웹훅 재정리(Notion API 호출 줄이기)**. Notion이 할 수 있는 일은 Notion 버튼·자동화로, 여러 건을 한꺼번에 하는 일은 한 건씩 나눠 큐로, 무엇을 만들지는 Notion 수식이 계산하고 서버는 쓰기만 한다. 함께 라이브러리 교보문고 가져오기, 수업 관리 학습활동 편집이 들어 있다.
- 매뉴얼 영향: 있음 → [Notion 작업 목록](v2.7-노션-작업.md) N-30, v2.7.4

## 왜 나눴나

v2.6과 같다. 코드는 v2.7.2 한 커밋으로 넘어가고, Notion 작업을 배포 전(속성·수식)과 배포 후(버튼·자동화)로 나눴다. 속성·수식은 v2.6.5 코드가 읽지 않아 먼저 해도 안전하고, 버튼·자동화는 v2.7 함수의 새 주소를 부르므로 배포 뒤에 한다. 배포 후 항목은 하나씩 해도 되고, 아직 안 바꾼 버튼은 예전 웹훅으로 계속 동작한다.

| 버전 | 내용 | 코드 배포 | 주로 하는 사람 |
| --- | --- | --- | --- |
| [v2.7.1](v2.7.1.md) | Notion 사전 작업: 속성 추가, 수식 추가·교체(N-1~N-12) | 없음 | 운영 AI + 운영자 |
| [v2.7.2](v2.7.2.md) | 코드 배포(한 커밋): 함수 15개와 공용 코드, 화면 파일 7개, 관리자 웹훅 체크리스트 | 함수·Pages | 운영 AI |
| [v2.7.3](v2.7.3.md) | 배포 후 Notion: 버튼·자동화 바꾸기, 속성 이름 `시험범위` → `시험정보`(N-13~N-29) | 없음 | 운영자 |

- **v2.7.2는 학원 수업이 없는 시간에** 한다(한 커밋을 올리면 Pages가 함수 배포보다 먼저 끝날 수 있다).
- v2.7.1은 며칠 전에 미리 해도 된다. v2.7.3은 v2.7.2 배포 확인 뒤. v2.7.4는 v2.7.3 뒤.
- 새 마이그레이션·새 Secrets·지울 파일은 없다.

### 서버만 바뀌는 것 (운영자 할 일 없음)

- 페이지 만들기 재시도로 같은 페이지가 두 번 생기던 일 막기(5xx·연결 끊김은 다시 보내지 않음, 큐는 계획 없이 다시 읽어 빠진 것만).
- 출석을 지울 때 이 학생만의 학습기록만 지우고, 반이 같이 쓰는 학습기록(그룹 진도·주제 기록)은 이 학생 연결만 끊는다.
- 수업 없는 출석(보강 대기실)으로는 학습기록을 만들지 않는다(보강 수업을 만들어 배정).
- 학부모 리포트·보고서 날짜를 출석 날짜 기준으로(학습기록·학습활동은 출석 관계로, 과제 마감일은 마감 출석 날짜).
- 보고서·수강료 생성(예전 웹훅)의 설정 문제(발송함 미연결·구분·기간, 월간 수업 총량 없음)를 ⚠️ 오류와 `마지막 오류`로 표시.
- 학습활동 계획 값이 잘리면 학습기록을 다시 읽음.
- 관계가 25개를 넘어 잘린 목록을 고쳐 쓰지 않음(잘렸을 때만 끝까지 읽음).
- 웹훅 본문 전체를 로그에 남기던 곳을 페이지 id·키 이름만 남기게.

### 화면

- **라이브러리**: 교보문고 [교재 가져오기] 즐겨찾기(키 없이, 책 상세 한 권 또는 검색 목록에서 체크한 20권까지), [가져온 정보 붙여넣기], 외국도서 ISBN·표지, [빼기]·[선택 비우기].
- **수업 관리**: 학습기록 카드 펼치기에서 학습활동 보기·바로 고치기(과제 상태 3단계 제출·일부·미제출, 내부 메모), 학생 탭 연락처 정리(이름 = 학생 보고서, ↗ = Notion).
- **학부모 리포트**: 과제 "일부 제출" 노란 알약.
- **관리자 설정**: 웹훅 체크리스트를 새 버튼·자동화 주소에 맞춤. 웹훅이 없어진 항목은 빼고, 아직 예전 버튼을 쓰는 학원을 위한 항목은 "(예전 방식)"으로 남김(39개).

## 원본에서 거쳤지만 운영에 적용하지 않는 것

v2.7 문서에는 최종 상태만 적었다. 아래는 이력을 찾다가 헷갈리지 않도록 적어 둔다.

- 수업 날짜 이동을 Notion 자동화가 출석 날짜를 직접 바꾸는 방식(v2.6.17): 출석 이름이 바뀌지 않아 서버 방식(v2.6.18)으로 바꿨다. 운영은 처음부터 서버 방식(N-20).
- 학습활동 `수업일`·`과제 마감일`에 9시간 더하기(v2.6.17): 적용하지 않는다. 오히려 학습기록 `수업일`의 9시간 더하기를 뺀다(N-5).
- `출석 조정 정보` 수식은 v2.6.11 → v2.6.17(보강) → v2.6.21(`books`)로 세 번 바뀌었다. 운영은 마지막 수식 하나(N-8).
- 클래스 [교재 생성]의 이어달리기, 발송함 [일괄 전송]의 10건씩 이어달리기, 클래스 `교재 생성 상태`·수업 `보고서 일괄전송 상태`·등록 `종료 상태`·`등록 상태`: 더 쓰지 않는다(지우지 않아도 됨).
