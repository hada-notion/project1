## 항목 2. 운영 Notion 자동화와 대조 (확인만)

- **유형**: 운영자 직접
- **선행 조건**: 항목 1
- **운영자 안내문**
  - 왜 필요한가: 체크리스트는 원본 템플릿 기준이다. 운영 워크스페이스의 자동화 개수가 다르면 키를 바꿀 곳을 빠뜨릴 수 있다.
  - 어디서: 각 DB 오른쪽 위 번개 모양(자동화) 목록.
  - 무엇을:
    1. 대시보드(학원) DB: 웹훅 자동화 2개(날짜 속성 편집, 페이지 추가)가 있는지 본다.
    2. 정규교재(학원)·일정(학원) DB: 웹훅 자동화 2개(속성 편집, 페이지 추가)가 있는지 본다.
    3. 수업·출석·학습기록·학습활동·교재비·교재배부·교재결제 DB: "삭제 체크"가 체크됨일 때 웹훅을 보내는 자동화가 있는지 본다.
  - 입력할 값의 이름: 없음
  - 끝났는지 확인하는 방법: 위 자동화가 모두 있고, 다르면 운영 AI에게 차이를 알렸다.
  - 흔한 오류와 대처: 개수가 다르면 키를 바꿀 때 체크리스트 항목과 실제 자동화를 직접 대조한다.
