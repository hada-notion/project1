# v2.6.32 — 관계 25개 잘림 막기(삭제·예전 종료 처리)

- 날짜: 2026-10-17
- 이전 버전: v2.6.31
- 요약:
  - Notion은 페이지 읽기와 DB 조회 모두 관계를 25개까지만 돌려주고 "더 있음(has_more)"만 표시한다. 그 목록에서 하나를 빼고 통째로 다시 쓰면 26번째부터의 연결이 지워진다.
  - 이렇게 다시 쓰는 곳 세 군데를, 목록이 잘렸을 때만 그 속성을 끝까지 읽은 뒤 쓰도록 고쳤다. 25개 이하면 호출이 늘지 않는다.
    1. 출석 삭제(출석 조정의 중복 정리, 종료 처리 포함) 때 반 전체 학습기록의 `출석`·`등록`에서 그 학생만 빼기 — 26명 이상 반에서 나머지 학생 연결이 지워질 수 있었다.
    2. 예전 종료 처리(`sync-registration-end`, 아직 옮기지 않은 운영)의 수업 `등록` 명단에서 빼기, 공용 학습기록 연결 해제.
    3. 공용 함수 `addRelation`(지금 쓰는 곳 없음).
  - 실제로 연결이 지워진 일이 있었는지는 확인하지 못했다(원본 반은 25명 이하).
