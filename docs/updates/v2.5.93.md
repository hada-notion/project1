# v2.5.93 — 수업 관리 캘린더 접기·출석 체크 탭·학생 명부

- 날짜: 2026-10-14
- 이전 버전: v2.5.92
- 요약: 캘린더에서 날짜를 고르면 학부모 리포트처럼 주로 접히고 그 아래에서 출석 체크·과제 점검·학습 기록을 처리한다. 학생 탭은 출석·과제 검사 대신 반 학생 명부(학교·학년·연락처·학생 보고서 링크)로 바꾸고, 학생 보고서와 겹치던 학생 공간 화면은 없앴다.
- 매뉴얼 영향: 수업 관리 매뉴얼 작성 때 출석 체크 위치(캘린더 → 날짜 → 출석 체크, 또는 홈 등원 칸), 학생 명부·학생 보고서 링크 설명(원본 Notion 메뉴얼 반영은 따로 승인)
- 변경 유형: 웹 화면(Pages) + class-room 함수(읽기 조회 추가). Notion 구조·DB 변경 없음.

## 항목 1. class-room 함수: 학생 명부 조회

- **유형**: AI 자동(`main` 병합 시 "Deploy Supabase Functions"가 자동 배포)
- **대상 파일**: `supabase/functions/_shared/classRoom.ts`, `supabase/functions/_shared/classRoom_test.ts`
- **변경**: 새 동작 `roster`(수업 ID): 이 수업 출석 학생마다 이름·학교(설문)·학년(설문)·학생 연락처(등록의 "학생정보" 원생 페이지, 리포트와 같은 속성), 우선 연락처(등록의 "학부모 연락처" = 알림톡 우선 연락 대상), 학생 보고서 토큰(등록의 "토큰", 꺼져 있으면 주지 않음). Notion은 읽기만 한다. 학생 탭을 열 때만 부른다.
- **개인정보**: 연락처·보고서 토큰은 관리자 비밀번호로 로그인한 수업 관리 화면에만 내려가고, 저장소·로그에는 남지 않는다.
- **검증(모의 데이터)**: `classRoom_test.ts` 18개 통과(원생 페이지 값, 우선 연락처, 토큰, 꺼진 토큰, 원생 연결 없음, 잘못된 ID). 전체 함수 테스트 193개, `deno check`.
- **원문 확인**: 학생 보고서는 열 때 `get-report-fast`·`get-report-detail`(캐시 읽기)만 부르고, 동기화(`sync-report-cache`)는 보고서의 새로고침 버튼을 눌렀을 때만 돈다 — 선생님이 열어도 열람 기록·동기화가 생기지 않는다(코드 확인, 실환경 미확인).
- **미검증**: 운영 Notion 데이터로 응답(원생 페이지 속성 값 형태).
- **실패 시 대처**: v2.5.92의 `classRoom.ts`와 화면으로 되돌리고 `main`에 병합(자동 재배포).

## 항목 2. 수업 관리 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`, `class_room.html`, `docs/DESIGN.md`("수업 관리 규칙")
- **화면**

  | 화면 | 내용 |
  |---|---|
  | 캘린더 탭 | 처음엔 월간(출석 색·범례). 날짜를 누르면 그 수업으로 가며 그 주 한 줄로 접히고 [⌄ 월 전체 보기] · 그날 머리(등원 n/전체) · [출석 체크 \| 과제 점검 \| 학습 기록]. 같은 주 다른 날을 누르면 그 수업으로(탭 유지). 뒤로가기는 월간으로 |
  | 출석 체크 | 기존 학생 목록 출석(한 줄, [편집]·저장, 메모 아이콘) |
  | 과제 점검 | 기존 과제 검사(제출·미제출, [전원 제출]) |
  | 학습 기록 | 그 수업 기록 카드 + [이 수업에 기록 만들기] |
  | 메모 창 | [메모 \| 선생님 한마디] 전환, 바뀐 칸만 바로 저장(한마디는 학생 공간에서 옮김) |
  | 학생 탭 | 명부: 이름·학교·학년, 학생/우선 연락처(누르면 전화), ↗ 학생 보고서 새 탭(꺼짐·없음 안내) |
  | 홈 | 등원·과제 제출 칸을 누르면 캘린더 출석 체크·과제 점검으로. 마감 과제 줄도 과제 점검으로 |

- **바뀐 동작**
  - 학생 공간(학생 이름을 눌러 열던 과제 현황·평가·메모 화면)은 없앴다. 같은 내용은 학생 보고서(새 탭)에서, 메모·한마디는 출석 체크의 메모 창에서.
  - Notion 수업 페이지 링크(`?session=`)로 열면 학생 탭 대신 캘린더가 그 날짜로 접힌 채 출석 체크가 열린다.
- **검증(모의 데이터)**: 수업 관리 화면 흐름 검사 390·768·1280 통과 — 월간 → 날짜 누르면 주 한 줄·세 탭·등원 머리, 뒤로 → 월간(고른 수업 유지), [월 전체 보기], 접힌 주의 학습 기록 탭, 홈 등원 칸 → 출석 체크·뒤로 홈, 마감 과제 줄 → 과제 점검, 출석 편집·저장, 메모 창 메모 빠른 입력·저장, 한마디 탭(빠른 입력 없음, 탭 오가도 글자 유지, 한마디만 저장), 과제 전원 제출·저장, 학생 명부(학교·학년, tel: 링크, 보고서 새 탭 주소, 꺼짐·없음 안내), `?session=` → 캘린더 출석 체크, 기존 흐름 전체, 가로 넘침·버튼 44px·글자 잘림. 디자인 규칙 검사, 회귀 가드.
- **미검증**: 운영 데이터·실제 휴대폰 화면, 실제 전화 걸기, 학생 보고서 새 탭 열기(운영 토큰).
- **실패 시 대처**: v2.5.92의 `class_room.js`·`class_room.html`로 되돌린다.
