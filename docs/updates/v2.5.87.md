- 매뉴얼 영향: 수업 관리 매뉴얼 작성 때 첫 화면·사이드바·반 상세 탭 설명(원본 Notion 메뉴얼 반영은 따로 승인)

## 항목 1. class-room 함수: 클래스 목록에 이번 주 수업·학생 수

- **유형**: AI 자동(`main` 병합 시 "Deploy Supabase Functions"가 자동 배포)
- **대상 파일**: `supabase/functions/_shared/classRoom.ts`, `supabase/functions/_shared/classRoom_test.ts`
- **변경**: `classes` 응답의 반마다 `week`(기준일이 있는 주 월~일의 수업: id·날짜·시간), `students`(기준일에 가장 가까운 수업 — 오늘 → 다음 → 지난 — 의 출석 학생 수), `next`·`last`에 `time`을 더했다. 기존 값은 그대로이고 Notion은 읽기만 한다(추가 조회 없음).
- **검증(모의 데이터)**: `classRoom_test.ts` 16개 통과(이번 주 범위가 월요일에 시작하는지, 지난주 수업이 빠지는지, 학생 수, 시간). 전체 함수 테스트 191개 통과, `deno check`.
- **미검증**: 운영 Notion 데이터로 실제 응답.
- **실패 시 대처**: v2.5.86의 `classRoom.ts`로 되돌리고 `main`에 병합(자동 재배포). 화면은 `week`·`students`가 없어도 빈 시간표·0명으로 열린다.

## 항목 2. 수업 관리 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`, `class_room.html`, `docs/DESIGN.md`("수업 관리 규칙")
- **화면**

  | 화면 | 내용 |
  |---|---|
  | 첫 화면 | "수업 관리" / 강사 이름 / "역할 · 담당 클래스 n개" / 클래스 카드(배지: 오늘 수업 "오늘 17:00", 아니면 다음 수업 "수 19:00" 또는 날짜) / 보강 대기실(대기 인원). 오른쪽 위 새로고침·☰. 아래로 내리면 이번 주 시간표(수업을 누르면 그 수업으로) |
  | ☰ 사이드바 | 강사 이름·역할, 담당 클래스·학생(반별 합)·이번 주 수업 수, [강사 바꾸기](사이드바 안에서 고름), [보강 대기실], [이 기기에서 로그아웃] |
  | 반 상세 · 홈 | 반 이름 머리(선생님 · 요일 시각, ↗ Notion 수업), 보고 있는 수업 + ‹ ›(같은 반 이전·다음 수업), 그날 등원·과제 제출·다음 수업, 그날 마감 과제(누르면 학생 탭 과제 검사), 이 수업 학습기록 |
  | 교재 | 이 수업 학생들의 교재 카드 [진행 중 \| 전체]. 누르면 그 교재로 기록 만들기 |
  | 캘린더 | 이 반 수업 달력. 출석 색(모두 출석 초록, 결석·보강 있음 빨강, 미입력 노랑, 예정 테두리), 오늘 빨간 테두리. 날짜를 누르면 그 수업으로 바꾸고 아래에 그날 요약·[이 수업 학생 보기]·학습기록 |
  | 학습기록 | 기존 목록 + 오른쪽 아래 [+ 기록 만들기] |
  | 학생 | 기존 학생 목록 [출석 \| 과제 검사], 메모, 이름 → 학생 공간 |

- **바뀐 동작**
  - 상단 ≡(클래스 서랍)·📅(날짜 서랍)와 하단 가운데 [+]는 없앴다. 반 고르기는 첫 화면 카드·주간 시간표, 날짜 이동은 홈 ‹ ›·캘린더 탭, 기록 만들기는 학습기록 탭 [+]·교재 탭.
  - 처음 열면 오늘 수업 대신 첫 화면이 열린다. Notion 수업 페이지 링크(`?session=`)로 열면 그 수업의 학생 탭이 열린다.
  - 뒤로가기: 창·사이드바 → 닫힘, 다른 탭 → 홈(탭은 쌓지 않음, 고른 수업 유지), 홈 → 첫 화면, 학생 공간·기록 카드·보강 대기실 → 들어오기 전 화면, 첫 화면에서는 페이지를 나간다. 같은 반 안에서 수업만 바꾸면(‹ ›·캘린더) 방문 기록을 쌓지 않는다.
- **검증(모의 데이터)**: 수업 관리 화면 흐름 검사 390·768·1280 통과 — 첫 화면(빈 강사 안내, 카드 순서·배지, 주간 시간표), 사이드바(숫자, 강사 바꾸기, 뒤로 닫힘), 반 상세 5탭·경로·머리, 홈 요약·‹ ›, 뒤로가기(탭 여러 번 오간 뒤 뒤로 한 번 홈·한 번 더 첫 화면, 앞으로 가기 무시, ‹ › 뒤 뒤로 첫 화면, 캘린더 날짜 바꾼 뒤 뒤로 홈에서 그 수업 유지), 캘린더 출석 색·달 이동·[오늘], 교재 탭 [진행 중/전체]·카드 → 기록 만들기(교재 선택됨), 홈 과제 → 학생 탭 과제 검사, 기존 흐름 전체(출석·과제 편집 저장, 메모, 학생 공간, 기록 만들기·글머리, 기록 카드 교재·점수, 보강 대기실·보강 수업 만들기, 오늘이 아닌 수업 확인), `?session=` 링크, 가로 넘침·버튼 44px·글자 잘림. 디자인 규칙 검사, 회귀 가드, 관리자 설정·리포트 화면 검사.
- **미검증**: 운영 데이터·실제 휴대폰에서의 화면과 뒤로가기, 반이 많을 때(10개 이상) 주간 시간표 칸 높이.
- **실패 시 대처**: v2.5.86의 `class_room.js`·`class_room.html`로 되돌린다(함수는 새 값을 더하기만 해서 그대로 둬도 된다).
