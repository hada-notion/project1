# v2.5.8 — 웹페이지 주소 표와 알림톡 버튼 URL

- 날짜: 2026-10-06 (Asia/Seoul)
- 이전 버전: v2.5.7
- 요약: 학원 화면 주소와 솔라피 버튼에 붙일 글자를 기준 주소 1행에서 만듭니다. 알림톡 설정 DB와 실행 코드는 바꾸지 않습니다.
- 매뉴얼 영향: 있음 → 메뉴얼 1절과 최초 설치 절의 안내 문장
- 작성자·출처: 강인희 요청·승인, Notion AI 프링글스 작성.
- 변경 유형: 스키마, 매뉴얼, 원본 표 데이터. 실행 코드·Supabase·Secrets·GitHub Pages 재배포 없음.

> 이 표는 주소를 보여 주고 복사할 글자를 만듭니다. 솔라피 버튼, 발송 코드의 `REPORT_PATH`, 등록 DB 안내 링크, 학교 검색 수식을 자동으로 바꾸지 않습니다. 원본 주소를 운영에 그대로 복사하지 않습니다.

## 항목 1. 웹페이지 DB 만들기

- **유형**: AI 자동
- **선행 조건**: 운영 소유자의 전체 계획 승인. 같은 역할의 DB가 이미 있으면 새로 만들지 않고, 속성·수식·행이 아래와 같은지만 확인한다. 다르면 추정해 겹치지 않고 중단한다.
- **변경 이유·증상**: 버튼 URL은 도메인 뒤에 `#{페이지ID}`만 붙는 글자다. 화면 주소는 저장소와 파일명이 포함된 클릭 링크다. 규칙이 다르므로 알림톡 설정 DB에 버튼 URL 수식을 넣지 않는다.
- **대상 Notion**: 웹페이지(학원) DB. 새 메뉴 페이지는 만들지 않는다. 원본 DB는 공개 DB 페이지에 두고, 보는 표는 메뉴얼 1절에 연결한다.
- **속성**:
  - `이름`: 제목
  - `순서`: 숫자. 기준 주소 1, 버튼 URL 6.
  - `파일명`: 텍스트. 화면 행에만 고정 파일명. 기준 주소 행과 버튼 URL 행은 비움.
  - `깃허브 URL`: 텍스트. 기준 주소 행에만 입력. 형식은 `https://계정.github.io/저장소`. 끝 슬래시는 있어도 된다.
  - `기준`: 같은 DB를 가리키는 관계, 1개 제한. 화면 행과 버튼 URL 행만 기준 주소 행을 가리킨다.
  - `페이지 주소`: 수식. 별도 버튼 URL 속성은 만들지 않는다.
- **행**:
  1. 기준 주소
  2. 학생 보고서, 파일명 `student_report.html`
  3. 출결 키오스크, 파일명 `attendance_kiosk.html`
  4. 학교 검색, 파일명 `school_search.html`
  5. 관리자 서류, 파일명 `legal_documents.html`
  6. 버튼 URL, 파일명 없음, 기준 주소 행을 관계로 연결
- **페이지 주소 수식**:

```txt
ifs(
	not empty(prop("깃허브 URL")),
	lets(
		raw, prop("깃허브 URL").trim().replaceAll("/+$", ""),
		base, if(empty(raw), "", if(raw.contains("://"), raw, "https://" + raw)),
		if(empty(base), "", link(base, base))
	),
	not empty(prop("파일명")) and not empty(prop("기준")),
	lets(
		raw, prop("기준").first().prop("깃허브 URL").trim().replaceAll("/+$", ""),
		base, if(empty(raw), "", if(raw.contains("://"), raw, "https://" + raw)),
		if(empty(base), "", link(base + "/" + prop("파일명"), base + "/" + prop("파일명")))
	),
	not empty(prop("기준")),
	lets(
		raw, prop("기준").first().prop("깃허브 URL").trim().replaceAll("/+$", ""),
		noScheme, raw.replaceAll("^https://", "").replaceAll("^http://", ""),
		host, noScheme.split("/").first(),
		if(empty(host), "", "https://" + host + "/#{페이지ID}")
	),
	""
)
```

- **표 보기**: 메뉴얼 연결 표는 `순서`, `이름`, `페이지 주소`만 보인다. `깃허브 URL`은 표에서 숨기고 기준 주소 행에서만 입력한다.
- **환경별 값**: 기준 주소 행에만 해당 운영의 `https://계정.github.io/저장소`를 넣는다. 원본 주소를 복사하지 않는다. 학생별 token은 넣지 않는다.
- **필요한 Secret (이름만)**: 없음
- **마이그레이션 / 재배포**: 없음
- **검증**: 기준 주소를 입력한 뒤 2번은 `기준/파일명` 클릭 링크, 6번은 `기준 도메인/#{페이지ID}` 글자인지 확인한다. 6번을 링크로 만들면 `#{페이지ID}`가 깨질 수 있으므로 글자로 둔다.
- **실패 시 대처**: 파일명·관계·수식 결과가 위와 다르면 해당 학원 적용을 중단한다. 알림톡 설정·발송 기록·실행 코드는 건드리지 않는다.
- **매뉴얼**: 항목 2.

## 항목 2. 메뉴얼 안내 문장

- **유형**: AI 자동
- **선행 조건**: 항목 1 완료.
- **대상**: 메뉴얼 1절, 웹페이지 주소를 안내하는 문단과 최초 설치 절. 다른 절·링크는 보존한다.
- **찾을 원문**:

```txt
평소에는 주소를 직접 입력하기보다 Notion에 만들어진 링크와 버튼을 사용하면 됩니다.
```

- **바꿀 원문**:

```txt
평소에는 주소를 직접 입력하기보다 아래 표의 링크를 사용하면 됩니다.
```

- 위 문장 바로 아래에 안내 콜아웃과 웹페이지 DB 연결 표를 둔다. 이미 같은 안내가 있으면 겹치지 않는다.

```txt
이 표의 기준 주소에는 원본 주소가 들어 있습니다. 운영으로 배포할 때 운영 AI가 이 깃허브 URL을 해당 운영의 주소로 바꿉니다. 형식은 https://계정.github.io/저장소 입니다. 원본 주소를 그대로 두지 않습니다. 기준 주소 행에 깃허브 주소만 넣으면 2-6번 페이지 주소가 자동으로 채워집니다. 화면 주소는 눌러서 엽니다. 6번 버튼 URL의 페이지 주소는 링크가 아니라 글자이므로 솔라피 모바일·PC URL에 그대로 붙여 넣습니다.
```

- **최초 설치 절에 추가할 문장**: 원본 값을 그대로 복사하지 않는다는 문장 뒤에, 이미 없으면 다음을 넣는다.

```txt
위의 웹페이지 표도 같습니다. 배포할 때 기준 주소의 깃허브 URL을 해당 운영의 GitHub Pages 주소로 바꿉니다.
```

- **환경별 값**: 없음
- **필요한 Secret (이름만)**: 없음
- **마이그레이션 / 재배포**: 없음
- **검증**: 메뉴얼 1절에서 순서, 이름, 페이지 주소만 보이는지 확인한다. 기준 주소 행의 깃허브 URL을 바꾸면 2-6번이 같이 바뀌는지 확인한다.
- **실패 시 대처**: 기준 문장이 없거나 다르면 임의 위치에 삽입하지 않고 해당 항목을 보류한다.
- **매뉴얼**: 위 문장이 최종 원문이다.
