# v2.2 — 업데이트 진행 방식 개선 (AI 순차 진행, 운영자 직접 단계 안내)

- 날짜: 2026-10-04
- 이전 버전: v2.1
- 요약: 업데이트 때 AI가 자동으로 할 수 있는 일은 순서대로 진행하고, 운영자가 직접 해야 하는 부분만 상황에 맞게 설명한다. "되돌리기 어려움" 표시와 개별 승인은 없애고, 계획 승인은 한 번만 받는다. 코드 변경 없음.
- 매뉴얼 영향: 있음 (AI·관리자 작업 규칙 16-8, 시스템 정보 업데이트 절차, 메뉴얼 문구 1문장)
- 유형: 전 항목 **AI 자동**

> 문서의 문장은 서식 기호(굵게, 코드 표시)를 무시하고 문장 그대로 찾는다. 찾을 원문이 없으면 그 항목만 멈추고 보고한다. 이 문서는 v2.1 적용 이후의 운영에 적용한다.

---

## 항목 1. 16-8 — 6번 하위 항목 수정

- **유형**: AI 자동
- **대상**: "AI·관리자 작업 규칙" 페이지의 16-8, 6번 하위 항목
- **찾을 원문**: `바뀌는 내용·영향 범위·"담당자 필요" 항목·"되돌리기 어려움" 항목·되돌리는 방법을 보고한 뒤 승인을 요청합니다.`
- **바꿀 원문**: `전체 계획("AI 자동"·"운영자 직접"·"담당자 필요" 항목, 바뀌는 내용, 영향 범위)을 보고하고 진행 여부를 한 번만 묻습니다.`

## 항목 2. 16-8 — 7번 교체

- **유형**: AI 자동
- **선행 조건**: 항목 1 완료 후
- **대상**: 16-8의 7번 항목 전체 ("7. 적용 방식: 지침의 AI 가능 항목만 …"으로 시작해 "… 이력의 적용 주체를 기록합니다."로 끝나는 항목)
- **바꿀 원문**:

````markdown
7. **적용 방식**: 운영 워크스페이스 소유자가 진행을 승인하면 지침의 항목을 순서대로 진행하며, 항목마다 다시 묻지 않습니다. 지침에 지정된 파일·함수·"찾을 원문"만 최소한으로 수정하고, 지침에 없는 변경은 하지 않습니다. 찾을 원문이 운영에 없으면 그 항목만 멈추고 보고합니다. 항목은 세 가지 유형입니다.
   - **AI 자동**: AI가 순서대로 진행합니다.
   - **운영자 직접**: AI가 할 수 없지만 운영자가 할 수 있는 일입니다. 이 단계에서 AI가 멈추고, 지침의 운영자 안내문을 바탕으로 운영자의 상황에 맞게 설명합니다(왜 필요한지, 어느 화면에서 무엇을 하는지, 완료 확인 방법). 비밀값은 채팅에 붙이지 않고 해당 서비스 화면에 직접 입력하게 합니다. 운영자가 끝났다고 알리면 확인 가능한 것은 확인하고 다음 항목으로 넘어갑니다.
   - **담당자 필요**: 진행하지 않고 보고합니다.

   적용 전에 현재 구조(속성·수식·버튼)를 시스템 정보 이력에 스냅샷으로 남기며, 이는 묻지 않고 자동으로 합니다. 중간에 멈추면 어디까지 완료했는지 이력에 기록해 이어갈 수 있게 합니다. 전부 끝나면 현재 버전과 이력을 갱신하고 적용 주체를 기록합니다. 패치에는 학생·수업 등 업무 데이터의 삭제나 대량 변경을 포함하지 않으며, 그런 작업이 필요하면 "담당자 필요"로 분류하고 16-4를 따릅니다.
````

## 항목 3. 시스템 정보 — 업데이트 절차 4~7번 교체

- **유형**: AI 자동
- **대상**: "시스템 정보" 페이지의 "업데이트 절차" 번호 목록 중 4번부터 끝까지
- **찾을 원문 (4번의 일부)**: `바뀌는 내용·영향 범위·담당자 필요 항목·되돌리기 어려움 항목·되돌리는 방법을 보고하고 승인을 요청한다.`
- **바꿀 원문**: `전체 계획(AI 자동·운영자 직접·담당자 필요 항목, 바뀌는 내용, 영향 범위)을 보고하고 진행 여부를 한 번만 묻는다.`
- **이어서**: 기존 5번, 6번, 7번 항목(승인 후 AI 가능 항목 적용 / 담당자 필요 보고 / 전부 완료 후 버전 갱신)을 지우고 아래 5~8번으로 바꾼다.

````markdown
5. 승인을 받으면 적용 전에 현재 구조(속성·수식·버튼)를 이 페이지 이력에 스냅샷으로 남기고, 지침의 항목을 순서대로 진행한다. 항목마다 다시 묻지 않는다. **AI 자동** 항목은 AI가 진행한다.
6. **운영자 직접** 항목에서는 멈추고, 지침의 운영자 안내문을 바탕으로 운영자의 상황에 맞게 설명한다(왜 필요한지, 어느 화면에서 무엇을 하는지, 완료 확인 방법). 비밀값은 채팅에 붙이지 않고 해당 서비스 화면에 직접 입력하게 한다. 운영자가 끝났다고 하면 확인 가능한 것은 확인하고 다음 항목으로 넘어간다.
7. **담당자 필요** 항목은 진행하지 않고 목록으로 보고한다.
8. 중간에 멈추면 이력에 어디까지 완료했는지 기록한다. 전부 완료 후 **현재 버전**을 갱신하고 이력에 기록한다. 적용 주체는 "배포 담당자", "운영 AI (소유자 승인)", "운영자 직접" 중 하나로 적는다.
````
