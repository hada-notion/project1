# v2.5.36 — 키오스크 알림톡을 응답 뒤에 발송

- 날짜: 2026-10-12
- 이전 버전: v2.5.35
- 요약: 키오스크 등원·하원은 출석 기록까지만 기다리고 바로 결과를 보여 준다. 알림톡 설정 조회·발송·전송로그 기록은 응답 뒤에 서버가 마저 처리한다. v2.5.35 측정에서 이 구간이 약 1.3~1.5초였다. 화면 문구는 "학부모님께 알림을 보냅니다."로 바뀐다.
- 매뉴얼 영향: 없음(키오스크 결과 문구만 변경)
- 변경 유형: Supabase 함수(`kiosk-checkin`), 웹 화면(`attendance_kiosk.html` 문구). 마이그레이션·Secrets·Notion 변경 없음.

---

## 항목 1. 알림톡 발송을 응답 뒤로

- **유형**: AI 자동
- **선행 조건**: v2.5.35 적용
- **대상 파일**: `supabase/functions/kiosk-checkin/index.ts`, `attendance_kiosk.html`
- **변경 내용**
  - 출석 기록(등원·하원 스템프, 출석 상태) 후 바로 응답한다.
  - 알림톡 설정 조회, 학부모 번호·수신자 확인, Solapi 발송, 전송로그(성공/실패) 기록은 `EdgeRuntime.waitUntil`로 응답 뒤에 처리한다. 그 기능이 없는 환경에서는 예전처럼 응답 전에 기다린다.
  - 응답 뒤 처리의 시간은 `[kiosk-checkin timing alimtalk]` 로그로 따로 남긴다. 예상하지 못한 오류는 `kiosk-checkin alimtalk error` 로그로 남긴다.
  - 키오스크 성공 문구: "…처리되었습니다. 학부모님께 알림을 보냅니다."
- **달라지는 점**: 알림톡 발송 실패를 키오스크 화면에서는 알 수 없다(예전에도 화면에는 나오지 않았다). 실패는 지금처럼 전송로그와 출석 DB의 "전송 내역"에 남는다.
- **환경별 값 (중요)**: `attendance_kiosk.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값을 유지**한다.
- **검증**:
  1. 배포 후 키오스크에서 등원·하원을 처리하고 결과가 빨라졌는지 본다.
  2. Supabase 함수 로그에서 `kiosk-checkin timing`(화면 대기)과 `kiosk-checkin timing alimtalk`(응답 뒤 처리)을 확인한다.
  3. 학부모 알림톡과 전송로그가 예전처럼 남는지 본다.
- **실패 시 대처**: v2.5.35의 `kiosk-checkin`과 `attendance_kiosk.html`로 되돌린다. 출결 데이터 영향 없음.
