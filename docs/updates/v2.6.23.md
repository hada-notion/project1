# v2.6.23 — 학습활동 계획: 본문 값이 잘리면 학습기록을 다시 읽기, 계획 출처 로그

- 날짜: 2026-10-16
- 이전 버전: v2.6.22
- 요약: 학습활동 생성 큐가 웹훅 본문의 `학습활동 계획` 값을 읽지 못하면(학생이 많아 값이 잘린 경우 등) 바로 예전 방식으로 가지 않고, 학습기록을 한 번 읽어 수식 값을 다시 받는다. 큐 로그에 계획을 어디서 받았는지(본문/학습기록), 글자 수, 학생 수를 남긴다(학생 이름·ID는 남기지 않는다).
- 매뉴얼 영향: 없음
- 변경 유형: 함수(`process-sync-queue`의 학습활동 생성 처리)
- **선행 조건: v2.6.22.**

- **유형**: AI 자동(원본 `supabase/functions/_shared/assignmentPlan.ts` 반영 시 자동 배포)
