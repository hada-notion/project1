## 항목 2. 등록(학원) DB 자동화 "보고서 생성"

- **유형**: 운영자 직접
- 트리거: `보고서 생성 상태`가 `⚪ 대기`로 편집됨
- 동작 1: 보고서(학원) DB에 페이지 추가

| 속성 | 값 |
| --- | --- |
| 보고서(제목) | 수식 ① |
| 보고서 기간 | `context("페이지 실행").prop("클래스").first().prop("보고서 생성 대상").first().prop("기간")` |
| 보고서 구분 | `format(context("페이지 실행").prop("클래스").first().prop("보고서 생성 대상").first().prop("구분"))` |
| 등록 | 페이지 실행 |
| 알림톡 발송함 | `context("페이지 실행").prop("클래스").first().prop("보고서 생성 대상")` |
| 일괄전송 선택 | 체크 |
| 출석 | 수식 ② |
| 학습기록 | 수식 ② 끝에 `.map(current.prop("학습기록")).flat().unique()` |
| 학습활동 | 수식 ② 끝에 `.map(current.prop("학습활동")).flat().unique()` |

① 제목("26.10 학생 월간 보고서")
```
lets(
  batch, context("페이지 실행").prop("클래스").first().prop("보고서 생성 대상").first(),
  formatDate(dateStart(batch.prop("기간")), "YY.MM") + " " + context("페이지 실행").prop("학생이름(등록)").format() + " " + batch.prop("구분").format()
)
```
② 출석(발송함 기간 안의 이 등록 출석)
```
lets(
  batch, context("페이지 실행").prop("클래스").first().prop("보고서 생성 대상").first(),
  startN, toNumber(formatDate(dateStart(batch.prop("기간")), "YYYYMMDD")),
  endN, toNumber(formatDate(dateEnd(batch.prop("기간")), "YYYYMMDD")),
  context("페이지 실행").prop("출석").filter(
    if(empty(current.prop("수업일시")), false,
      toNumber(formatDate(current.prop("수업일시"), "YYYYMMDD")) >= startN
      and toNumber(formatDate(current.prop("수업일시"), "YYYYMMDD")) <= endN)
  )
)
```
- 동작 2: 페이지 실행 편집 — `보고서 생성 상태` = `✅ 완료`
- 자동화가 만든 페이지에서는 보고서 DB의 "보고서 이름 자동화"가 돌지 않으므로 제목을 ①로 직접 넣는다.

## 항목 3. 클래스(학원) [보고서 생성] 버튼

- **유형**: 운영자 직접. 웹훅 보내기를 지우고:
  - 변수 `대상등록`
```
lets(
  batchId, id(context("이 페이지").prop("보고서 생성 대상").first()),
  startN, toNumber(formatDate(dateStart(context("이 페이지").prop("보고서 생성 대상").first().prop("기간")), "YYYYMMDD")),
  endN, toNumber(formatDate(dateEnd(context("이 페이지").prop("보고서 생성 대상").first().prop("기간")), "YYYYMMDD")),
  context("이 페이지").prop("등록").filter(
    empty(current.prop("등록일")) == false
    and toNumber(formatDate(current.prop("등록일"), "YYYYMMDD")) <= endN
    and if(empty(current.prop("종료일")), true, toNumber(formatDate(current.prop("종료일"), "YYYYMMDD")) >= startN)
    and current.prop("보고서").map(current.prop("알림톡 발송함")).flat().map(id(current)).includes(batchId) == false
  )
)
```
  - 페이지 편집 — `var("대상등록")`: `보고서 생성 상태` = `⚪ 대기`
- **발송함 기간**: 발송함 `기간`의 시작~끝을 그대로 쓴다(예전 서버는 시작일로 월~일 주나 그 달을 다시 계산했다). 주간은 월~일, 월간은 1일~말일로 기간을 정확히 넣는다.
- **확인**: 기간 안에 수강 중이고 이 발송함 보고서가 없는 학생에게만 보고서가 하나씩 생기고, 다시 눌러도 늘지 않는다(원본 확인).

## 수식 주의 (Notion)

- `or`는 앞이 참이어도 뒤를 계산한다. 빈 값을 숫자로 바꾸는 식은 `if(empty(…), …, …)`로 감싼다(예: 빈 종료일 → 필터 전체가 0명이 됐다).
- 날짜 크기 비교는 글자 비교가 되지 않는다. `toNumber(formatDate(날짜, "YYYYMMDD"))`로 숫자로 바꿔 비교한다(수업 시각이 있어도 날짜만 비교된다).
- `lets` 변수 이름으로 `e`처럼 수식 기본 이름과 겹치는 것을 쓰지 않는다.

## 매뉴얼
