# v2.5.65 — 수업용 비밀번호 (선생님 공용 로그인)

- 날짜: 2026-10-14
- 이전 버전: v2.5.64
- 요약: 선생님들이 함께 쓰는 "수업용 비밀번호"를 추가했다. 원장님이 관리자 설정에서 정하고, 선생님은 이 비밀번호로 30일 동안 유지되는 수업 세션을 받는다. 수업 세션은 수업방(`class-room`, 다음 패치)만 부를 수 있고 관리자 설정·법정 서류·키오스크·학교 검색·Notion 웹훅 기능은 열 수 없다. 관리자 비밀번호와 따로 잠금(5회 실패 15분)을 가진다.
- 매뉴얼 영향: 있음(관리자 설정 화면 "수업용 비밀번호" 칸, 수업방 매뉴얼은 수업방 패치 때)
- 변경 유형: 마이그레이션 1개 + Supabase 함수(`admin-security`, 공용 `adminSecurity.ts`) + 웹 화면(관리자 설정). Secrets·Notion 변경 없음.

---

## 항목 1. 마이그레이션과 함수

- **유형**: AI 자동
- **선행 조건**: v2.5.12 관리자 보안(마이그레이션 `20261011010000`~`20261013020000`)이 적용돼 있어야 한다. 보안 기능(`ADMIN_SECURITY_ENABLED=true`)이 꺼진 운영에서는 수업용 로그인이 동작하지 않는다(관리자 설정 화면 자체가 꺼진 상태).
- **대상 파일**: `supabase/migrations/20261014010000_class_password.sql`, `supabase/functions/admin-security/index.ts`, `supabase/functions/_shared/adminSecurity.ts`
- **변경 내용**
  - 보안 상태에 수업용 비밀번호 해시·버전·변경일·잠금 칸 추가, 세션 종류에 `class` 추가(30일).
  - 서버 작업 `class-owner`·`class-login`(선생님 로그인), `class-set`(원장님 관리자 세션 + 현재 관리자 비밀번호 확인, 관리자 비밀번호와 같으면 거부). 바꾸면 모든 수업 세션이 끝난다.
  - 초기 비밀번호(0000) 상태에서는 수업용 로그인·설정 모두 막힌다.
  - 원장님이 관리자 비밀번호를 바꾸면 키오스크처럼 수업 세션도 모두 끝난다(선생님 다시 로그인).
  - 수업 세션의 허용 경로는 `class-room` 하나. 관리자 세션도 `class-room`을 쓸 수 있다.
- **환경별 값**: 없음
- **검증**: `node tests/admin-security-sql.cjs`(PostgreSQL 146개), Deno 인증 테스트.
- **실패 시 대처**: 수업용 비밀번호를 쓰지 않으면 기존 동작과 같다. 마이그레이션은 칸 추가뿐이라 되돌릴 필요가 없다.

## 항목 2. 관리자 설정 화면

- **유형**: AI 자동
- **대상 파일**: `admin_settings.html`, `admin_settings.js`
- **변경 내용**: 대시보드에 "수업용 비밀번호" 칸(정한 날짜 / 아직 없음)과 [수업용 비밀번호 정하기·변경] 화면(현재 관리자 비밀번호, 새 비밀번호, 확인).
- **배포 순서**: 함수가 먼저 배포돼야 한다. 화면이 먼저 열리고 함수가 옛 버전이면 저장할 때 "지원하지 않는 서버 작업" 오류가 나며, 함수 배포가 끝나면 다시 저장하면 된다.
- **검증**: 관리자 설정 로그인 → 수업용 비밀번호 정하기 → 칸에 정한 날짜 표시.

## 항목 3. 원장님이 수업용 비밀번호 정하기

- **유형**: 운영자 직접
- **방법**: 관리자 설정 → [수업용 비밀번호 정하기] → 현재 관리자 비밀번호와 새 수업용 비밀번호(8자 이상, 관리자 비밀번호와 다르게) 입력 → 저장. 선생님들에게는 학원 안에서 직접 알려 준다(채팅·Notion에 적지 않는다).
- **확인**: 수업방이 배포된 뒤 선생님 기기에서 로그인되는지 본다. 이 패치만으로는 로그인할 화면이 아직 없다.
