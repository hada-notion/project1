# v2.5.32 — 출결 키오스크 키보드 입력

- 날짜: 2026-10-12
- 이전 버전: v2.5.31
- 요약: PC·노트북을 키오스크로 쓸 때 키보드로 전화번호를 입력할 수 있다. 숫자 키(숫자패드 포함)는 숫자, Backspace는 한 글자 지우기, Delete는 전체 지우기. 등원·하원은 실수로 처리되지 않도록 키보드로 정하지 않고 화면 버튼으로만 누른다. 누른 키는 화면 숫자판에도 잠깐 표시된다.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면(GitHub Pages). 함수·마이그레이션·Secrets·Notion 변경 없음.

## 항목 1. 키오스크 키보드 입력

- **유형**: AI 자동
- **선행 조건**: v2.5.31 적용
- **대상 파일**: `attendance_kiosk.html`(숫자판 처리 스크립트와 `<style>`의 `.key.pressed`)
- **변경 내용**: 숫자판 버튼 처리를 `pressKey()` 하나로 모으고, 문서 전체 `keydown`에서 숫자·Backspace·Delete를 같은 처리로 보낸다. 로그인 화면·학생 선택 화면·입력칸에 글자를 넣는 중에는 동작하지 않는다. 숫자패드는 NumLock이 꺼져 있어도 키 위치(`e.code`)로 받는다.
- **환경별 값 (중요)**: `attendance_kiosk.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값을 유지**한다. 원본 파일을 가져온 뒤 운영 값으로 되돌리고 원문 비교로 확인한다.
- **검증**: Pages 반영 후 PC에서 키오스크를 열고 숫자 키로 번호를 넣은 뒤 Backspace·Delete가 동작하는지, Enter로는 등원·하원이 처리되지 않는지 본다.
- **실패 시 대처**: v2.5.31의 `attendance_kiosk.html`로 되돌린다. 서버·데이터 영향 없음.
