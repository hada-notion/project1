# v2.7.6 — 페이지 레이아웃 정리(헤더·정보 탭·세부 정보 패널)와 `점수` 빈 값

- 날짜: 2026-10-18
- 이전 버전: v2.7.5
- 요약: 업무 DB 11개(수업·출석·학습기록·등록·클래스·보고서·진도교재·학생·학습활동·수강료·교재비)의 페이지 레이아웃을 한 기준으로 맞춘다. 누를 버튼은 헤더에, 읽고 쓰는 내용은 첫 탭에, 나머지는 세부 정보 패널의 섹션으로 정리하고, 학습활동을 여러 탭으로 나눠 보이던 것을 `구분`으로 묶은 탭 하나로 합친다. 학습활동 `점수`는 문항 수를 넣기 전에는 0 대신 빈 값이 된다.
- 매뉴얼 영향: 있음 → 탭 이름이 바뀐다(아래 "매뉴얼")
- 변경 유형: Notion 수식 1개, 페이지 레이아웃(화면 설정). 코드·마이그레이션·Secrets·Notion 속성 이름 변경 없음. 업무 데이터는 바꾸지 않는다.
- 기준 문서: [이름 규칙](../이름-규칙.md) 7장 "페이지 레이아웃". 이 지침의 DB별 최종 형태는 7장 표와 같다.

> 레이아웃은 Notion API로 바꿀 수 없다. 운영 AI는 아래 항목을 넘김 메모로 모아 원본 지원(브라우저)에 넘기고, 끝난 뒤 커넥터로 데이터 소스를 읽어 `page-layout`이 7장과 같은지 확인한다([운영 적용 시작 안내](v2.7-운영-시작.md)의 흐름).

## 공통: 레이아웃 편집기 쓰는 법

- 여는 곳: 그 DB의 아무 페이지 → 오른쪽 위 "레이아웃 사용자 지정". 페이지가 안 열리면 DB 보기 설정(⚙) → 추가 설정 → "페이지 레이아웃 사용자 지정".
- 저장: 오른쪽 위 **[모든 페이지에 적용]**. 저장 전 [취소]하면 아무것도 바뀌지 않는다. 기존 페이지에도 바로 반영된다.
- 헤더(제목 모듈 ⋯): 고정된 속성 목록에서 핀으로 고정·해제, 손잡이로 순서 변경.
- 탭: 한 번 누르면 선택, 한 번 더 누르면 "설정 보기"(이름·아이콘·레이아웃·속성 표시 여부·필터·그룹화·보기 삭제).
- 첫 탭에 속성 넣기: 모듈 사이 ⊕ → 기존 속성 사용에서 검색. 패널에서 본문으로 옮길 때는 패널 모듈 ⋯ → "페이지로 옮기기".
- 세부 정보 패널 속성 그룹 ⋯: "섹션 추가"(맨 위에 생김, 이름 클릭으로 바꾸기), 손잡이로 속성을 섹션 사이로 옮김, 오른쪽 눈 아이콘으로 **항상 표시 / 비어있을 때 숨기기 / 항상 숨기기**.
- 탭 필터에 같은 "○○ 포함 이 페이지" 규칙이 두 번 들어 있으면 하나를 지운다.

## 항목 1. 학습활동 `점수` — 문항 수가 없으면 빈 값

- **유형**: 운영자 직접(원본 지원 브라우저)
- **선행 조건**: 없음. 항목 2보다 먼저 한다(학습활동 탭에 `점수`를 보이므로).
- **변경 이유·증상**: 과제·학습 학습활동에도 `점수`가 `0.0`으로 나와, 학습활동 탭에서 과제 줄마다 0점이 보인다. 리스트·갤러리는 빈 값만 숨기므로 0이 아니라 빈 값이어야 한다.
- **Notion 변경**: 학습활동(학원) DB 수식 속성 `점수`
  - 찾을 원문:

    ```
    정답 문항 / 전체 문항 * 100
    ```

  - 바꿀 원문:

    ```
    if(empty(전체 문항) or 전체 문항 <= 0, empty(), 정답 문항 / 전체 문항 * 100)
    ```

  - 원문이 위와 다르면(다른 계산식) 멈추고 보고한다.
- **영향 확인(원본에서 원문 비교 완료)**: 학습활동 `평가점수값`(`if(구분 = 평가, 점수, 0)`)은 입력 전 평가가 빈 값이 된다. 출석 `평가(보고서)`는 전체 문항 > 0일 때만 점수를 쓴다. 보고서 `평가현황`은 `점수`를 쓰지 않는다. 수업 `평가 결과`는 `점수 > 0`만 평균한다(결과 같음, 0점 평가는 예전부터 평균에서 빠짐). 서버 함수는 `점수`를 읽지 않는다.
- **운영자 안내문**
  - 왜 필요한가: 학습활동 목록에서 과제 줄에 0점이 보이지 않게 한다.
  - 어디서: 학습활동(학원) DB → 표 보기 → `점수` 열 이름 → 속성 편집 → 수식 편집
  - 무엇을: 수식 전체를 위 "바꿀 원문"으로 바꾸고 창을 닫는다(닫으면 저장).
  - 끝났는지 확인하는 방법: 전체 문항이 빈 학습활동의 `점수`가 비어 있고, 전체 문항 10·정답 7인 평가는 70.
  - 흔한 오류와 대처: 수식 미리보기에 오류가 나면 속성 이름(`전체 문항`·`정답 문항`)이 운영 DB와 같은지 본다.
- **검증**: 위 확인 방법 두 가지.
- **실패 시 대처**: 찾을 원문으로 되돌린다. 데이터는 바뀌지 않는다.
- **매뉴얼**: 변경 없음

## 매뉴얼

운영 매뉴얼에서 페이지 탭 이름을 말하는 문장을 찾아 바꾼다.

- 수업·출석: "이번과제"·"평가결과" 탭 → "학습활동 탭(학습·과제·평가가 묶여 보임)". "과제검사" 탭은 그대로.
- 학습기록·등록·보고서: "과제"·"평가" 탭 → "학습활동 탭". 학습기록의 "학습" 탭 → "학습활동 탭".
- 등록: "캘린더" 탭 → "출석" 탭.
- 버튼 위치: 보고서 [보고서 전송], 클래스 [교재비 생성]·[보고서 생성]·[월 수강료 생성], 학습기록 [단원 입력], 학생 [접수안내 전송]은 페이지 위쪽(헤더)에 있다. 클래스의 보고서·수강료 생성 대상과 생성 내역은 "클래스 정보" 탭에서 고른다.
