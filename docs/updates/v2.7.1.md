# v2.7.1 — Notion 사전 작업 (속성·수식, 배포 전)

- 날짜: 2026-10-17
- 이전 버전: v2.6.5
- 요약: v2.7 버튼·자동화가 쓸 속성과 수식을 먼저 만든다. v2.6.5 코드는 이 속성·수식을 읽지 않으므로 언제 해도 안전하다. v2.7.2(코드 배포) 전에 끝낸다.
- 매뉴얼 영향: 없음(매뉴얼은 v2.7.4)
- 변경 유형: Notion 속성·수식(AI 자동 + 운영자 직접). 코드·Supabase·Secrets 변경 없음.

---

## 항목 1. 스냅샷

- **유형**: AI 자동
- 바꿀 DB(학습활동·시간표·수업·학습기록·출석·보고서·수강료·교재비·등록·학생)의 속성 목록과 교체할 수식(`생성 오류`, 학습기록 `수업일`, 이미 있으면 `출석 조정 정보`)의 원문을 운영 시스템 정보에 남긴다.

## 항목 2. 속성 추가 (AI 자동, 커넥터)

- [N-6](v2.7-노션-작업.md) 수업 `진도교재` 양방향 관계(진도교재 쪽 `수업`, 숨김)
- [N-7](v2.7-노션-작업.md) 상태·연결 속성 12개와 학생 `응시 등록` 보기
- 커넥터로 만들 수 없으면(권한·다른 DB 거치는 속성) 운영자에게 같은 설정으로 안내한다.

## 항목 3. 속성·수식 (운영자 직접)

다른 DB를 거치는 수식은 API로 만들 수 없어 Notion 화면에서 넣는다. 수식 원문은 [v2.7-노션-작업.md](v2.7-노션-작업.md)에 있다.

| 번호 | DB | 할 일 |
| --- | --- | --- |
| N-1 | 학습활동 | `메모`(텍스트), `과제상태` 선택지 `🟡 일부 제출` — **v2.7.2 전에 꼭** |
| N-2 | 시간표 | 수식 `기준일` |
| N-3 | 시간표 | 수식 `수업추가 정보`(N-2 뒤) |
| N-4 | 수업 | 수식 `생성 오류` 교체 |
| N-5 | 학습기록 | 수식 `수업일` 교체(9시간 더하기 빼기) |
| N-8 | 수업 | 수식 `출석 조정 정보` |
| N-9 | 학습기록 | 수식 `학습활동 계획` |
| N-10 | 교재비 | 수식 `담기 계획` |
| N-11 | 수업 | 수식 `학습기록 계획` |
| N-12 | 보고서·학습활동 | 수식 `보고서기간(보고서)`, 학습활동 이름 자동화 수식 |

- 수식 속성은 페이지에서 숨긴다.

## 항목 4. 확인

- **유형**: AI 자동(읽기만)
- 각 수식 값이 문서의 "확인" 줄과 같은 모양인지 몇 페이지에서 본다(예: `출석 조정 정보`가 `{"v":1,"day":…,"books":[…]}`, `수업추가 정보`의 `reg` 수가 명단 수와 같음, `학습기록 계획`이 `오늘 학습` 체크가 없으면 `"items":[]`).
- 값이 비거나 "Type error"면 그 수식만 다시 붙여 넣고, 운영 DB 속성 이름이 원본과 다른지(예: `라이브러리` ↔ `정규교재`) 확인한다.
