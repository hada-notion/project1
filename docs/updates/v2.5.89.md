- 날짜: 2026-10-14
- 이전 버전: v2.5.88

- 매뉴얼 영향: 수업 관리 매뉴얼 작성 때 교재 상세·학습기록 탭 설명(원본 Notion 메뉴얼 반영은 따로 승인)

- **유형**: AI 자동(`main` 병합 시 "Deploy Supabase Functions"가 자동 배포)
- **대상 파일**: `supabase/functions/_shared/classRoom.ts`, `supabase/functions/_shared/classRoom_test.ts`
- **변경**: 새 동작 `class-records`(수업 ID): 같은 반 앞뒤 수업(9주 전 ~ 5주 뒤, 보강 제외, 최대 90개 — 캘린더 `class-sessions`와 같은 범위, 같은 조회 함수로 묶음)의 학습기록을 수업 날짜·시각과 함께 최근부터 돌려준다. 반이 없는 보강 수업은 그 수업 기록만. Notion은 읽기만 한다.
- **검증(모의 데이터)**: `classRoom_test.ts` 17개 통과(최근순·날짜·시각, 보강 수업 기록 제외, 반 없는 수업, 잘못된 ID). 전체 함수 테스트 192개, `deno check`.
- **미검증**: 운영 Notion 데이터로 응답 시간(반 수업이 많을 때).
- **실패 시 대처**: v2.5.88의 `classRoom.ts`로 되돌리고 `main`에 병합(자동 재배포). 화면도 v2.5.88로 되돌린다(학습기록 탭이 이 조회를 쓴다).

## 항목 2. 수업 관리 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`, `class_room.html`, `docs/DESIGN.md`("수업 관리 규칙")
- **화면**

  | 화면 | 내용 |
  |---|---|
  | 학습기록 탭 | 이 반 앞뒤 수업 기록을 날짜별로(최근부터). 보고 있는 수업 날짜에 "· 보고 있는 수업". [전체 · 학습 · 과제 · 평가], [+ 기록 만들기]는 보고 있는 수업에 |
  | 교재 탭 | [진행 중 n \| 완료 n \| 다음 n]. 카드를 누르면 교재 상세 |
  | 교재 상세 | 교재 카드, [+ 이 교재로 기록 만들기](진행 중 교재만), 학생(최근 범위, 개별 교재 진도 %), 이 교재 학습기록(날짜별). 뒤로가기는 교재 탭 |
  | 홈 | 교재 진도(진행 중 교재 진도 막대, 누르면 교재 상세)를 마감 과제와 학습기록 사이에 |

- **바뀐 동작**: 교재 탭 카드를 누르면 바로 기록 만들기 창이 열리던 것(v2.5.87)이 교재 상세로 바뀌었다. 기록 만들기는 상세의 [+ 이 교재로 기록 만들기].
- **검증(모의 데이터)**: 수업 관리 화면 흐름 검사 390·768·1280 통과 — 홈 교재 진도 3줄, 교재 탭 구분 개수·다음·완료(빈 안내), 교재 상세(경로, 교재 탭 켜짐, 학생 3명, 이 교재 기록, 기록 만들기 창에 교재 선택됨, 뒤로 → 교재 탭), 다음 교재 상세에는 기록 만들기 없음, 학습기록 날짜 묶음 2개·보고 있는 수업 표시·분류 개수, 기존 흐름 전체, 가로 넘침·버튼 44px·글자 잘림. 디자인 규칙 검사, 회귀 가드, 관리자 설정 화면 검사.
- **미검증**: 운영 데이터·실제 휴대폰 화면.
- **실패 시 대처**: v2.5.88의 `class_room.js`·`class_room.html`로 되돌린다.
