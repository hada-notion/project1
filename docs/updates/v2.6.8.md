# v2.6.8 — 교보문고 검색 목록에서 여러 권 가져오기, 선택 빼기·비우기

- 날짜: 2026-10-15
- 이전 버전: v2.6.7
- 요약: 교보문고 검색 목록에서 체크한 책을 한 번에 라이브러리로 가져오고, 추가하지 않을 교재를 선택에서 뺄 수 있게 한다.
- 매뉴얼 영향: 있음 → 교재·학습 7-6 라이브러리 안내(아래 "매뉴얼")
- 변경 유형: 화면(Pages `library.html`), 함수(`textbook-api` 새 동작 `kyobo-book`). Notion·DB·Secrets 변경 없음.

---

## 항목 1. 화면·함수 반영

- **유형**: AI 자동(원본 `library.html`, `supabase/functions/_shared/textbookSearch.ts`, `supabase/functions/textbook-api/index.ts`를 반영하면 함수·Pages 자동 배포. `hada_config.js`는 덮어쓰지 않는다)
- **선행 조건**: v2.6.7
- **동작**
  - 즐겨찾기 [교재 가져오기]: 책 상세 페이지에서는 지금처럼 한 권. 교보문고 검색 목록(`search.kyobobook.co.kr`)에서는 체크한 책(20권까지)의 상품번호·ISBN·교재명을 복사한다. 체크한 책이 없거나 20권을 넘으면 안내한다.
  - 목록 페이지에서는 브라우저가 상품 쪽 정보를 읽지 못하게 막아서, 라이브러리 함수 `textbook-api`의 `kyobo-book { pid }`가 교보문고 상품 정보 요청(`https://product.kyobobook.co.kr/api/gw/pdt/v2/product/<상품번호>`, 주소 고정, `S`+숫자만)을 한 권씩 불러 정가·출판사·목차(단원 후보)를 준다. 쪽수·시리즈는 이 요청에 없어 비워 둔다(시리즈는 교재명으로 선택지를 맞춤).
  - [가져온 정보 붙여넣기]: 여러 권이면 그 수만큼 "1 / n" 창을 바로 열고, 한 권씩 채워지는 대로 보여 준다. 실패한 책은 교재명·표지만 남기고 안내한다.
  - 선택 정리: 창 머리 [빼기](지금 교재를 선택에서 빼기, 검색 결과에서 고른 책이면 체크도 풂, 내용을 넣은 직접 추가 교재는 한 번 묻는다), 선택 막대 [선택 비우기](묻고 모두 비움), 교재명도 단원도 없는 [직접 추가]는 창을 닫으면 저절로 빠진다. 라이브러리에 이미 추가한 교재에는 영향이 없다.
- **검증(원본)**: 실제 교보문고 검색 목록에서 체크 0권 안내·2권 복사(같은 코드), 제 PC에서 교보문고 상품 정보 요청 응답(교재명·정가·출판사·쪽 번호가 붙은 목차), 함수 테스트(주소 고정·상품번호 검사·실패 502), 라이브러리 UI 검사(여러 권 창·한 권 실패 안내·한 권씩 요청, [빼기]·[선택 비우기]·빈 항목 정리, 6개 폭, 휴대폰 선택 막대 버튼 줄바꿈 없음).
- **미검증**: Supabase 서버에서 교보문고 상품 정보 요청이 막히지 않는지(배포 뒤 확인), 실제 즐겨찾기에서 검색 목록 체크 후 누르기.
- **실패 시 대처**: 교보문고가 서버 요청을 막으면 여러 권 가져오기는 교재명·표지만 채운다. 그 책들은 상세 페이지에서 한 권씩 가져온다.
- **알아둘 점**: 교보문고가 공개한 API가 아니라 자기 화면이 쓰는 요청이다. 예고 없이 바뀌거나 막힐 수 있다. 사람이 체크한 책만, 한 번에 20권까지, 한 권씩 부른다.

## 항목 2. 즐겨찾기 다시 끌어다 놓기

- **유형**: 운영자 직접(이미 즐겨찾기를 만든 PC만)
- **운영자 안내문**: 즐겨찾기 막대의 [교재 가져오기]를 지우고, 라이브러리를 새로고침(Ctrl+Shift+R)한 뒤 [라이브러리 추가] → "교보문고에서 가져오기 준비"의 [교재 가져오기]를 다시 끌어다 놓는다.
- **확인**: 교보문고 검색 목록에서 책 두 권을 체크하고 즐겨찾기를 누르면 "체크한 2권을 복사했어요"가 뜨고, 라이브러리에서 붙여넣으면 "1 / 2" 창이 열린다.

## 매뉴얼

교재·학습 7-6 라이브러리 안내에 추가:

> 교보문고 검색 목록에서 책을 체크(한 번에 20권까지)하고 즐겨찾기 [교재 가져오기]를 누르면 여러 권을 한 번에 가져올 수 있어요. 라이브러리에서 [가져온 정보 붙여넣기]를 누르면 한 권씩 창이 열리고 정가·출판사·목차가 채워져요. 추가하지 않을 교재는 창 오른쪽 위 [빼기], 선택을 모두 지우려면 [선택 비우기]를 누르세요.
