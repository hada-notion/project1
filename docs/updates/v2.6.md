# v2.6 — v2.5.11 이후 원본 변경을 한 번에 (개요)

- 날짜: 2026-10-14
- 이전 버전: v2.5.11 (운영에 마지막으로 나간 버전, 원본 기준 커밋 `f9be7fc327d752ef78fea811027dc2353199e5e1`)
- 요약: 원본에서 v2.5.12~v2.5.130으로 나눠 고친 것을 운영 적용 단위로 다시 묶었다. 중간에 넣었다 되돌린 것과 돌아서 간 단계는 빼고, v2.5.11과 지금의 차이만 적었다. v2.5.12~v2.5.130 지침 파일은 지웠다(세부 경과는 Git 이력).
- 매뉴얼 영향: 있음 → [Notion 작업 목록](v2.6-노션-작업.md) N-14

## 왜 나눴나

코드(함수·마이그레이션·화면)는 v2.6.2 한 커밋으로 넘어간다. 서버와 화면을 따로 올리지 않는 이유: 함수 배포 워크플로의 테스트·회귀 가드가 새 화면 파일(`admin_settings.js`, `hada_config.js`를 쓰는 화면)을 전제로 해, v2.5.11 화면이 남은 채 서버만 올리면 배포가 테스트에서 막힌다. 대신 Notion 작업을 배포 전·후로 나누고 확인·선택 단계를 따로 두어, 단계마다 확인하고 멈출 수 있게 했다.

- **v2.6.2는 학원 수업이 없는 시간에** 한다. 한 커밋을 올리면 Pages가 함수 배포보다 먼저 끝나 잠시 새 화면이 아직 없는 새 함수를 부를 수 있다.
- v2.6.1은 며칠 전에 미리 해도 된다(v2.5.11 코드는 새 속성을 읽지 않는다).
- v2.6.3은 v2.6.2 확인 뒤(먼저 하면 v2.5.11 코드가 학습기록 단원을 못 읽는다). v2.6.4는 v2.6.3 뒤. v2.6.5는 필요할 때만, 순서 무관.

## v2.5.11 → v2.6에서 달라지는 것 (최종 상태 기준)

### 새 화면
- **수업 관리** `class_room.html`(선생님용, 새 탭): 첫 화면 강사·담당 클래스(오늘 수업 시간순, 5개 넘으면 접기)·보강 대기실·통합 시간표, ☰ 사이드바(강사 정보·강사 바꾸기·로그아웃). 반 상세 하단 탭 [홈 · 교재 · 캘린더 · 학습기록 · 학생]: 보고 있는 수업(‹ ›)·등원·과제 제출, 교재 진도·교재 상세, 캘린더 [출석 현황 | 과제 현황](날짜 → 그 주로 접히고 [학생 목록 | 학습 기록]에서 출석 체크·메모·기록), 학습기록 타임라인과 [+ 기록 만들기](구분·클래스·교재·주제·범위·단원 고르기·내용, 글머리 입력), 학생 명부(학교·학년·연락처·학생 보고서 ↗)와 반 요약(출석률·과제이행률·평가 추이). 보강 수업 만들기·풀기·지우기. 뒤로가기는 앱처럼. Notion 수업 페이지에서 `class_room.html?session=<수업 페이지 ID>`로 열면 그 수업이 열린다.
- **라이브러리** `library.html`(관리 화면): [라이브러리 열기] 교재를 시리즈별로 보고 단원 창에서 단원 추가·수정·삭제·북커버 바꾸기, [라이브러리 추가] 국립중앙도서관·카카오 책 검색(교재명 한 글자부터, ISBN13)·목차 단원 나누기·직접 추가, [시리즈 관리] 시리즈 선택지 추가·이름·순서(편집에서 끌기)·삭제.

### 바뀌는 화면
- **관리 화면 공통**(관리자 설정·라이브러리·학교 검색·법정 서류): 공용 디자인(학부모 리포트 기준), 상단 메뉴 [관리자 설정 | 라이브러리 | 시험 관리(준비 중, 흐리게) | 학교 검색 | 법정 서류] + 새 탭 [키오스크] [수업 관리], 오른쪽 ⋯(보안 설정 현황·로그아웃), 휴대폰 폭은 ☰ 사이드바. 관리 화면끼리 같은 탭에서 로그인 공유. 브라우저 탭 아이콘.
- **출결 키오스크**: 공용 디자인, 카드 아래 학원 이름, 키보드 입력(숫자·Backspace·Delete·←/→·Enter, 학생 선택 ↑/↓), 결과 모달, 설정(톱니: 체크 방식 1일 1회/매번 기록·지금 동기화·로그아웃). 매일 04:00 오늘 출석 준비로 등원·하원이 빨라지고 알림톡은 응답 뒤에 보낸다.
- **학부모 리포트**: 반 상세 첫 탭 "홈"(오늘·곧 마감·진도·선생님 한마디), 교재 카드·캘린더(실제 출석 기준, 날짜 → 그 주로 접힘, 오늘 빨간 테두리, 과제 현황은 마감일 기준)·학습기록·보고서(일간·주간·월간 요약에 평가 칸, 평가 목록 창, 일간 출석 칸 아래 등원 시각) 개편, 제목·용어 통일, 뒤로가기는 앱처럼, 달력 카드 오른쪽 아래 첫 요일 버튼([월–일]/[일–토], 기기별 저장, 수업 관리와 같은 설정).
- **법정 서류·학교 검색**: 공용 디자인, 알림 줄, 정렬·필터 창 간소화, 나이스 출처 표시. 출력 서식·조회 로직은 그대로.
- **관리자 설정**: 보안 모드를 켰을 때만 쓴다(관리자 비밀번호 변경, Notion 웹훅 키 교체와 DB별 체크리스트). 꺼져 있으면 "최초 서버 설정이 필요합니다" 안내만 보인다.

### 서버·데이터
- 출석 **정기 예약 동기화 해제**(GitHub Actions 매시간·매일). 학부모 리포트는 보고서 발송 직전과 [학생 페이지 동기화]에서만 최신화. 워크플로는 수동 실행용으로 남는다.
- Supabase 복사본: 키오스크 오늘 출석(`kiosk_today`), 수업 관리(`cr_sessions`·`cr_attendance`·`cr_records`·`cr_activities`), 라이브러리(`lib_books`·`lib_units`). Notion이 원본이고 예약 실행이 맞춘다.
- 학습기록 단원을 관계 하나(`단원` → 단원목록)로. Notion [단원 입력] 버튼(새 함수 `fill-record-units`)과 수업 관리 단원 고르기.
- 보강 수업 표시(수업 `보강`), 출석 내부 `메모`, 학습기록 `주제`.
- 출석 "선생님 한마디"가 리포트에 안 나오던 버그(속성 이름 오타) 수정. 학사일정 가져오기 중복 생성 방지. 출석 등원·하원 시각을 리포트 원자료에 저장.
- 웹 화면의 Supabase 주소·공개 키는 학원별 파일 `hada_config.js` 하나에서 읽는다. 앞으로 화면 파일은 원본 최신본으로 통째로 바꾸고 이 파일만 지킨다.
- 쓰지 않는 함수 삭제: `sync-registration-timetable`, `mark-report-source-dirty`, `sync-student-report`, `sync-school-schedules`.
- 관리자 보안(선택): 관리자 비밀번호와 Notion 웹훅 키 분리, 키별 호출 범위, 웹훅 키 교체. 켜지 않으면 지금처럼 `ADMIN_SECRET` 하나로 로그인한다.

## 원본에서 거쳤지만 운영에 적용하지 않는 것

v2.6 코드에 이미 최종 상태만 들어 있다. 아래는 지침을 찾다가 헷갈리지 않도록 적어 둔다.

- 선생님 공용 "수업용 비밀번호"(v2.5.65): v2.5.82에서 없애고 관리자 비밀번호 하나로 통일. 마이그레이션 두 개가 차례로 만들고 지우므로 그대로 적용하면 된다.
- 알라딘 책 검색과 `ALADIN_TTB_KEY`(v2.5.118~119): 알라딘 OpenAPI 종료로 국립중앙도서관·카카오로 교체. 이 키는 등록하지 않는다.
- 학습기록 관계 이름 `선택 단원`(v2.5.126): 최종 이름은 `단원`. 운영은 처음부터 `단원`으로 만든다(N-9).
- 수업 관리 복사본 수동 워크플로 `Class room copy sync (manual)`(v2.5.113): 다음 버전에서 지우고 pg_cron으로. GitHub Secret `ADMIN_SECRET`을 새로 넣을 필요 없다.
- 수업방 PC 두 칸 배치·≡/📅 서랍·하단 [수업 목록] 탭·학생 공간 화면, 캘린더 칸 비율과 색을 여러 번 바꾼 단계, 휴대폰 짧은 탭 이름: 모두 최종 화면으로 대체.
- 키오스크 로그인 30일 제한: 관리자 비밀번호를 바꿀 때까지 유지로 바뀜(보안 모드에서만 해당).
