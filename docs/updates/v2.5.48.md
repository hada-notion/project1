# v2.5.48 — 버튼 크기 흔들림 정리

- 날짜: 2026-10-12
- 이전 버전: v2.5.47
- 요약: 버튼 글자가 처리 중에 바뀌면서("조회" → "조회 중…", "Excel 다운로드" → "엑셀 생성 중…", "정렬" → "오름차순") 버튼 폭과 옆 칸이 흔들렸다. 처리 중인 버튼은 크기를 그대로 두고 글자 대신 가운데 회전 표시만 보이게 하고, 진행 문구는 화면 위 알림 줄로 옮겼다. 상태에 따라 글자가 바뀌는 정렬 버튼은 가장 긴 글자에 맞춘 최소 폭을 줬다.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면(GitHub Pages). 함수·마이그레이션·Secrets·Notion 변경 없음.

## 항목 1. 처리 중 버튼

- **유형**: AI 자동
- **선행 조건**: v2.5.47
- **대상 파일**: `assets/hada-ui.css`(`.loading`), `admin_settings.js`(`task`), `legal_documents.html`, 네 화면 `?v=` 버전 표시, `docs/DESIGN.md`(2-4 "처리 중")
- **변경 내용**
  - 공용 `.loading`: 관리 화면에서는 버튼 글자를 숨기고 같은 자리 가운데에 회전 표시를 둔다(버튼 크기 그대로). 키오스크는 큰 버튼 안 "확인 중…" 글자를 지금처럼 쓴다.
  - 법정 서류: [조회]·[로그인]·[Excel 다운로드]가 처리 중에 글자를 바꾸지 않는다. "조회 중…", "엑셀 파일을 만드는 중…"은 위 알림 줄에. 필터 칸 폭이 [조회] 때문에 바뀌지 않는다. 정렬 버튼은 정렬 / 오름차순 / 내림차순에서 폭이 같다.
  - 관리자 설정: 처리 중 버튼 글자를 바꾸지 않고 대기 문구("불러오는 중…", "Notion에서 찾는 중… (최대 1분)" 등)를 위 알림 줄에 보여 준다. 작업이 새 안내를 남기지 않으면 원래 안내로 돌아간다.
  - 학교 검색: [검색]·[이 학교로 연결]도 같은 규칙(회전 표시가 버튼 폭을 늘리지 않음).
- **환경별 값 (중요)**: `attendance_kiosk.html`·`legal_documents.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`, `school_search.html`의 `ENDPOINT`는 **운영 값을 유지**한다.
- **검증**: Pages 반영 후 법정 서류 [조회]를 눌러 필터 칸과 버튼 크기가 그대로인지, 정렬 버튼을 눌러도 폭이 같은지, 관리자 설정에서 버튼을 눌렀을 때 위 알림 줄에 대기 문구가 보이는지 본다.
- **실패 시 대처**: v2.5.47의 해당 파일들로 되돌린다. 데이터 영향 없음.
