## 항목 1. 단계별 시간 기록

- **유형**: AI 자동
- **선행 조건**: 없음
- **대상 파일**: 신규 `supabase/functions/_shared/stepTiming.ts`(+ `_test.ts`), 수정 `supabase/functions/kiosk-checkin/index.ts`, `.github/workflows/deploy-supabase-functions.yml`(테스트 추가)
- **변경 내용**: 요청마다 `auth`(관리자 키 확인), `db_ids`(학생·출석 DB ID), `verify`(등록·학생 확인), `full_lookup`(번호만 온 예외 경로), `class`(클래스 조회), `attendance_find`, `attendance_write`, `alimtalk_config`, `parent_phone`, `recipients`, `send`(Solapi 발송), `send_log`/`send_fail_log`, `total`을 기록한다. 결과 종류(`outcome`: done/already/pick/no_match/refresh/error)와 함께 `[kiosk-checkin timing] {...}` 한 줄로 로그에 남기고, 정상 응답에는 `Server-Timing` 헤더를 붙인다.
- **개인정보**: 단계 이름과 숫자만 기록한다. 학생 이름·전화번호·페이지 제목은 기록하지 않는다.
- **환경별 값**: 없음
- **검증**:
  1. 배포 후 키오스크에서 등원·하원을 몇 번 처리한다.
  2. Supabase 대시보드 → Edge Functions → `kiosk-checkin` → Logs에서 `kiosk-checkin timing`을 검색해 단계별 시간을 본다.
- **실패 시 대처**: 이전 `kiosk-checkin`으로 되돌린다. 출결 데이터 영향 없음.
