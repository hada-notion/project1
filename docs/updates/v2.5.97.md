# v2.5.97 — 학부모 리포트 보고서 요약에 평가 칸

- 날짜: 2026-10-14
- 이전 버전: v2.5.96
- 요약: 보고서 탭의 일간·주간·월간 위쪽 요약이 출석·과제 두 칸뿐이었다. 수업 관리 반 요약(출석률·과제이행률·평가 평균)과 같게 평가 칸을 더해 세 칸으로 만들었다. 학부모 화면이라 요청한 이 부분만 고쳤다.
- 매뉴얼 영향: 학부모 리포트 안내 자료에 보고서 요약 세 칸 설명(원본 Notion 메뉴얼 반영은 따로 승인)
- 변경 유형: 웹 화면만(Pages). 함수·Notion 변경 없음.

---

## 항목 1. 화면

- **유형**: AI 자동
- **대상 파일**: `student_report_part2.js`(`buildDailyBodyHtml`·`buildReportTabHtml`의 요약 줄만), `student_report.html`(요약 세 칸 CSS, 스크립트 버전 표시), `docs/DESIGN.md`
- **동작**
  - 일간: [출석 현황] [과제 현황] [평가 현황]. 평가 현황은 그날 평가 점수(정답 ÷ 전체 문항 × 100, 여러 개면 평균) 알약(색은 평가 기록 알약과 같은 단계)과 "n건", 평가가 없으면 "해당 없음".
  - 주간·월간: [출석률] [과제이행률] [평가 평균]. 평가 평균은 그 기간 평가 점수 평균(소수 한 자리, 최근 평가 추이와 같은 값)을 브라운 도넛으로 채우고 아래 "(평가 n개)", 평가가 없으면 빈 도넛 "–"·"(평가 없음)".
  - 폭 480px 이하에서는 세 칸이 들어가게 제목 13px·도넛 68px·배지 글자를 조금 줄인다. 넓은 화면은 그대로.
  - 숫자는 리포트가 이미 받는 평가 데이터로 화면에서 계산한다(새 조회 없음).
- **검증(모의 데이터)**: 새 보고서 요약 검사(`check-report-cards.cjs`) 390·1280 — 일간 세 칸·그날 평가 "90점 1건"·평가 없는 날 "해당 없음", 월간·주간 세 도넛·"90.0점 (평가 1개)"(또는 평가 없음), 가로 넘침·글자 잘림 없음. 기존 리포트 화면 검사 3종(첫 화면·탭, 뒤로가기, 확장 화면), 회귀 가드.
- **미검증**: 운영 학생 데이터·실제 휴대폰(카카오톡 인앱) 화면.
- **실패 시 대처**: v2.5.96의 `student_report_part2.js`·`student_report.html`로 되돌린다.
