# v2.5.72 — 캘린더 정사각형 고정과 모양 통일

- 날짜: 2026-10-13
- 이전 버전: v2.5.71
- 요약: 학부모 리포트의 일정 탭·캘린더 탭(월·주)과 수업방 캘린더를 같은 모양으로 맞췄다. 날짜 칸은 화면 크기와 상관없이 늘 정사각형이고, 카드 안쪽 12px·제목 16px·이동 버튼 32px·요일 12px·칸 간격 4px·숫자 14px·모서리 10px로 고정했다. 그동안 리포트 캘린더는 화면 폭·높이(vw·vh)에 따라 크기가 바뀌고, 캘린더 탭은 칸 높이를 화면 높이로 정해 직사각형이 되거나 헤더가 접히면 줄어들었다. 오늘 표시는 세 곳 모두 빨간 테두리.
- 매뉴얼 영향: 없음
- 변경 유형: 웹 화면만(Pages). 함수·Notion 변경 없음.
