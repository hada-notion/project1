## 항목 2. 진도교재 이름 자동화 수식 — 운영자 직접

왜 필요한가: 교재 이름은 복사 출처가 아니라 클래스/등록 귀속으로 결정합니다. 코드가 새 개별교재의 초기 이름은 설정하지만, 직접 만든 교재와 이후 관계 편집의 네이밍은 Notion 자동화가 맡습니다.

어디서: 진도교재(학원) DB → 번개 → 기존 ‘진도교재 이름 자동화’ → ‘진도교재 속성 편집’ → 수식.

기존 기준: 정규교재명+(반별교재 없음이면 클래스, 있으면 등록을 거친 학생정보). 실제 자동화는 운영에서 원문을 확인하고 백업합니다. 첨부 화면 외 전체 자동화 원문은 이 작업의 도구로 조회하지 못했습니다.

교체 수식:

```text
if(
  empty(페이지 실행.prop("정규교재")),
  "정규교재 연결 필요",
  페이지 실행.prop("정규교재").format()
) + "(" +
ifs(
  not empty(페이지 실행.prop("클래스")),
  페이지 실행.prop("클래스")
    .map(current.prop("클래스명"))
    .join(", "),

  페이지 실행.prop("등록").length() == 1,
  페이지 실행.prop("등록")
    .map(current.prop("이름"))
    .join(""),

  페이지 실행.prop("등록").length() > 1,
  "개별교재 등록 연결 확인",

  "연결 필요"
) + ")"
```

`페이지 실행`은 실행 페이지 참조 칩입니다. 붙여넣은 문자열이 일반 텍스트로 남거나 인식되지 않으면 수식 편집기의 페이지 실행(Trigger page) 항목으로 선택합니다. 운영의 정확한 제목 속성 이름은 등록 `이름`, 클래스 `클래스명`을 확인하며 다르면 먼저 보고합니다.

트리거: 페이지 추가 및 정규교재·클래스·등록 편집을 포함하는 이름 자동화를 확인합니다. 필요한 경우 페이지 추가/속성 편집 자동화를 UI가 지원하는 방식으로 분리합니다. 진도교재 제목 자체를 트리거로 삼아 반복 실행하지 않습니다. 기존 별도 과목 설정 액션과 관련 없는 자동화는 보존합니다. 반별교재는 네이밍 판단에 사용하지 않습니다.

완료 확인: UI의 수식 유효성 검사 통과·저장 확인 후 승인된 테스트로 클래스 교재/복사 개별교재/직접 개별교재 각각의 이름을 확인합니다. 이 원본 코드 배포만으로 Notion 자동화가 변경되지는 않습니다.

흔한 오류: 일반 수식 속성용 `prop()`만 넣거나 페이지 참조 칩을 누락하면 자동화에서 읽을 대상이 없습니다. 실행 페이지 칩과 정확한 속성 이름을 확인합니다. 클래스 없는 교재에 등록을 여러 개 연결하면 ‘개별교재 등록 연결 확인’으로 표시하며 관계를 임의 제거하지 않습니다.

## 항목 3. 사용 매뉴얼 — AI 자동

대상: 메뉴얼 하위 교재·학습 페이지의 `7-1. 진도교재 준비`. 기존 7-2 이후와 클래스 일괄 생성 안내는 보존합니다. 아래 내용으로 7-1의 본문을 맞춥니다. 섹션이 없거나 다르면 추정하지 않고 보고합니다.

### 7-1. 진도교재 준비

1. 반에 공통 커리큘럼이 있으면 진도교재 DB에 기준 교재를 만들고 `클래스`, `정규교재`, `진도방식`을 설정합니다. 개별 진도의 기준 교재는 `등록`을 비워 둡니다.
2. 등록 페이지의 `교재 생성`은 해당 반의 기준 교재를 연결·복사합니다. 그룹 진도는 반의 교재 한 건을 공유하고, 개별 진도는 해당 등록 1건에 연결된 교재를 생성합니다.
3. 새 개별교재는 `클래스`를 직접 연결하지 않습니다. `반별교재`에는 복사 출처만 남기며, 소속 반은 `등록 → 클래스`로 확인합니다.
4. 학생마다 다른 책을 쓰는 경우에는 진도교재를 직접 만들고 `진도방식=개별 진도`, `등록=해당 등록 1건`, `정규교재=실제 책`으로 설정합니다. `클래스`와 `반별교재`는 비워 둡니다. 기준 교재가 없어도 사용할 수 있으며 생성 버튼이 책을 임의로 선택하지는 않습니다.
5. 교재를 시작할 때 `진행상태`를 `진행 중`으로 변경합니다. 다음 교재는 `다음 교재`, 완료하거나 쓰지 않는 교재는 `완료` 또는 `미사용`으로 관리합니다.
6. 반의 기준·공동 교재 이름은 `정규교재명(클래스명)`, 개별교재 이름은 `정규교재명(등록명)`으로 관리합니다. 자동화 수식은 진도교재 DB의 정규교재·클래스·등록 변경을 기준으로 설정합니다.

- **그룹 진도**: 클래스에 연결된 교재 한 건과 학습기록을 여러 등록이 공유합니다.
- **개별 진도**: 등록 1건에 귀속된 교재와 학습기록을 사용합니다. `반별교재`는 선택적인 복사 출처이지 개별교재 여부를 결정하는 기준이 아닙니다.
- 기존 개별교재의 클래스 연결은 이번 코드 배포로 일괄 제거하지 않습니다. 기존 교재는 중복 생성 없이 재사용하며, 데이터 정리는 별도 승인 범위입니다.

## 완료 판정

- 원본: 코드·테스트·문서 커밋 원문 및 필요한 배포 결과 확인 후 원본 작업 상태를 기록합니다.
- 운영: 자동화 설정·실제 버튼/학습기록·화면 확인은 원본 배포와 구분합니다. 자동화 또는 실사용 미검증이면 그 상태를 남기고 운영 전체 버전을 완료로 올리지 않습니다.
- 기존 데이터의 클래스 일괄 제거·등록 연결 변경·삭제는 이 패치에 포함하지 않습니다.
