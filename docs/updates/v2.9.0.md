# v2.9.0 — 종합 평가 (작업 중)

- 날짜: 작업 중(2026-10-29 시작)
- 이전 버전: v2.8.0
- 요약: 교재 하나를 끝냈을 때 진도교재 [종합 평가 만들기]로 그 교재의 수강 중 학생 모두(또는 개별교재 학생 한 명)에게 종합 평가를 만든다. 일일·주간·월간 보고서와는 별개로, 학부모 리포트에서 그 교재를 열었을 때 보인다(리포트·알림톡은 다음 항목에서).
- 매뉴얼 영향: 있음 → 기능이 끝나면 "메뉴얼 갱신" 항목에 적는다(진도교재·평가 쓰는 법). 지금은 작업 중.

## 항목 1. 진도교재 [종합 평가 만들기]

- **유형**: AI 자동(칸·코드) + 운영자 직접(버튼 웹훅 키)
- **선행 조건**: v2.8.0(학습기록 `평가 구분`에 "종합 평가" 선택지, 출석 없는 평가의 학습활동 계획)
- **변경 이유**: 교재를 끝냈을 때 보는 평가를 반·학생 단위로 한 번에 만든다. 주간·월간 평가처럼 보고서 기간에 묶이지 않고 교재에 묶인다.
- **동작**
  - 대상: 누른 진도교재의 `등록` 중 `수강상태`가 수강 중인 학생. 그룹 진도 반 교재는 반 학생 모두, 학생의 개별교재는 그 학생 한 명.
  - 개별 진도 반 교재(템플릿, `개별교재`가 달린 페이지)에는 등록이 없어 만들지 않고 `마지막 오류`에 "학생의 개별교재에서 누르라"고 남긴다.
  - 만드는 것: 학습기록 1개 — 제목 `[종합 평가] (진도교재 이름)`, `구분` 평가, `평가 구분` 종합 평가, `평가 기간` 누른 날(서울), `진도교재`·`교재`(라이브러리)·`과목`·`등록`(수강 중)·`클래스`(교재의 클래스, 비면 등록의 클래스). 이어서 [학습활동 생성] 큐가 학생별 학습활동(점수 칸)을 만든다.
  - 같은 교재로 다시 공부하면 새 진도교재 페이지를 만드므로 교재마다 횟수를 막지 않는다. 두 번 누름은 `종합 평가 상태`(⏳ 대기열·🔄 작업중이면 받지 않음)가 막는다.
  - 점수가 없는 평가(예체능 수료)는 점수를 비워 둔다(리포트·알림톡 "수료"는 다음 항목).
- **대상 코드**: `supabase/functions/_shared/finalEvaluation.ts`(새로), `create-class-reports/index.ts`(경로 `/final-evaluation`), `process-sync-queue/index.ts`(큐 `final-evaluation`), `status-watchdog/index.ts`(진도교재 종합 평가 상태 감시). 테스트 `finalEvaluation_test.ts`.
- **Notion 칸(진도교재(학원) DB)**
  - `종합 평가 상태` — 선택: ⚪ 대기·⏳ 대기열·🔄 작업중·✅ 완료·⚠️ 오류·⏱️ 타임아웃 복구. 설명: "[종합 평가 만들기] 처리 상태. 서버가 ⏳ 대기열 → 🔄 작업중 → ✅ 완료/⚠️ 오류로 바꾼다. 오류 사유는 마지막 오류."
  - `종합 평가 처리 시작 시각` — 날짜. 설명: "종합 평가 상태가 🔄 작업중으로 바뀐 시각. 워치독이 멈춘 작업 판단에 쓴다."
- **버튼(운영자 직접)**: 진도교재(학원) DB 버튼 속성 [종합 평가 만들기] — 확인 표시 후 웹훅 보내기, 주소 `…/functions/v1/create-class-reports/final-evaluation`, 헤더 `x-admin-key`(웹훅 키, 다른 버튼과 같은 값), 콘텐츠는 페이지 기본값.
- **확인 수준**: 모의 테스트(반 교재·개별교재·템플릿·수강 중 없음). 실환경 미검증.

## 항목 2. 메뉴얼 갱신 (작업 중)

- **유형**: AI 자동
- **선행 조건**: 종합 평가 리포트·알림톡까지 끝난 뒤
- 원본 메뉴얼 진도교재·평가 절에 [종합 평가 만들기](그룹 진도는 클래스 → 진도교재 탭, 개별 진도는 학생의 개별교재), 점수 입력(평가 탭), 리포트 교재 상세 표시를 적는다. 찾을 낱말: "진도교재", "평가 만들기", "종합 평가". 기능이 끝나면 찾을 문구 → 바꿀 문구로 고쳐 적는다.
