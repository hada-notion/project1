- 날짜: 2026-10-06 (Asia/Seoul)
- 이전 버전: v2.5.5
- 요약: 등록(학원) DB에서 보고서 원본 변경으로 취급할 트리거 속성과 제외할 내부 속성을 명확히 합니다.
- 매뉴얼 영향: 없음
- 작성자·출처: 강인희 요청·승인, Notion AI 프링글스 작성.
- 변경 유형: 운영 기준·패치 지침. 실행 코드·Supabase·Secrets·Notion 자동화 설정 변경 없음.

> 이 패치는 등록 DB의 자동화 트리거 대상 기준을 문서화합니다. 실제 Notion 자동화 연결과 웹훅 실행은 별도 검증 대상이며, 이 문서 배포만으로 자동화가 생성되거나 변경되지는 않습니다.

## 항목 1. 등록 DB 트리거 속성 기준

- **유형**: AI 자동
- **선행 조건**: 운영 소유자의 전체 계획 승인.
- **변경 이유·증상**: 등록 DB의 모든 편집을 동기화 대상으로 삼으면 내부 상태 변경이나 수정일 갱신 때문에 불필요한 동기화가 발생할 수 있습니다. 보고서 내용에 영향을 주는 속성만 `학습정보 수정일`을 갱신해야 합니다.
- **대상 Notion**: 등록(학원) DB
- **트리거 대상 속성**:
  - `학생정보`
  - `클래스`
  - `시간표`
  - `진도교재`
  - `등록일`
  - `종료일`
  - `토큰`
  - `링크 비활성화`
- **트리거 동작**: 위 속성 중 하나가 변경되면 `학습정보 수정일`만 현재 시각으로 기록합니다. 이 단계에서 전체 리포트 캐시를 재계산하거나 학부모 알림을 발송하지 않습니다.
- **트리거 제외 속성**:
  - `학습정보 수정일`
  - `마지막 동기화`
  - `동기화 필요`
  - `등록 상태`
  - `교재 상태`
  - `수업 상태`
  - `시간표 상태`
  - `종료 상태`
  - `처리 시작 시각` 계열
  - `마지막 오류`
  - `메모`
  - 버튼 속성
- **수식 속성**: `수강상태`는 `등록일`·`종료일`로 계산되므로 별도 트리거로 두지 않습니다.
- **환경별 값**: 없음
- **필요한 Secret (이름만)**: 없음
- **마이그레이션 / 재배포**: 없음
- **검증**: 원본 리포트 캐시 조립 코드가 등록의 학생·클래스·시간표·진도교재·기간·토큰 정보를 사용함을 확인합니다.
- **실패 시 대처**: 실제 DB에 없는 속성이나 역할이 다른 동명 속성이 발견되면 자동화를 추정해 만들거나 변경하지 않고 중단합니다.
- **매뉴얼**: 변경 없음.

## 항목 2. 동기화 시점 기준

- **유형**: AI 자동
- **선행 조건**: 항목 1 완료.
- **동작 기준**:
  1. 등록 원본 편집 시에는 `학습정보 수정일`만 기록합니다.
  2. 동기화 요청이 들어오면 `학습정보 수정일`과 `마지막 동기화`를 비교합니다.
  3. 수정일이 더 최근인 등록만 동기화 대상으로 좁힙니다.
  4. 동기화가 성공한 뒤에만 `마지막 동기화`를 갱신합니다.
- **주의**: 현재 등록 DB의 `학생 페이지 동기화` 버튼은 등록 학생 리포트를 직접 전체 갱신하는 수동 경로입니다. 이 패치 문서만으로 해당 버튼을 dirty-only 방식으로 변경하지 않습니다.
- **웹훅**: 수정 시점에 전체 동기화 웹훅을 호출하지 않습니다. 기존 원본의 `mark-report-source-dirty` 마커 웹훅을 사용할 경우에도 역할은 `학습정보 수정일` 기록으로 한정합니다.
- **환경별 값**: 없음
- **필요한 Secret (이름만)**: 없음
- **마이그레이션 / 재배포**: 없음
- **검증**: 실제 자동화 연결·동기화 요청·리포트 반영은 별도 승인된 테스트가 필요하며 이번 문서 패치에서는 실행하지 않습니다.
- **실패 시 대처**: 자동화가 연결되지 않았거나 대상 속성이 다르면 속성·업무 데이터·웹훅을 임의로 변경하지 않고 미검증으로 기록합니다.
- **매뉴얼**: 변경 없음.
