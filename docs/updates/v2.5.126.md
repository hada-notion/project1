# v2.5.126 — 학습기록 단원 직접 고르기("선택 단원")

- 날짜: 2026-10-14
- 이전 버전: v2.5.125
- 요약: 수업 관리에서 기록을 만들거나 고칠 때 단원을 체크박스로 고르고, 리포트·수업 관리가 고른 단원을 보여 준다.
- 매뉴얼 영향: 있음 → 수업 관리 기록 만들기 안내(아래 "매뉴얼")
- 변경 유형: Notion DB 속성 추가(운영자 직접), 마이그레이션(자동 적용), 함수(자동 배포), 화면(Pages). 새 Secret 없음.

---

## 항목 1. 학습기록 DB에 "선택 단원" 속성 추가

- **유형**: 운영자 직접(학원 Notion, 원본은 2026-10-14 추가함)
- **순서**:
  1. Notion 학습기록(학원) DB에서 속성 추가 → 관계 → 대상 `단원목록(학원) DB`.
  2. 이름은 정확히 `선택 단원`. "단원목록(학원) DB에 표시"를 켜고 그쪽 이름은 `학습기록`(양방향).
  3. 학습기록 페이지 사이드바에서는 "비어 있으면 숨기기"로 둬도 된다.
- **확인**: 수업 관리에서 단원을 골라 기록을 만든 뒤 Notion 학습기록 페이지의 `선택 단원`에 그 단원이 연결됐는지.
- **이 속성이 없을 때**: 지금처럼 동작한다(단원은 `단원` 수식). 단원을 골라 저장하면 "학습기록 DB에 '선택 단원' 속성이 없어 고른 단원은 저장하지 않았어요" 안내가 나온다.

## 항목 2. 고르기·저장·보여 주기

- **유형**: AI 자동(`main` 병합 시 마이그레이션·함수·Pages 반영)
- **대상 파일**: `supabase/functions/_shared/selectedUnits.ts`(새 파일), `supabase/functions/_shared/classRoom.ts`, `supabase/functions/_shared/classRoom_test.ts`, `supabase/functions/_shared/classRoomCopy.ts`, `supabase/functions/_shared/classRoomRead.ts`, `supabase/functions/_shared/reportCacheBuilder.ts`, `supabase/functions/_shared/libraryCopy.ts`, `supabase/migrations/20261014090000_record_selected_units.sql`, `class_room.js`, `class_room.html`, `library.html`(문구), `docs/DESIGN.md`
- **동작**:
  - 화면: 범위 칸 아래 단원 안내 한 줄 + 접기 [단원 고르기](교재 단원 전체 체크 목록). 직접 고르지 않으면 범위에 걸친 단원이 입력하는 대로 골라지고, 체크를 바꾸면 그때부터 고른 대로([범위로 다시 고르기]로 되돌림). 교재를 바꾸면 고른 것은 비워진다.
  - 저장: 기록 만들기는 고른 단원을 같은 라이브러리 교재의 기록에만 `선택 단원`으로 넣는다. 기록 화면은 고른 단원이 바뀌었을 때만 보낸다(모두 빼면 비움).
  - 보여 주기: 수업 관리 기록·학부모 리포트 학습기록의 단원은 `선택 단원`이 있으면 그 단원 이름(라이브러리 복사본에서, 없으면 Notion), 없으면 `단원` 수식. 수업 관리 복사본 `cr_records`에 고른 단원 id 열(`unit_ids`)을 더한다.
  - 라이브러리: 단원목록 쪽 `학습기록` 관계가 생기므로, 학습기록에 쓰인 단원은 라이브러리 [편집]에서 지울 수 없다(시험범위와 같은 규칙).
- **검증(모의 데이터)**: 함수 테스트(같은 교재 기록에만 저장, 다른 교재·속성 없는 학원, 바꾸기·비우기·보내지 않으면 그대로, 고른 단원 이름이 단원 글자로, 비우면 수식), 전체 테스트·타입 검사·회귀 가드·디자인 검사, 수업 관리 UI 검사(자동 고르기·직접 고르기·범위 무시·보낸 값), 라이브러리 UI 검사.
- **원본 Notion**: 학습기록(학원) DB에 `선택 단원` 관계(→ 단원목록, 양방향 `학습기록`) 추가 — 원문 확인.
- **미검증**: 실제 수업 관리에서 고른 단원 저장·리포트 표시, 학원 Notion 속성 추가.
- **실패 시 대처**: 단원 표시가 이상하면 학습기록의 `선택 단원`을 비우면 `단원` 수식으로 돌아간다.

## 매뉴얼

수업 관리 기록 만들기 안내 끝에 추가할 문장:

> 범위 아래 [단원 고르기]를 펼치면 교재 단원을 직접 체크할 수 있습니다. 고르지 않으면 범위에 맞는 단원이 자동으로 골라지며, 고른 단원은 학부모 리포트에 그대로 보입니다.
