## 항목 1. 버전 표시

- **유형**: AI 자동
- **대상 파일**: `student_report.html`(스크립트 두 줄), `tests/design-lint.cjs`(검사 대상에 두 스크립트 추가), `docs/DESIGN.md`
- **앞으로**: 리포트 스크립트를 고치면 커밋 전에 `node tests/design-lint.cjs --fix`를 실행한다. 버전이 파일 내용과 다르면 웹 검사(CI)가 실패한다. `hada_config.js`는 학원마다 다른 설정 파일이라 버전 표시를 붙이지 않는다(기존과 같음).
- **검증**: 디자인 검사(버전 일치), 리포트 화면 흐름 검사(스크립트 정상 로드·오류 없음), 회귀 가드.
- **실패 시 대처**: `student_report.html`의 두 스크립트 주소에서 `?v=…`를 뺀다.
