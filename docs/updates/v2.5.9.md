# v2.5.9 — 새 학원 이식 문서 보강 (연결 문자열 예시·동기화 흐름·재실행 참고)

- 날짜: 2026-10-06
- 이전 버전: v2.5.8
- 요약: 새 학원 이식 체크리스트에 DB 연결 문자열(Session pooler) 작성 예시와 보고서 동기화 흐름(수정일→스캔→동기화→발송) 표를 추가하고, 버튼-웹훅 매핑에 확인된 범위의 재실행 안전성 참고를 추가했다. 강인희 피드백의 "설정 위치별 입력표"·"웹훅 완성된 설정"·"설치 체크리스트" 요구는 이미 이 두 문서와 "새 학원 최초 설치·배포" Notion 페이지가 다루고 있어 별도 문서를 새로 만들지 않았다.
- 매뉴얼 영향: 있음 → "새 학원 최초 설치·배포" 페이지 단계 2·4에 동일 내용 반영

> 이번 패치는 코드·Notion 자동화·Secrets 변경이 없다. 기존 v2.5.5·v2.5.6에서 이미 확정된 트리거 속성 결정을 그대로 인용했고, 재실행 안전성은 시스템 정보에 이미 기록된 패치 로그에서 확인된 범위만 인용했다. 추정으로 새 내용을 만들지 않았다.
