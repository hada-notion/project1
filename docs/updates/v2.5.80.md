## 항목 1. 함수 `class-room`

- **유형**: AI 자동(병합 시 자동 배포)
- **대상 파일**: `supabase/functions/_shared/classRoom.ts`, `supabase/functions/_shared/classRoom_test.ts`
- **바뀐 점**:
  - `books`: 교재마다 표지(정규교재 "북커버" 파일 주소), 전체 페이지, 진행도(%), 최근 학습 범위를 더 돌려준다(학부모 리포트 교재 카드와 같은 속성).
  - `classes`(새) — 날짜와 강사를 받아 그 강사의 수업(기준일 4주 전 ~ 4주 뒤, 보강 제외)을 반별로 묶고, 반마다 이름·이모지, 그날 수업(시간순), 그날 뒤 첫 수업, 그날 전 마지막 수업을 돌려준다. 조회만 한다.
- **검증**: `deno check`, Deno 테스트 192개(수업방 16개: 강사 반만·보강 제외·오늘/다음/마지막·잘못된 날짜와 강사 400, 교재 표지·쪽수·진행도·최근 범위와 값이 없을 때 빈 값).

## 항목 2. 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`, `class_room.html`, `docs/DESIGN.md`
- **바뀐 점**:
  - ≡ 왼쪽 서랍: 클래스 한 줄 [이모지] [클래스명] [오늘 수업시간]. 오늘 수업이 있는 반이 시간순으로 위, 없는 반은 이름순으로 아래(시간 칸에 "수업 없음"). 반을 누르면 오늘 수업(진행 중 → 다음 → 마지막) → 다음 수업 → 가장 최근 수업 순으로 연다. 아래에 보강 대기실, 맨 아래 강사 바꾸기.
  - 📅 오른쪽 서랍: 이 반 월 캘린더(수업 날 칠함, 보는 날 진하게, 오늘 빨간 테두리, ‹ › 달, [오늘]) + [‹ 직전] [다음 ›]. 날짜를 고르면 닫히고 보던 탭은 그대로.
  - 서랍은 바깥을 누르거나 ✕로 닫는다. 서랍 머리는 상단 바와 같은 높이(56)라 ✕가 상단 바 버튼과 같은 선에 온다.
  - 상단 바는 학부모 리포트처럼 화면 폭 전체이고 양끝 버튼(≡·📅, ←·↗)이 화면 가장자리에 붙는다. 본문은 640 한 줄 그대로.
  - 학생 목록: [이름] [출석 상태] [등원] [하원] [메모] 한 줄과 열 제목 줄. 이름을 누르면 학생 공간. 편집 중에는 [이름] [출석|결석|보강]만. 과제 검사 줄도 동그라미 없이.
  - 기록 만들기: 순서를 클래스 → 교재 → 구분 → 주제 → 범위 → 내용으로 바꿨다. 클래스는 반 이름만(같은 이름이 둘이면 시간). 교재는 드롭다운 대신 리포트 교재 카드 모양([표지] [교재명 / 반 교재·n명·쪽수 / 진도 막대 / 최근 범위])이고, 누르면 같은 창이 교재 카드 목록(반 교재 / 개별 "n명 모두"·학생별 / 학생별 / 교재 없이)으로 바뀐다. 고르지 않으면 만들지 않는다. 표지가 안 열리면 책 아이콘.
  - 기록 카드: 교재 칸도 같은 교재 카드다. 누르면 같은 교재 고르기 목록(기록 하나라 "n명 모두" 묶음은 없음, 지금 교재는 진행 중이 아니어도 보임)에서 바꾸고 [기록 저장]으로 저장한다. 고르는 동안 적던 주제·범위·내용은 그대로.
  - 메모 창: 메모 아이콘(Feather file-text, 메모가 있으면 색 바탕)을 누르면 메모가 바로 보이고, 고쳐 [저장]하면 바로 저장. 빠른 입력 "교재 두고 옴 / 과제 안 해 옴 / 집중 좋음 / 조퇴"는 메모 끝에 붙는다.
- **검증(모의 데이터)**: 수업방 화면 흐름 검사 390·768·1280(기록 만들기 교재 카드: 고르지 않으면 오류·교재 고르기 카드 목록과 묶음 진도 평균·고른 뒤 적던 범위 유지·표지 여백 위·왼쪽·아래 같음, 기록 카드 교재 바꾸기·묶음 카드 없음·적던 내용 유지·저장 값, ≡ 서랍 강사 바꾸기·클래스 순서와 시간·다른 반 고르면 다음 수업·현재 반 표시, 📅 서랍 칠한 칸·달 이동·바깥 눌러 닫기·직전 수업에서 학습기록 탭 유지·[오늘], 학생 줄이 열 제목과 가운데 1px 안으로 맞음·줄 높이 52, 메모 창 빠른 입력·저장 값, 기존 흐름 전체, 가로 넘침·글자 잘림·버튼 44px), 디자인 규칙 검사, 회귀 가드, `git diff --check`.
