# v2.5.55 — 학부모 리포트 링크 속성 이름 "학생 페이지"

- 날짜: 2026-10-12
- 이전 버전: v2.5.54
- 요약: 등록(학원) DB의 학부모 리포트 링크 수식 이름을 "안내 링크"에서 "학생 페이지"로 바꿨다. 링크 글자("학생 페이지 바로가기")와 [학생 페이지 동기화] 버튼과 같은 말을 쓰기 위해서다. 출석(학원) DB에는 이 링크를 등록 관계로 가져오는 롤업 "학생 페이지"를 추가했다. "보고서 링크"는 보고서(학원) DB·리포트의 보고서 탭과 헷갈려 쓰지 않았다.
- 매뉴얼 영향: 있음(등록·출석 DB 속성 설명)
- 변경 유형: Notion 속성 이름 1개 변경, 롤업 1개 추가. 저장소는 문서·스크립트 안내 문구만. 함수·마이그레이션·Secrets·웹 화면 변경 없음.

---

## 항목 1. 등록 DB 속성 이름 바꾸기

- **유형**: 운영자 직접
- **선행 조건**: 없음
- **운영자 안내문**
  - 왜 필요한가: 원본과 같은 이름을 써야 매뉴얼과 이후 패치 안내가 맞는다. 함수는 이 속성을 읽지 않으므로 바꾸지 않아도 기능은 그대로다.
  - 어디서: 등록(학원) DB의 "안내 링크" 수식 속성
  - 무엇을: 속성 이름을 `학생 페이지`로 바꾼다. 수식 내용(운영 GitHub Pages 주소)은 그대로 둔다.
  - 끝났는지 확인하는 방법: 등록 페이지 오른쪽에 "학생 페이지" 링크가 보이고 누르면 리포트가 열린다.

## 항목 2. 출석 DB 롤업 추가 (선택)

- **유형**: 운영자 직접
- **선행 조건**: 항목 1
- **운영자 안내문**
  - 왜 필요한가: 출석 페이지·수업의 출석 표에서 학생 리포트를 바로 열 수 있다.
  - 어디서: 출석(학원) DB
  - 무엇을: 롤업 속성 `학생 페이지` 추가 → 관계 `등록`, 속성 `학생 페이지`, 계산 "원본 표시".
  - 끝났는지 확인하는 방법: 수업 페이지 출석 표에 "학생 페이지 바로가기" 링크가 보인다.

## 항목 3. 저장소 문서

- **유형**: AI 자동
- **대상 파일**: `docs/새-학원-이식-체크리스트.md`, `scripts/setup-new-academy.py`(안내 문구만)
- **변경 내용**: "안내 링크" → "학생 페이지"(예전 이름 함께 표기). 출석 DB 롤업은 따로 고칠 필요 없다는 안내 추가.
- **실패 시 대처**: 문구만 바뀌었으므로 되돌릴 필요 없음.
