# v2.5.127 — 학습기록 단원을 관계 하나로, [단원 입력] 버튼, 쉼표 범위

- 날짜: 2026-10-14
- 이전 버전: v2.5.126
- 요약: 학습기록의 단원을 단원목록과의 관계 하나(`단원`)로 정리한다. Notion에서는 [단원 입력] 버튼으로 범위만큼 단원을 채우고, 범위는 쉼표로 여러 구간을 쓸 수 있다.
- 매뉴얼 영향: 있음 → 교재·학습 7-3 학습 내용 입력(아래 "매뉴얼")
- 변경 유형: 함수(새 함수 `fill-record-units`, 자동 배포), 화면(Pages), Notion 속성 이름 바꾸기·버튼(운영자 직접). 마이그레이션 없음. 새 Secret 없음.

---

## 항목 1. [단원 입력] 버튼과 쉼표 범위

- **유형**: AI 자동(`main` 병합 시 함수·Pages 반영)
- **대상 파일**: `supabase/functions/fill-record-units/index.ts`(새 함수), `supabase/functions/_shared/selectedUnits.ts`, `supabase/functions/_shared/unitRange.ts`(새 파일), `supabase/functions/_shared/selectedUnits_test.ts`(새 파일), `supabase/functions/_shared/classRoom.ts`, `supabase/functions/_shared/adminSecurity.ts`(웹훅 경로), `admin_settings.js`(웹훅 체크리스트 [단원 입력]), `class_room.js`, `docs/DESIGN.md`, `docs/버튼-웹훅-매핑.md`, `.github/workflows/deploy-supabase-functions.yml`(테스트 추가)
- **동작**:
  - `fill-record-units`: 학습기록 한 건의 지금 범위로 그 교재(라이브러리)의 단원을 찾아 단원 관계를 새 값으로 채운다(토글 아님, 범위가 비었거나 맞는 단원이 없으면 비움). 수업 시작 전에는 범위를 모를 수 있으므로 자동으로 다시 계산하지 않고, 범위를 정한 뒤 버튼을 누른다.
  - 범위 규칙(서버·수업 관리 같음): 쉼표로 구간을 나누고(`12-24, 31-35`), 구간마다 숫자의 처음~끝. 단원 i는 시작쪽부터 다음 단원 시작쪽 앞까지.
  - 이름: 단원 관계는 `단원`(최종) 또는 `선택 단원`(v2.5.126) 중 관계인 쪽을, 예전 수식은 `단원`(수식일 때) 또는 `단원(수식)`을 읽는다. 그래서 아래 이름 바꾸기 전후 모두 동작한다.
- **검증(모의 데이터)**: 함수 테스트(쉼표 구간·뒤집힌 숫자·마지막 단원·시작쪽 없음, 버튼 덮어쓰기·비우기·옛 이름, 교재 없음·속성 없음, 두 이름 읽기), 전체 테스트·타입 검사·회귀 가드·디자인 검사, 수업 관리 UI 검사(쉼표 범위).

## 항목 2. Notion 정리(학원마다, 원본은 승인 후 적용)

- **유형**: 운영자 직접(이번 배포가 끝난 뒤에 한다 — 먼저 하면 지금 코드가 단원을 못 읽는다)
- **순서**:
  1. 학습기록(학원) DB `단원`(수식) 속성 이름을 `단원(수식)`으로 바꾸고 페이지에서 숨긴다. 지우지 않는다 — 다른 수식·롤업이 이 속성을 쓰고 있어도 그대로 동작한다(Notion은 이름이 아니라 속성 id로 참조).
  2. `선택 단원`(관계) 이름을 `단원`으로 바꾸고, 페이지 본문 탭의 범위 아래에 보이게 둔다. (v2.5.126 속성을 아직 안 만든 학원은 관계 속성 `단원`을 새로 만든다: 대상 단원목록(학원) DB, 양방향 이름 `학습기록`.)
  3. 학습기록 DB에 버튼 속성 `단원 입력` → 동작 "웹훅 보내기" → `https://<학원 Supabase 주소>/functions/v1/fill-record-units`, 헤더 `x-admin-key: <웹훅 키>`(다른 버튼과 같은 키, 값은 문서에 쓰지 않는다).
  4. 범위가 있는 기존 학습기록은 [단원 입력]을 한 번씩 누르거나, 원본처럼 한 번에 채운다.
- **확인**: 학습기록에서 범위를 `p.12-24, 31-35`처럼 넣고 [단원 입력] → `단원`에 해당 단원이 연결되고, 수업 관리·리포트(동기화 후)에 그 단원이 보이는지.

## 매뉴얼

교재·학습 7-3 학습 내용 입력에 추가할 문장:

> 범위를 정한 뒤 학습기록의 [단원 입력]을 누르면 교재 단원 중 범위에 걸친 단원이 `단원`에 채워집니다(누를 때마다 새로 채움). 범위는 `12-24, 31-35`처럼 쉼표로 여러 구간을 쓸 수 있습니다. 수업 관리에서 기록을 만들면 범위 아래 [단원 고르기]로 직접 고를 수도 있습니다.
