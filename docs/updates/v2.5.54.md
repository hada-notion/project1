## 항목 1. 학부모 리포트 화면

- **유형**: AI 자동
- **선행 조건**: 없음
- **대상 파일**: `student_report.html`(색 변수 4개·새 화면 스타일 추가), `student_report_part1.js`(탭 목록·첫 탭·캘린더 날짜 선택), `student_report_part2.js`(홈·교재·일간 보고서·캘린더 화면)
- **변경 내용**
  - 하단 탭: 홈 · 교재 · 캘린더 · 학습기록 · 보고서. 반을 열면 홈이 먼저 보인다.
  - 홈: 반 이름·선생님·수업 요일, 오늘(출석·남은 과제·다음 수업), 곧 마감 과제, 진행 중 교재 진도, 최근 선생님 한마디.
  - 교재: 표지(없으면 교재 이름이 들어간 색 표지) + 진도 막대 + 최근 학습 범위의 목록. 탭에 개수.
  - 일간 보고서: 출석·이날 마감 과제를 한 카드 두 칸 요약으로, 학습·다음 과제·평가를 학습기록과 같은 분류 아이콘으로 한 카드에. 선생님 코멘트는 말풍선 카드. 주간·월간 보고서는 그대로.
  - 캘린더: 월요일 시작, 수업 있었던 날만 색칠, 남은 수업일(시간표 기준, 휴원 제외)은 테두리. 달력 위에 그달 수업 횟수만큼 칸을 나눈 막대(예: `3 / 7회`)와 숫자 칩. 날짜를 누르면 그 주 한 줄로 접히고 아래에 그날 학습·과제·평가와 [이날 보고서 보기].
  - 그대로 둔 것: 학생 첫 화면, 학습기록 탭 내용, 교재 상세, 주간·월간 보고서, 오른쪽 아래 새로고침 버튼.
- **환경별 값 (중요)**: `student_report_part1.js`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값을 유지**한다. 세 파일 모두 바뀐 범위가 넓으므로 원본 파일을 받은 뒤 이 두 값만 운영 값으로 되돌려 넣는다(덮어쓴 뒤 두 값이 운영 값과 같은지 반드시 확인). 운영에서 리포트를 따로 고친 부분이 있으면 덮어쓰기 전에 차이를 비교한다.
- **검증**: Pages 반영 후 학생 리포트 링크를 열어 반을 누르면 홈 탭이 먼저 나오는지, 캘린더에서 날짜를 누르면 주간으로 접히고 그날 기록이 보이는지, [월 전체 보기]로 돌아오는지 본다. 학습기록 탭은 이전과 같아야 한다.
- **실패 시 대처**: v2.5.53의 세 파일로 되돌린다. 데이터 영향 없음.
