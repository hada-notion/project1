## 항목 1. 달력 첫 요일 버튼

- **유형**: AI 자동(`main` 병합 시 Pages 반영)
- **대상 파일**: `student_report.html`, `student_report_part1.js`, `student_report_part2.js`, `class_room.html`, `class_room.js`, `docs/DESIGN.md`
- **동작**:
  - 달력 왼쪽 위 ‹ 오른쪽에 [월–일] 버튼. 누를 때마다 [일–토]와 바뀌고 달력이 바로 다시 그려진다. 버튼에는 지금 상태가 적힌다.
  - 기기별 저장(브라우저 저장소). 같은 기기에서는 학부모 리포트와 수업 관리가 같은 값을 쓴다. 처음 기본값은 월–일.
  - 적용: 학부모 리포트 출석·과제 달력(월 보기, 날짜를 고른 주 한 줄), 학원 일정 달력, 보고서 일간·월간 날짜 선택 달력, 수업 관리 캘린더.
  - 그대로 월요일 시작: 주간 보고서 기간과 주 선택 달력(보고서 주가 월~일), 수업 관리 홈 주간 시간표.
- **검증**: 디자인 검사, 리포트 UI 검사(요일 머리·1일 위치·저장·새로고침 뒤 유지·390/1280), 학원 일정 달력 전환(2026년 10월 1일 목요일이 일요일 시작에서 다섯째 칸), 수업 관리 UI 검사(전환 뒤 수업 날 그대로, 390/768/1280).
- **미검증**: 실제 운영 화면(병합 후 확인).

## 항목 2. 시험 관리 자리와 상단 메뉴 폭

- **유형**: AI 자동(`main` 병합 시 Pages 반영)
- **대상 파일**: `assets/hada-shortcuts.js`, `assets/hada-ui.css`
- **동작**:
  - 관리 화면 상단 메뉴에 [시험 관리] 탭이 흐리게 보인다. 누르면 이동하지 않고 탭 이름 자리에 1.5초 동안 "준비 중". 380px 이하 아주 좁은 폰에서는 숨긴다.
  - 탭이 5개가 되면서 넘치던 폭을 고쳤다: 1180px 이하에서 메뉴를 아래 줄로, 900px 이하에서 탭 아이콘을 빼고 새 탭 링크는 아이콘만, 420px 이하에서 탭 여백을 줄인다. 누르는 영역은 그대로 44.
- **검증**: 관리자 설정·학교 검색·법정 서류·라이브러리·키오스크 UI 검사, 320~1400px을 10px 단위로 재서 상단 메뉴가 상단 바 밖으로 넘치는 폭 없음(이전 v2.5.129는 320~370·710~780에서 조금 넘쳤음).
- **미검증**: 실제 운영 화면(병합 후 확인).
