# v2.5.16 — 디자인 통일 2단계 (학교 검색) · 키오스크 학원 이름

- 날짜: 2026-10-13
- 이전 버전: v2.5.15
- 요약: 학교 검색 화면을 공용 디자인으로 옮기고 상단 바·바로가기를 붙였다. 키오스크는 로고를 빼고 카드 아래에 학원 이름을 작게 표시한다. 학원 이름은 각 학원 Notion 최상위 페이지 제목에서 자동으로 가져온다.
- 매뉴얼 영향: 있음 → 항목 3
- 변경 유형: 웹 화면·Edge Function(`list-students`)·문서. 마이그레이션·Secrets·Notion DB 스키마·업무 데이터 변경 없음.

---

## 항목 1. 키오스크 학원 이름 (서버)

- **유형**: AI 자동
- **선행 조건**: 운영 소유자의 전체 계획 승인, v2.5.15 적용.
- **대상 코드**
  - 신규 `supabase/functions/_shared/academyName.ts`(+ `academyName_test.ts`)
  - 수정 `supabase/functions/list-students/index.ts`: 키오스크 최소 목록(`?kiosk=1`) 응답에 `academyName` 추가
  - 수정 `.github/workflows/deploy-supabase-functions.yml`: 새 테스트를 키오스크 테스트 단계에 추가
- **변경 내용**: 등록 DB에서 Notion 부모를 따라 올라가 workspace 바로 아래 페이지(원본: "하다 학원관리 v2.0")의 제목을 학원 이름으로 쓴다. 함수 인스턴스 안에서 1시간 재사용한다. 중간 부모에 접근할 수 없으면 잘못된 이름 대신 빈 값을 돌려주고, 키오스크는 이름 줄을 숨긴다. 학생 목록·출석 처리는 바뀌지 않는다.
- **환경별 값**: 없음.
- **필요한 Secret**: 없음(기존 Notion 토큰 사용).
- **Notion 변경**: 없음. 단, 최상위 페이지가 Notion 연결(integration)에 공유되어 있어야 이름이 나온다(항목 3).
- **마이그레이션 / 재배포**: 마이그레이션 없음. 기존 CI가 함수 전체를 재배포한다. **함수 배포를 먼저 끝낸 뒤 화면(Pages)을 반영한다.**
- **검증**: Deno 테스트(이름 찾기·공유 안 됨·이상한 부모), 배포 후 키오스크 로그인 시 카드 아래 학원 이름 표시.
- **실패 시 대처**: 이름이 안 나오면 업무에는 영향이 없다. 항목 3의 공유 상태를 확인한다.

## 항목 2. 화면 (학교 검색, 키오스크, 바로가기)

- **유형**: AI 자동
- **선행 조건**: 항목 1 배포.
- **대상 파일**: `school_search.html`, `attendance_kiosk.html`, `admin_settings.html`, `admin_settings.js`, `assets/hada-ui.css`, 신규 `assets/hada-shortcuts.js`, `tests/design-lint.cjs`, `docs/DESIGN.md`
- **변경 내용**
  - 학교 검색: 공용 디자인(상단 바·로고·알림 줄·카드·버튼), 상태 문구를 위쪽 알림 줄로, 검색·연결 중 회전 표시, 어두운 모드 제거, 바로가기. 검색·연결·`pageId` 자동 선택 로직은 그대로.
  - 키오스크: 로고 제거, 카드 아래 학원 이름(서버 값, 없으면 숨김).
  - 바로가기 목록을 `assets/hada-shortcuts.js` 하나로 모아 관리자 설정·학교 검색이 같이 쓴다(지금 화면은 자동 제외).
- **환경별 값 (중요)**: `school_search.html`의 `ENDPOINT`(Supabase 주소)와 `attendance_kiosk.html`의 `SUPABASE_URL`·`SUPABASE_ANON_KEY`는 **운영 값을 유지**한다. 원본 파일을 가져온 뒤 이 값만 운영 값으로 되돌리거나 `scripts/setup-new-academy.py`의 치환을 다시 적용하고, 원문 비교로 확인한다.
- **검증**: `node tests/design-lint.cjs` 통과. Pages 반영 후 학교 검색(Notion 학교 페이지의 "학교 검색" 링크로 열어 자동 선택 확인), 키오스크(학원 이름 표시), 관리자 설정 바로가기 확인. 실제 학교 연결 저장은 시험용 학교 페이지에서만 한다.

## 항목 3. 운영자 확인과 매뉴얼

- **유형**: 운영자 직접
- **운영자 안내문**
  - 왜 필요한가: 키오스크에 표시되는 학원 이름은 Notion 최상위 페이지 제목이다.
  - 어디서: Notion 학원관리 최상위 페이지(원본 이름 "하다 학원관리 v2.0").
  - 무엇을: 1. 페이지 제목을 학원 이름으로 바꾼다. 2. 그 페이지가 학원관리 Notion 연결에 공유되어 있는지 확인한다(페이지 오른쪽 위 ··· → 연결).
  - 끝났는지 확인하는 방법: 키오스크에서 로그아웃 후 다시 로그인하면 카드 아래에 학원 이름이 보인다(서버가 이름을 최대 1시간 재사용하므로 바로 안 바뀌면 잠시 뒤 확인).
- **매뉴얼**: 키오스크 안내에 "카드 아래 학원 이름은 Notion 최상위 페이지 제목에서 자동으로 표시됩니다"를 추가한다.
