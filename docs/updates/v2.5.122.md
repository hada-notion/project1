## 항목 1. 검색·추가 화면·시리즈 관리

- **유형**: AI 자동(`main` 병합 시 함수·Pages 반영)
- **대상 파일**: `supabase/functions/_shared/textbookSearch.ts`, `supabase/functions/_shared/textbookSearch_test.ts`, `supabase/functions/textbook-api/index.ts`, `library.html`, `assets/hada-tokens.css`(위·아래 화살표 아이콘), `docs/DESIGN.md`, 공용 스타일 버전 표시(`*.html`)
- **동작**:
  - 검색: 1~80자. 한 글자는 결과가 넓으니 좁히라는 안내 한 줄.
  - [라이브러리 추가]: 카드 ① 검색해서 추가, 카드 ② 직접 추가(설명 + 버튼).
  - [시리즈 관리]: 시리즈 목록(교재 수), [추가], ↑↓ 순서(= [라이브러리 열기] 묶음 순서), [이름 바꾸기](그 시리즈 교재에 모두 반영), 삭제(교재가 0권일 때만). 바꿀 때마다 Notion의 지금 선택지를 새로 읽어 고친 뒤 보내며, 기존 선택지는 그대로 유지한다. 쉼표(,)가 든 이름과 같은 이름은 받지 않는다.
  - 고르기: 추가 창(검색·직접 추가)과 단원 창 [편집]에 `[시리즈 ▾] [출판사 ▾]`. 선택지에 있는 값만 넣는다(출판사 선택지는 Notion에서 관리). 검색한 교재는 자동으로 맞춘 값이 미리 골라져 있다. 직접 추가의 출판사는 자유 입력에서 고르기로 바뀌었다.
- **검증(모의 데이터)**: 함수 테스트(고른 시리즈·출판사 우선·비움·없는 이름 거부, 교재 정보 고치기, 시리즈 추가·이름·순서·삭제와 id 유지, 쓰는 시리즈·같은 이름·쉼표 거부, Notion 거부 시 안내), 전체 테스트·타입 검사·회귀 가드·디자인 검사, 라이브러리 UI 검사 6개 크기(세 탭, 두 카드, 시리즈 관리, 고르기 전송).
- **미검증**: 실제 Notion에서 선택지 이름 바꾸기·순서 바꾸기·삭제가 API로 되는지(추가는 Notion API가 지원하는 방식). 안 되면 화면에 "Notion에서 직접 고쳐 주세요"가 나온다. 실제 Notion 등록·편집.
- **실패 시 대처**: 시리즈 변경이 거부되면 Notion 라이브러리 DB "시리즈" 속성에서 직접 고친다. 화면은 다시 열면 Notion 선택지를 다시 읽는다.

## 항목 2. Notion 연결 권한 확인

- **유형**: 운영자 직접
- **내용**: [시리즈 관리]는 라이브러리 DB의 속성(선택지)을 고친다. 이 학원의 Notion 연결(integration)에 라이브러리 DB 편집 권한이 있어야 한다(교재 페이지를 만드는 권한과 같은 연결). [시리즈 추가]가 "Notion이 시리즈 변경을 받지 않았습니다"로 실패하면 연결 권한을 확인한다.
