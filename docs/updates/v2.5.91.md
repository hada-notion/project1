# v2.5.91 — 수업 관리 첫 화면 클래스가 많을 때

- 날짜: 2026-10-14
- 이전 버전: v2.5.90
- 요약: 담당 클래스가 많아 첫 화면이 한 화면을 넘으면 [통합 시간표 보기]가 보강 대기실 카드와 겹치고, 위 새로고침·☰ 아이콘이 잘려 보였다(카카오톡 인앱 브라우저에서 확인). 오늘 수업이 있는 반만 펼쳐 두고 나머지는 접어 화면을 줄이고, 겹침·잘림을 고쳤다.
- 매뉴얼 영향: 수업 관리 매뉴얼 작성 때 "다른 클래스 n개" 설명
- 변경 유형: 웹 화면만(Pages). 함수·Notion 변경 없음.

---

## 항목 1. 화면

- **유형**: AI 자동
- **대상 파일**: `class_room.js`, `class_room.html`, `docs/DESIGN.md`
- **동작**
  - 오늘 수업이 있는 반은 모두 보이고, 오늘 수업이 없는 반은 "다른 클래스 n개 ⌄" 한 줄로 접는다. 누르면 펼치고 다시 누르면 접는다. 이 기기에 기억하지 않아 다시 열면 접혀 있다. 오늘 수업이 있는 반이 없으면 모두 보인다. 다른 반은 통합 시간표에서도 들어갈 수 있다.
  - [통합 시간표 보기]는 화면 아래 고정이 아니라 내용 아래에 붙는다. 칸이 넉넉하면 칸 맨 아래, 내용이 길면 보강 대기실 아래로 밀려 겹치지 않는다.
  - 첫 칸이 화면보다 길어도 위에서부터 보이고(위 아이콘 잘림 없음), 그 칸 안에서 끝까지 내려간 뒤 통합 시간표로 넘어간다.
- **검증(모의 데이터)**: 수업 관리 화면 흐름 검사 390·768·1280 — 오늘 반 2개만 보이고 "다른 클래스 1개" 펼침·접힘, 전체 수업 12반(오늘 9반)에서 처음 열 때 위 아이콘이 보이고, [통합 시간표 보기]가 보강 대기실 아래에 있고, 첫 칸 안에서 끝까지 내려감, 기존 흐름 전체. 디자인 규칙 검사, 회귀 가드.
- **미검증**: 카카오톡 인앱 브라우저·iOS 사파리 실기기.
- **실패 시 대처**: v2.5.90의 `class_room.js`·`class_room.html`로 되돌린다.
