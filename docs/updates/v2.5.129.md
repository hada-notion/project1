## 항목 1. 상단 바

- **유형**: AI 자동(`main` 병합 시 Pages 반영)
- **대상 파일**: `assets/hada-shortcuts.js`, `assets/hada-ui.css`, `admin_settings.html`, `admin_settings.js`, `legal_documents.html`, `school_search.html`, `library.html`, `docs/DESIGN.md`(버전 표시만 바뀐 `attendance_kiosk.html`, `class_room.html` 포함)
- **동작**:
  - "관리자 전용" 배지를 없앤다(넓은 화면에서 두 줄로 깨졌고, 로그인으로 이미 막혀 있어 뜻이 없음).
  - 탭 순서: 관리자 설정 · 라이브러리 · (시험 관리) · 학교 검색 · 법정 서류. 시험 관리는 목록에 자리만 두고 화면이 생기기 전까지 보이지 않는다.
  - 보안 설정 현황·로그아웃은 맨 오른쪽 ⋯ 메뉴 안에 있다. 바깥을 누르거나 Esc, 항목을 고르면 닫힌다. 로그인 전에 보일 항목이 없으면 ⋯도 숨긴다.
  - 관리자 설정의 로그아웃은 대시보드 아래에서 ⋯ 메뉴로 옮겼다(대시보드에서만 보임).
  - 휴대폰 폭 짧은 이름: 설정·라이브러리·시험·학교·서류.
- **검증**: 디자인 검사, 관리자 설정·학교 검색·법정 서류·라이브러리·키오스크·수업 관리 UI 검사(⋯ 열기·Esc 닫기·로그인 전 숨김 포함), 상단 바 전후 캡처(1280·768·390, 가로 넘침 없음, ⋯ 누르는 영역 44×44, 메뉴 항목 높이 44).
- **미검증**: 실제 운영 화면(병합 후 확인).

## 항목 2. 매뉴얼 표현

- **유형**: 운영자 직접(학원 매뉴얼에 로그아웃·보안 설정 현황 위치를 적어 두었다면)
- **내용**: "오른쪽 위 [로그아웃]" 같은 표현을 "오른쪽 위 ⋯ → 로그아웃"으로 바꾼다.
