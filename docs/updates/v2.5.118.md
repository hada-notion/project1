## 항목 1. 교재 검색 화면과 함수

- **유형**: AI 자동(`main` 병합 시 함수 배포·Pages 반영)
- **대상 파일**: `textbook_search.html`, `supabase/functions/textbook-api/index.ts`, `supabase/functions/_shared/textbookSearch.ts`, `supabase/functions/_shared/textbookToc.ts`, 테스트(`textbookSearch_test.ts`, `textbookToc_test.ts`, `adminSecurity_test.ts`), `supabase/functions/_shared/adminSecurity.ts`(브라우저 경로에 `textbook-api`), `assets/hada-shortcuts.js`·`assets/hada-ui.css`(상단 메뉴), `tests/design-lint.cjs`, `scripts/check-known-regressions.sh`, `.github/workflows/deploy-supabase-functions.yml`, `docs/DESIGN.md`, `docs/새-학원-이식-체크리스트.md`
- **동작**:
  - 관리자 로그인(다른 관리 화면과 같은 탭에서 공유) → 교재명·시리즈 검색(알라딘 최대 20권) → 결과마다 표지·출판사·출간일·가격·ISBN13, 같은 ISBN13이 정규교재 DB에 있으면 "등록됨"(체크 불가).
  - 체크하면 그 책의 목차를 단원 후보로 나눈다. 대단원이 있으면 `1-1. 중단원명`(중단원 번호는 대단원마다 1부터), 없으면 `1. 중단원명`. 대단원 이름·소단원은 단원으로 만들지 않고, 줄 끝 쪽수가 있으면 시작쪽으로 넣는다(중단원에 쪽수가 없으면 첫 소단원 쪽). 정답·해설·머리말·차례 줄은 처음부터 뺀다. 목차가 없으면 목차를 붙여넣어 나눈다.
  - 교재명·단원명·시작쪽은 등록 전에 고칠 수 있다. [선택한 교재 등록] → 확인 창 → 교재 하나씩 등록.
  - 정규교재: 교재명, ISBN13, 가격, 전체 페이지, 북커버(교보문고 ISBN 주소, 이미지가 없으면 넣지 않음), 사용중 체크. 출판사·시리즈는 기존 선택지와 맞을 때만(새 선택지를 만들지 않음). 과목·교육과정·교재 유형은 비워 둔다.
  - 단원목록: 단원명, 시작페이지(있을 때만), 정규교재 관계.
  - DB 위치는 진도교재 DB의 "정규교재" 관계와 정규교재 DB의 "단원목록" 관계에서 찾는다(새 Notion ID 설정 없음).
  - 상단 메뉴에 [교재 검색] 추가. 휴대폰 폭(700px 이하)에서는 메뉴가 넘치지 않도록 탭 이름을 짧게(설정·서류·학교·교재) 보인다.
- **검증(모의 데이터)**: 목차 변환 테스트 8개(대단원 유무, 소단원 쪽수, 번호 모양, 뺄 줄, 연도는 쪽수 아님), 함수 테스트 6개(출판사·시리즈 맞추기, 검색·등록됨, 목차, 등록 속성, 중복 409, 표지 없음, 단원 일부 실패, 키 없음 503), 관리자 경로 테스트, 전체 함수 `deno check`·테스트, 회귀 가드, 디자인 규칙 검사, UI 검사(교재 검색 6개 크기, 관리자 설정·학교 검색·법정 서류·키오스크·수업 관리).
- **미검증**: 실제 알라딘 응답(목차 모양·쪽수 유무), 실제 Notion 등록.
- **실패 시 대처**: 화면 링크를 쓰지 않으면 다른 기능에는 영향이 없다. 함수·화면 파일을 지우면 이전과 같다.

## 항목 2. 알라딘 키 넣기

- **유형**: 운영자 직접
- **선행 조건**: 항목 1 배포
- **운영자 안내문**: 알라딘에 로그인한 뒤 "Open API(TTB) 신청"에서 키를 발급받는다(무료, 학원 계정으로). Supabase 대시보드 → Edge Functions → Secrets에 이름 `ALADIN_TTB_KEY`로 저장한다. 키 값은 채팅·문서에 쓰지 않는다.
- **확인**: 교재 검색 화면에서 검색이 결과를 보여 준다(키가 없으면 "알라딘 키(ALADIN_TTB_KEY)가 설정되지 않았습니다").

## 항목 3. Notion 연결(선택)

- **유형**: 운영자 직접
- **운영자 안내문**: 정규교재 페이지(메뉴 > 6. 교재관리 > 정규교재) 안내 문구 근처에 교재 검색 화면 링크(`<Pages 주소>/textbook_search.html`)를 둔다. 상단 메뉴에서도 열 수 있으므로 필수는 아니다.

## 매뉴얼

7-6 "정규교재 북커버 입력" 끝에 추가할 문단:

> 새 교재는 교재 검색 화면(상단 메뉴 [교재 검색])에서 교재명이나 시리즈로 찾아 체크하면, 교재명·ISBN13·가격·쪽수·북커버와 목차에서 나눈 단원목록을 함께 만들 수 있습니다. 단원명은 대단원이 있으면 "1-1. 중단원명", 없으면 "1. 중단원명"이며 등록 전에 고칠 수 있습니다. 같은 ISBN13의 교재는 다시 만들지 않습니다.
