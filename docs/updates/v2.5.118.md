# v2.5.118 — 라이브러리(교재 보기·추가) 화면

- 날짜: 2026-10-14
- 이전 버전: v2.5.117
- 요약: 새 관리 화면 `library.html`(라이브러리)에서 Notion 정규교재 DB의 교재를 시리즈별로 보고 단원을 추가하며, 알라딘에서 교재를 찾아 정규교재와 단원목록(책소개 목차에서 나눈 단원)을 함께 추가한다. 북커버는 메뉴얼 7-6 규칙(ISBN13 교보문고 주소)으로 넣는다. "정규교재"와 "진도교재"가 헷갈린다는 의견에 따라 화면 이름을 "라이브러리"로 했다(Notion 속성 이름은 그대로).
- 매뉴얼 영향: 있음 → 7-6 "정규교재 북커버 입력" 아래에 라이브러리 화면 안내 한 단락(아래 "매뉴얼")
- 변경 유형: 새 함수 `textbook-api`(자동 배포), 새 화면(Pages), 상단 메뉴, 함수 Secret 1개(`ALADIN_TTB_KEY`, 운영자 직접). DB 구조·속성 이름 변경 없음.

## 항목 1. 라이브러리 화면과 함수

- **유형**: AI 자동(`main` 병합 시 함수 배포·Pages 반영)
- **대상 파일**: `library.html`, `supabase/functions/textbook-api/index.ts`, `supabase/functions/_shared/textbookSearch.ts`, `supabase/functions/_shared/textbookToc.ts`, 테스트(`textbookSearch_test.ts`, `textbookToc_test.ts`, `adminSecurity_test.ts`), `supabase/functions/_shared/adminSecurity.ts`(브라우저 경로에 `textbook-api`), `assets/hada-shortcuts.js`·`assets/hada-ui.css`(상단 메뉴), `tests/design-lint.cjs`, `scripts/check-known-regressions.sh`, `.github/workflows/deploy-supabase-functions.yml`, `docs/DESIGN.md`, `docs/새-학원-이식-체크리스트.md`
- **동작**:
  - 관리자 로그인(다른 관리 화면과 같은 탭에서 공유). 위쪽 전환 탭 `[라이브러리 열기 | 라이브러리 추가]`.
  - **열기**: 정규교재 DB의 교재를 시리즈별로(Notion 시리즈 선택지 순, 시리즈 없음은 맨 끝) 표지·교재명·단원 수·사용 여부와 함께 보여 준다. 교재명으로 찾기. 교재를 누르면 창에서 단원목록을 보고 새 단원을 추가한다(같은 이름은 건너뜀, 기존 단원은 고치거나 지우지 않음).
  - **추가**: 교재명·시리즈로 알라딘 검색(최대 20권) → 결과마다 표지·교재명·출판사(출간일·정가·ISBN13은 [자세히]) → 같은 ISBN13이 이미 있으면 "등록됨"(체크 불가) → 체크하면 목차를 미리 불러 둔다 → [라이브러리에 추가] → 창에서 "1 / n"으로 한 권씩 교재명·단원을 확인·수정하고 [등록하고 다음]. 이전·다음 버튼, 휴대폰은 좌우로 밀어도 넘어간다.
  - 단원명: 대단원이 있으면 `1-1. 중단원명`(중단원 번호는 대단원마다 1부터), 없으면 `1. 중단원명`. 대단원 이름·소단원은 단원으로 만들지 않고, 줄 끝 쪽수가 있으면 시작쪽(중단원에 쪽수가 없으면 첫 소단원 쪽). 정답·해설·머리말·차례 줄은 처음부터 뺀다. 목차가 없으면 붙여넣거나 [단원 추가]로 직접 넣는다(다음 번호를 미리 채움).
  - 정규교재: 교재명, ISBN13, 가격, 전체 페이지, 북커버(교보문고 ISBN 주소, 이미지가 없으면 넣지 않음), 사용중 체크. 출판사·시리즈는 기존 선택지와 맞을 때만(새 선택지를 만들지 않음). 과목·교육과정·교재 유형은 비워 둔다.
  - 단원목록: 단원명, 시작페이지(있을 때만), 정규교재 관계.
  - DB 위치는 진도교재 DB의 "정규교재" 관계와 정규교재 DB의 "단원목록" 관계에서 찾는다(새 Notion ID 설정 없음).
  - 상단 메뉴에 [라이브러리] 추가. 휴대폰 폭(700px 이하)에서는 메뉴가 넘치지 않도록 탭 이름을 짧게(설정·서류·학교·라이브러리) 보인다(읽어 주는 이름은 그대로).
- **검증(모의 데이터)**: 목차 변환 테스트 8개, 함수 테스트 9개(출판사·시리즈 맞추기, 검색·등록됨, 목차, 등록 속성, 중복 409, 표지 없음, 단원 일부 실패, 키 없음 503, 라이브러리 목록, 단원 순서·다른 DB 거절, 단원 추가 중복 건너뜀), 관리자 경로 테스트, 전체 함수 `deno check`·테스트, 회귀 가드, 디자인 규칙 검사, UI 검사(라이브러리 6개 크기 — 시리즈 묶음·찾기·단원 창·단원 추가·검색·창 1/3·이전/다음/스와이프·한 권씩 등록, 관리자 설정·학교 검색·법정 서류·키오스크·수업 관리).
- **미검증**: 실제 알라딘 응답(목차 모양·쪽수 유무), 실제 Notion 읽기·등록.
- **실패 시 대처**: 화면 링크를 쓰지 않으면 다른 기능에는 영향이 없다. 함수·화면 파일을 지우면 이전과 같다.

## 항목 2. 알라딘 키 넣기

- **유형**: 운영자 직접
- **선행 조건**: 항목 1 배포
- **운영자 안내문**: 알라딘에 로그인한 뒤 "Open API(TTB) 신청"에서 키를 발급받는다(무료, 학원 계정으로). Supabase 대시보드 → Edge Functions → Secrets에 이름 `ALADIN_TTB_KEY`로 저장한다. 키 값은 채팅·문서에 쓰지 않는다.
- **확인**: [라이브러리 추가]에서 검색이 결과를 보여 준다(키가 없으면 "알라딘 키(ALADIN_TTB_KEY)가 설정되지 않았습니다"). [라이브러리 열기]는 키 없이도 동작한다.

## 항목 3. Notion 이름 바꾸기(선택, 원본은 2026-10-14 적용)

- **유형**: 운영자 직접
- **운영자 안내문**: 헷갈림을 줄이려면 Notion에서 보이는 이름만 바꾼다 — 메뉴 페이지 `정규교재` → `라이브러리`, DB 제목 `정규교재(학원) DB` → `라이브러리(학원) DB`. **다른 DB의 관계 속성 이름 `정규교재`(진도교재·단원목록)는 바꾸지 않는다**(교재 생성·학습기록·학부모 리포트·수업 관리·라이브러리 코드가 이 이름으로 읽는다). 메뉴 페이지에 라이브러리 화면 링크(`<Pages 주소>/library.html`)를 두면 편하다(상단 메뉴에서도 열 수 있어 필수는 아님).

- **원본 적용 내용(2026-10-14)**: DB 제목 `라이브러리(학원) DB`, 메뉴 페이지 `라이브러리`, 메뉴얼(교재·학습 7-1·7-6, 메뉴얼 2장 교재 관리 흐름, 구조도 17-2-1·17-2-5, 웹훅 매핑 요약)의 정규교재 표기를 라이브러리로. 속성 이름 `정규교재`가 그대로인 문장은 "`정규교재`(라이브러리 교재 연결)"처럼 남겼다. 북커버 규칙(라이브러리 페이지 프롬프트·메뉴얼 7-6)에 영어 원서·수입 교재용 키다리영어샵(ltr.co.kr) 대표 이미지 규칙 추가. 시스템 정보의 지난 이력 기록은 고치지 않았다.

## 매뉴얼

7-6 "정규교재 북커버 입력" 끝에 추가할 문단:

> 라이브러리 화면(상단 메뉴 [라이브러리])의 [라이브러리 열기]에서 교재를 시리즈별로 보고 교재를 눌러 단원을 추가할 수 있습니다. [라이브러리 추가]에서 교재명이나 시리즈로 찾아 체크하면 교재명·ISBN13·가격·쪽수·북커버와 목차에서 나눈 단원목록을 한 권씩 확인하며 함께 만들 수 있습니다. 단원명은 대단원이 있으면 "1-1. 중단원명", 없으면 "1. 중단원명"이며 등록 전에 고칠 수 있습니다. 같은 ISBN13의 교재는 다시 만들지 않습니다.
