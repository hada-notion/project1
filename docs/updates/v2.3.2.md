## 항목 1. Notion 변경 — 학교(학원) DB에 "주소"·"홈페이지" 속성 추가

- **유형**: AI 자동
- **선행 조건**: 없음
- **변경 이유·증상**: 학교 검색 결과로 주소·홈페이지 정보를 받아도 저장할 속성이 없으면 운영자가 확인할 수 없습니다.
- **대상 코드**: 없음 (Notion 스키마 변경)
- **Notion 변경**: "학교(학원) DB"에 아래 속성이 이미 있으면 건너뛰고, 없으면 값은 비워 둔 채로 추가합니다.
  - text **주소**
  - url **홈페이지**
  - 뷰: 기존 "학교 검색·연결" 뷰(또는 동일 역할의 뷰)에 두 속성을 표시하면 운영자가 검색 결과를 바로 확인하기 편합니다(선택 사항).
- **환경별 값**: 없음
- **필요한 Secret (이름만)**: 없음
- **마이그레이션 / 재배포**: 없음
- **검증**:
  1. 학교 DB에 "주소"(텍스트), "홈페이지"(URL) 속성이 모두 존재하는지 확인한다.
  2. 테스트용 학교 페이지에서 두 속성에 값을 입력·저장할 수 있는지 확인한다.
- **실패 시 대처**: 속성이 없어도 기존 기능(학사일정 동기화 등)에는 영향이 없습니다. 재시도만 하면 됩니다.
- **매뉴얼**: 변경 없음
