# v2.6.15 — 수업 `생성 오류` 수식의 날짜범위 계산 바로잡기

- 날짜: 2026-10-16
- 이전 버전: v2.6.14
- 요약: 수업(학원) DB 수식 `생성 오류`의 "📅 날짜범위 밖" 계산을 `출석 조정 정보`·[수업추가] 명단과 같은 방식으로 바꾼다. 등록일·종료일이 빈 학생에서 `or`가 뒤쪽 날짜 계산까지 해 결과가 흔들리던 형태를 없앤다. 표시 내용(정상·누락·초과·중복·보강)은 그대로.
- 매뉴얼 영향: 없음
- 변경 유형: Notion 수식 1개(운영자 직접). 함수·화면·Supabase 변경 없음.

## 항목 1. 수업(학원) DB 수식 `생성 오류` 교체

- **유형**: 운영자 직접
- **선행 조건**: 수업(학원) DB에 `보강`(체크박스)이 있어야 한다(v2.6.1).
- **변경 이유**
  - 예전 수식은 `(empty(등록일) or 등록일 <= 수업일시) and (empty(종료일) or 수업일시 < dateAdd(종료일, 1, "days"))`를 `not(...)`으로 감쌌다. Notion은 `or` 앞쪽이 참이어도 뒤쪽을 계산하므로 날짜가 빈 학생에서 결과가 거짓·빈 값이 될 수 있다(v2.6.11 수식 주의). 바깥 `not`과 맞물려 우연히 맞게 보일 수 있지만 믿을 수 없다.
  - `if(empty(...), true, ...)`로 바꿔 등록일·종료일이 빈 쪽은 계산하지 않는다. 수업 자기 속성(`보강`·`출석`)은 맨 위 `lets`에서 변수로 받는다(안쪽에서 `prop("보강")`을 부르면 "유효한 속성이 아닙니다"가 난다).
- **방법**: 수업(학원) DB → `생성 오류` 속성 → 수식 편집 → 기존 수식을 복사해 두고, 내용을 모두 지운 뒤 아래 수식을 그대로 붙여 넣는다. 운영 수식이 원본과 다르게 고쳐져 있으면 붙여 넣기 전에 차이를 운영 AI에게 알리고, 운영 고유 부분을 살린 수식을 따로 만든다.

```
lets(
  sessionDateTime, prop("수업일시"),
  isMakeup, prop("보강"),
  attendances, prop("출석"),
  registeredRegistrations, prop("등록"),

  registeredOutOfRangeNow,
    registeredRegistrations.filter(
      lets(
        reg, current,
        not (
          if(empty(reg.prop("등록일")), true, reg.prop("등록일") <= sessionDateTime) and
          if(empty(reg.prop("종료일")), true, sessionDateTime < dateAdd(reg.prop("종료일"), 1, "days"))
        )
      )
    ),

  attendanceRegistrations, attendances.map(current.prop("등록")).flat(),

  missingRegistrations,
    registeredRegistrations.filter(lets(reg, current, not attendanceRegistrations.includes(reg))),

  duplicateRegistrations,
    registeredRegistrations.filter(
      lets(reg, current, attendances.filter(current.prop("등록").includes(reg)).length() > 1)
    ),

  extraRegistrations,
    attendanceRegistrations.filter(not registeredRegistrations.includes(current)).unique(),

  missingNames, missingRegistrations.map(current.prop("학생정보").first().format()).join(", "),
  duplicateNames, duplicateRegistrations.map(current.prop("학생정보").first().format()).join(", "),
  extraNames, extraRegistrations.map(current.prop("학생정보").first().format()).join(", "),
  outOfRangeNames, registeredOutOfRangeNow.map(current.prop("학생정보").first().format()).join(", "),

  duplicateNote,
    if(duplicateRegistrations.empty(), "",
      "\n🔁 중복(" + duplicateRegistrations.length() + "): " + duplicateNames),

  baseResult,
    ifs(
      missingRegistrations.empty() and extraRegistrations.empty(),
        "✅ 정상(" + attendances.length() + ")",
      not missingRegistrations.empty() and extraRegistrations.empty(),
        "⚠️ 누락(" + missingRegistrations.length() + "): " + missingNames,
      missingRegistrations.empty() and not extraRegistrations.empty(),
        "⚠️ 초과(" + extraRegistrations.length() + "): " + extraNames,
      "⚠️ 누락(" + missingRegistrations.length() + "): " + missingNames +
      "\n⚠️ 초과(" + extraRegistrations.length() + "): " + extraNames
    ),

  regularResult,
    if(registeredOutOfRangeNow.empty(), baseResult + duplicateNote,
      baseResult + duplicateNote + "\n📅 날짜범위 밖(" + registeredOutOfRangeNow.length() + "): " + outOfRangeNames),

  if(isMakeup,
    "🔵 보강 수업(" + attendances.length() + ")" + duplicateNote,
    regularResult)
)
```

- **확인**: 일반 수업이 전과 같이 `✅ 정상(n)`으로 나오고, 종료일이 빈 학생은 `📅 날짜범위 밖`에 나오지 않는다. 종료일이 지난 학생이 명단에 남은 수업은 `📅 날짜범위 밖(1): 이름`으로 나온다(그 수업의 [출석 조정]이 명단·출석을 정리한다).
- **확인(원본, 2026-10-16)**: 미리보기 고2 B 11.21 `✅ 정상(6)`, 다른 수업 `✅ 정상(n)` 유지, 종료일 10/20인 테스트 학생이 명단에 남은 고1 A 11.20 수업이 `✅ 정상(7)` + `📅 날짜범위 밖(1)`로 표시(같은 수업의 `출석 조정 정보`도 그 학생 출석을 del, 명단에서 제외).
- **되돌리기**: 복사해 둔 이전 수식을 다시 붙여 넣는다.
