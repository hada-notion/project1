# v2.5.71 — 함수 배포 CLI 버전 고정

- 날짜: 2026-10-14
- 이전 버전: v2.5.70
- 요약: `.github/workflows/deploy-supabase-functions.yml`의 Supabase CLI 설치를 `version: latest`에서 `version: 2.120.0`으로 고정했다. `latest`는 설치 때마다 최신 버전을 GitHub에 묻는데, 그 조회가 사용 한도(rate limit)에 걸리면 배포 전체가 CLI 설치 단계에서 멈춘다. v2.5.70 병합 때 실제로 발생했고, 실패한 작업을 다시 실행해 배포를 끝냈다.
- 매뉴얼 영향: 없음
- 변경 유형: 배포 워크플로만. 함수·화면·Notion 변경 없음.

---

## 항목 1. 배포 워크플로

- **유형**: AI 자동
- **대상 파일**: `.github/workflows/deploy-supabase-functions.yml`
- **확인 방법**: 다음 함수 배포 실행에서 "Install Supabase CLI" 단계가 `version: 2.120.0`으로 성공하는지 본다. 이 패치는 함수 파일을 바꾸지 않아 병합만으로는 배포가 돌지 않는다.
- **CLI를 올릴 때**: 이 값만 바꾸고, 바꾼 뒤 첫 배포 결과를 확인한다.
- **실패 시 대처**: `version: latest`로 되돌린다.
