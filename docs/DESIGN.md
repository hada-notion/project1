# 하다 학원관리 웹 화면 디자인 규칙

모든 웹 화면(관리자 설정, 출결 키오스크, 학교 찾기, 법정 서류, 학부모 리포트)이 같은 색·글자·간격·부품을 쓰도록 하는 기준이다. 화면을 고치거나 새로 만들 때 이 문서와 `assets/hada-ui.css`를 따른다.

- 색 값은 Notion "콘텐츠 디자인 기준"(카드뉴스·영상과 같은 팔레트, 출처는 `student_report.html`)과 같다. 웹에만 필요한 값은 아래 "웹 추가 토큰"에 따로 적는다.
- 규칙은 말이 아니라 검사로 지킨다. `node tests/design-lint.cjs`가 토큰 밖의 값을 막고, 화면 검사가 세 가지 폭에서 깨짐을 찾는다.

## 1. 적용 현황

| 화면 | 공용 스타일 | 비고 |
| --- | --- | --- |
| `admin_settings.html` | 적용 | 기준 화면 |
| `attendance_kiosk.html` | 적용 | 기기 화면 모드(`html.device`). 어두운 모드 제거(브랜드 단일 밝은 테마) |
| `school_search.html` | 적용 | 상단 바·바로가기 포함 |
| `legal_documents.html` | 미적용 | 인쇄 레이아웃 포함, 인쇄 규칙은 따로 정한다 |
| `student_report.html` | 미적용 | 팔레트는 같음, 글자·간격 체계가 다름 |

화면을 공용 스타일로 옮기면 `tests/design-lint.cjs`의 `PAGES`에 추가하고 이 표를 고친다. 옮기기 전에는 그 화면의 기능을 바꾸지 않는 것을 원칙으로 하고, 옮기는 작업은 화면 하나씩 따로 한다.

## 2. 토큰

값은 `assets/hada-ui.css`의 `:root`에만 있다. 화면 CSS는 `var(--이름)`만 쓴다. 화면이 자기 레이아웃용 변수를 만들 수는 있지만 색 변수는 만들지 않는다.

글자·간격·모서리·높이 토큰은 `rem`이다(기본 16px = 1rem이라 보이는 크기는 아래 px와 같다). 그래서 기기 화면 모드에서 기준 글자 크기만 바꾸면 화면 전체가 같은 비율로 커진다.

### 색

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `--brand-deep` | #6B5D4D | 유일한 포인트 색. 주 버튼, 로고, 링크, 강조 글자 |
| `--brand-primary` | #E6D8C4 | 배지·버튼 바탕 |
| `--brand-mid` | #D1BEA5 | 보조 바탕 |
| `--brand-light` | #F1E8DC | 하이라이트 바탕 |
| `--brand-soft` | #F5EFE7 | 상태 상자, 진행 막대 바탕 |
| `--brand-tint` | #FBF8F3 | 페이지 바탕 |
| `--brand-border` | #DED1C0 | 선, 카드 테두리 |
| `--text-ink` / `--text-muted` / `--text-subtle` | #191F28 / #4E5968 / #8B95A1 | 본문 / 보조 설명 / 가장 약한 안내 |
| `--success` `--danger` `--warning` `--info` (+`-soft`) | | 상태 표시 전용. 장식으로 쓰지 않는다 |

**웹 추가 토큰** (Notion 기준에 없음, 웹 화면에만 사용)

| 토큰 | 이유 |
| --- | --- |
| `--success-ink` `--danger-ink` `--warning-ink` `--info-ink` | 작은 글자용 상태색. 기본 상태색은 흰 바탕에서 글자 대비(4.5:1)가 부족하다 |
| `--surface` (#FFFFFF) | 카드·입력칸·대화상자 바탕. **페이지 바탕에는 쓰지 않는다**(페이지는 `--brand-tint`) |
| `--control-border` | 입력칸 테두리(선보다 진해야 입력칸으로 보인다) |
| `--warning-border` `--divider` | 알림 줄 테두리, 카드 안 얇은 구분선 |
| `--overlay` `--shadow-sm` `--shadow-md` | 대화상자 뒤 배경, 그림자 |

### 글자

- 글꼴: `--font-sans`(Pretendard 우선), 코드·키 값은 `--font-mono`. `word-break: keep-all` 필수.
- 크기는 7단계만 쓴다.

| 토큰 | 크기 | 쓰임 |
| --- | --- | --- |
| `--text-display` | 32px (모바일 28px) | 페이지 제목(h1) 하나 |
| `--text-title` | 22px | 카드 제목(h2), 로고 |
| `--text-lead` | 18px | 소제목, DB 카드 이름 |
| `--text-body` | 16px | 본문, 입력칸, 버튼 |
| `--text-small` | 14px | 도움말, 상태 상자, 표 |
| `--text-label` | 13px | 배지, 보조 정보 |
| `--text-caption` | 12px | 가장 작은 메타 정보 |

- 굵기: 400 본문, 600 강조·버튼·라벨, 700 배지·작은 제목, 800 로고.

### 간격

`--space-1` 4 · `--space-2` 8 · `--space-3` 12 · `--space-4` 16 · `--space-5` 20 · `--space-6` 24 · `--space-8` 32 · `--space-12` 48 (px)

- 같은 성격의 간격은 같은 단계를 쓴다: 카드 안쪽 32(모바일 24), 카드 사이 16~24, 폼 항목 사이 24, 제목과 설명 사이 12.
- 0~3px는 선·미세 정렬용으로만 직접 쓸 수 있다.

### 모서리·크기

- 모서리: `--radius-sm` 4(배지·코드) · `--radius-md` 8(버튼·입력칸·상태 상자) · `--radius-lg` 12(카드·대화상자) · `--radius-pill`(원형·숫자 배지)
- 폭: `--page-max` 1180(모든 화면의 바깥 폭 동일) · `--form-max` 560(입력 폼은 이 폭으로 가운데) · `--dialog-sm` 440 · `--dialog-md` 600
- 높이: `--control-h` 48(버튼·입력칸), `--control-lg` 56(키오스크 숫자판·등하원 버튼). 누르는 요소는 최소 44px.
- 아이콘: `--icon-sm` 14 · `--icon-md` 20 · `--icon-lg` 28. 선 아이콘은 `svg.line`(stroke 2, currentColor).

### 로고

- 파일: `assets/brand/hada-wordmark.png`. Notion 에셋 "하다 워드마크"의 brand-deep 버전(투명 배경)이다. 밝은 바탕에만 쓰고, 어두운 바탕이 생기면 같은 에셋의 화이트 버전을 추가한다. 블랙·라이트 원본은 쓰지 않는다.
- 위치: 상단 바 왼쪽, "하다 학원관리" 글자 앞(`.brand` → `.logo` + `.wordmark`), 간격 `--space-3`. **기기 화면 모드(키오스크)에는 로고를 넣지 않는다**(학원생과 보호자가 보는 화면이라 과하다). 대신 카드 아래에 학원 이름을 작게 표시한다.
- 높이: `--logo-h` 36px(모바일 28px), 가로는 비율대로. 늘리거나 색을 바꾸지 않는다.

## 3. 레이아웃

- 모든 화면은 `.shell`(바깥 폭 `--page-max`) → `.top`(로고·상단 버튼) → `header`(h1·설명) → `.notice`(연결 상태 한 줄) → `.card`(본문) → `.foot` 순서다.
- 화면을 바꿔도 바깥 폭은 그대로 둔다. 입력이 하나뿐인 폼처럼 좁아야 하는 내용은 카드 안에서 `--form-max`로 **가운데** 놓고, 제목도 같이 가운데로 맞춘다.
- 나란히 놓는 구성(대시보드 두 칸, 안내+예시)은 860px 아래에서 위아래로 쌓는다. 카드 목록은 `repeat(auto-fill,minmax(320px,1fr))`, 700px 아래에서 한 줄.
- 화면 폭 기준은 1280(데스크톱) · 768(태블릿) · 390(휴대폰). 세 폭 모두 가로 스크롤이 생기면 안 된다.
- 부가 정보(보안 설정 현황 등)는 본문을 좁히는 옆 칸 대신 상단 버튼으로 여는 대화상자에 둔다.

### 기기 화면 모드 (출결 키오스크)

- 학원 입구 태블릿처럼 한 화면을 꽉 채워 쓰는 화면은 `<html class="device">`로 둔다. 세로 카드(`--device-w`, 화면에 맞춰 최대 640px, 가로세로 0.6 비율)를 가운데 놓고, 기준 글자 크기를 카드 폭에 비례(360px 폭일 때 16px)시켜 모든 rem 토큰이 함께 커진다.
- 상단 바·제목 줄(`.shell`/`.top`) 대신 카드 안에 제목·설명을 가운데 정렬한다. 로고는 넣지 않는다.
- 카드 맨 아래에 학원 이름(`.academy-name`, `--text-caption`, `--text-subtle`)을 한 줄로 작게 둔다. 이름은 서버가 그 학원 Notion 최상위 페이지 제목에서 가져오므로 화면에 적어 두지 않는다.
- 확인 기준 폭은 1280×800(가로 태블릿·노트북), 768×1024(세로 태블릿), 390×844(휴대폰). 세 경우 모두 카드가 화면 안에 들어와야 한다.

## 4. 부품

`assets/hada-ui.css`에 있는 공용 부품만 쓰고, 같은 역할에 다른 모양을 만들지 않는다.

| 부품 | 클래스 | 규칙 |
| --- | --- | --- |
| 주 버튼 | `.primary` | 한 화면(한 카드)에 하나. 가장 중요한 다음 행동(키오스크는 등원) |
| 보조 버튼 | `.secondary` (`.wide`=가득 채움) | 돌아가기, 새로고침, 로그아웃 등 |
| 작은 버튼 | `.ghost` | 상단 바, 대화상자 닫기, 다시 찾기 같은 부가 동작. 글자는 항상 한 줄(공간이 모자라면 버튼 줄이 아래로 내려간다) |
| 바로가기 | 상단 바 `바로가기` + `dialog.links-dialog` + 빈 `.link-list` + `assets/hada-shortcuts.js` | 다른 웹 화면으로 가는 목록(아이콘·이름·한 줄 설명, 새 탭). 목록은 `hada-shortcuts.js` 한 곳에만 있고 지금 화면은 자동으로 빠진다. 화면이 추가되면 그 파일만 고친다. 학생별 주소가 필요한 학부모 리포트는 넣지 않는다 |
| 도움말 버튼 | `.help-btn` | `?` 한 글자. 누르면 대화상자로 설명·이미지 |
| 처리 중 | `.loading` | 서버 요청 중 누른 버튼에 회전 표시 + "불러오는 중…" 문구(오래 걸리면 예상 시간) |
| 알림 줄 | `.notice` | 화면 위 연결 상태·결과 한 줄 |
| 상태 상자 | `.status`, `.status.warn` | 안내·주의 문단 |
| 카드 | `.card` | 본문 덩어리, 대화상자 |
| 종류 배지 | `.kind.button`, `.kind.auto` | Notion 버튼(파랑, 버튼 아이콘) / 자동화(노랑, 번개 아이콘) |
| 대화상자 | `dialog.card` + `.dialog-head` | 제목 + 닫기 버튼 |
| 입력 | `label` + `input` + `.help` + `.error` | 라벨은 위, 도움말은 아래, 오류는 빨간 글자 |

- 아이콘은 단색 SVG(`currentColor`)로 그리고 크기는 글자 높이에 맞춘다. 외부 서비스의 아이콘 파일은 가져와 쓰지 않는다.
- 이미지 안내는 카드 안에 바로 넣지 않고 `?` 도움말 대화상자로 연다(카드 높이가 흔들리지 않게).

## 5. 금지

- 토큰 밖의 색(16진수, rgb, white/black)을 화면 CSS에 직접 쓰기
- 간격·글자 크기·모서리·레이아웃 폭에 임의 px 쓰기
- HTML의 `style="..."` 속성
- 페이지 바탕을 흰색으로 하기, 그라데이션 배경
- 화면별 어두운 모드(브랜드는 밝은 테마 하나만 쓴다)
- `--brand-deep` 외의 포인트 색 추가

## 6. 작업 절차

1. 고치기 전 화면을 캡처한다(1280·390).
2. 토큰과 공용 부품으로 고친다. 새 값이 꼭 필요하면 먼저 `assets/hada-ui.css` 토큰과 이 문서에 추가하고 이유를 적는다.
3. `node tests/design-lint.cjs`를 실행한다.
4. 화면 검사(세 폭 가로 넘침, 버튼 높이 44px 이상, 글자 잘림)를 실행하고 전후 캡처를 비교해 보고한다.

## 7. 남은 결정

- **Pretendard 글꼴 불러오기:** 지금 어느 화면도 Pretendard를 실제로 불러오지 않아 기기 기본 글꼴로 보인다. 글꼴 파일을 저장소에 함께 두는 방법(외부 연결 없음)과 CDN 방법 중 UI 통일 작업 때 정한다.
- **인쇄 화면(법정 서류):** 인쇄용 크기·여백은 화면 토큰과 따로 정한다.
