# Notion 페이지 레이아웃 (DB별)

> `scripts/notion-spec.py`가 원본 스캔으로 만든다. 손으로 고치지 않는다. 원본 레이아웃을 바꾸면 다시 스캔해 생성하고 지문과 함께 커밋한다. 레이아웃 원칙은 [이름 규칙](../이름-규칙.md) 7장, 적용 순서는 [적용 절차](적용-절차.md).

- 원본 스캔: 2026-10-27T09:22:09.842Z
- 각 DB는 세 부분으로 적는다. **1. 상단**(제목 아래 고정 속성), **2. 콘텐츠 탭**(첫 탭에 놓는 속성·블록과 나머지 탭), **3. 세부 정보 보기**(오른쪽 패널, 섹션별).
- 표시 방식: 보임 = 항상 표시, 빈 값 숨김 = 비어 있으면 숨김, 숨김 = 항상 숨김(패널 맨 아래 '숨김'에 모임).
- 상단·콘텐츠 탭·패널 위에 고정한 속성은 패널 섹션에 다시 나오지 않는다.
- 바꾸는 곳: 상단·패널·첫 탭 내용은 커넥터(`page_layout`)로, 탭(연결 보기)과 탭 필터는 화면 "레이아웃 사용자 지정"에서 바꾼다.
