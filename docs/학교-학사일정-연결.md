# 학교 검색·학사일정 수동 동기화

## 운영 방식
정기 자동 수집은 사용하지 않습니다. 기존 `sync-school-schedules` 엔드포인트는 인증 후 HTTP 410으로 차단됩니다. 마이그레이션은 NEIS 전용 예약 이름 두 개만 해제하며, 출석/보고서 등 다른 예약은 변경하지 않습니다.

학교 DB의 **학교 검색** 링크로 정확한 학교를 연결한 뒤 **학사일정 가져오기** 버튼을 누릅니다. `학사일정 동기화` 체크박스는 v2.5.1에서 삭제되었습니다. 체크 없이 버튼으로 실행합니다.

버튼은 클릭한 학교의 **현재 학년도 전체(3월 1일~다음 해 2월 말)** 중 나이스에 등록된 모든 일정을 수집합니다. 한국시간 1~2월에는 전년도 학년도를 사용합니다. 예: 2026년 10월 클릭 → 2026-03-01~2027-02-28. 아직 학교가 올리지 않은 일정은 다음 클릭 때 반영됩니다.

## 마지막 1회 설정: Notion 버튼 액션
현재 Notion MCP는 버튼 속성을 만들 수 있지만 버튼 안의 액션은 설정할 수 없습니다. **버튼 속성은 생성했으며, 아래 액션 연결 전에는 버튼이 실행되지 않습니다.**

1. 학교 DB의 `학사일정 가져오기` 속성 편집을 엽니다.
2. `액션 추가` → `웹훅 보내기`를 선택합니다.
3. URL:
   `https://twczhsxybkcvjkdfdxvs.supabase.co/functions/v1/sync-school-calendar`
4. 기존 관리자 인증 방식을 사용합니다. `사용자 지정 헤더 추가`에서 Key는 `x-admin-key`, Value는 기존 관리자 키입니다. 키 값은 채팅/본문/DB 일반 속성/HTML/저장소에 복사하지 말고 웹훅 인증 설정에서만 입력합니다.
5. 저장합니다. Notion 버튼의 POST 본문에 포함되는 `data.id`(누른 학교 페이지 ID)를 서버가 읽습니다. 별도의 JSON 본문이나 학교 코드 입력은 필요 없습니다.

공식 안내: https://www.notion.so/help/webhook-actions
유료 플랜의 웹훅 액션과 사용자 지정 헤더를 지원합니다. 데이터베이스 버튼은 보낼 속성을 별도로 선택하지 않습니다.

## 실행 확인
학교 페이지에서 확인합니다.
- `학사일정 처리 상태`: 🔄 작업중 / ✅ 완료 / ⚠️ 오류
- `학사일정 처리 현황`: 학년도와 처리 건수
- `학사일정 마지막 동기화`: 전체 처리가 실제 완료된 시각
- `학사일정 오류`: 실패 원인

HTTP 202는 접수이며 완료가 아닙니다. 서버는 4건씩 처리한 후 해당 작업만 다음 함수 호출로 이어갑니다. 이 이어달리기는 버튼에서 시작한 작업에 한정되며, 정기 Cron이나 다른 학교 스캔은 하지 않습니다.

반복 클릭은 학교별 DB 잠금으로 진행 중인 작업을 재사용합니다. 일시적 실패는 최대 3회 재시도하며, 플랫폼이 강제 종료한 경우 3분 임대 만료 뒤 버튼을 다시 누르면 저장된 커서부터 재개합니다. 마지막 실패를 복구한 뒤 한 번 더 누르면 최신 원본을 새로 조회합니다.

## 데이터 보존
- 모든 행사 종류를 가져옵니다. 표시 여부는 Notion의 전체/운영 학사일정 뷰와 `숨김`으로 조절합니다.
- 자동 수정: 이름/날짜/학교/학년/대상 학년/수업공제일명/원본 행사내용/NEIS 동기화키.
- 보존: 수동 숨김/메모/본문/태그/진행상태/담당자/직접 만든 일정.
- 원본에 행사 고유 ID가 없으므로 행사명·날짜·대상 학년 변경은 새 일정으로 처리합니다. 기존 일정이나 사라진 원본은 자동 삭제하지 않습니다.
- Notion 생성 POST는 응답 유실 시 blind retry하지 않으며 다음 실행에서 키를 조회해 복구합니다.

## 서버 설정
기존 `SB_URL`, `SB_SERVICE_ROLE_KEY`, `NOTION_TOKEN`, `ADMIN_SECRET`, `DATA_SOURCE_SCHEDULE_EVENT_ID`, `NEIS_API_KEY`를 재사용합니다. 학교/학년 데이터소스는 일정 DB 관계에서 조회합니다. 키를 추가 발급할 필요는 없습니다.

## 관리자 API 테스트 (인증 필요)
- 시작: POST `sync-school-calendar`, `{ "action":"start", "pageId":"학교 페이지 ID" }`
- 상태: POST 같은 함수, `{ "action":"status", "pageId":"학교 페이지 ID" }`
- `academicYear`는 선택 사항이며, 일반 Notion 버튼은 생략합니다.
- 조회/시작/내부 후속 처리 모두 `x-admin-key`를 검증합니다.
