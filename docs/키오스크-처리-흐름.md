# 키오스크 출결 처리 흐름

출결 키오스크(`attendance_kiosk.html`)가 등원·하원을 기록하는 현재 흐름입니다. 사용법은 Notion 메뉴얼 "수업·출석" 6-4, 바뀐 이력은 `CHANGELOG.md`를 봅니다. 등원·하원 기록은 수업 관리 복사본에도 함께 쓴다([수업 관리 Supabase 복사본](설계-수업관리-복사본.md)).

## 1. 로그인과 학생 목록

- 키오스크는 관리자 비밀번호로 로그인합니다. 보안 모드에서는 키오스크 전용 로그인을 받으며(관리자 비밀번호를 바꿀 때까지 유지, v2.5.82) `kiosk-checkin`과 `list-students?kiosk=1`만 부를 수 있습니다(localStorage `admin_key`). 비밀번호를 바꾸면 다시 로그인합니다. 관리 화면 3개의 로그인과는 따로입니다.
- 로그인 뒤 `GET list-students?kiosk=1`로 학생 이름·클래스 표시명·수강 중 등록 ID·정규화한 학생/보호자 연락처의 최소 목록을 받습니다. 목록은 화면 메모리에만 두고 새로고침·로그아웃 때 지웁니다. 보고서 토큰·출석 이력은 받지 않습니다.
- 목록은 출결 요청 때 5분 이상 지났으면 다시 받습니다. 번호가 목록에 없으면 한 번 더 받고, 그래도 없으면 전화번호만 보내는 전체 조회 경로로 보완합니다.

## 2. 오늘 출석 준비(출석 동기화, v2.5.37~)

- 매일 04:00 KST pg_cron `kiosk-prepare-daily`가 `kiosk-prepare`를 불러, 오늘 수강 중인 등록과 오늘 출석 페이지를 서버 표 `kiosk_today`(전화번호는 해시)에 준비하고 `kiosk_prepared`에 준비 시각을 남깁니다. 마이그레이션 `20261013030000_kiosk_today.sql`, Vault `sync_queue_admin_key` 인증.
- 오늘 준비가 없으면 키오스크 화면을 열 때(`list-students?kiosk=1`) 백그라운드로 준비합니다.
- 키오스크 설정(톱니)의 **지금 동기화**는 `list-students?kiosk=1&sync=1`로 즉시 다시 준비합니다(1분 안에 이미 했으면 생략). 설정 창에 "마지막 동기화 HH:mm"이 보입니다.

## 3. 등원·하원 처리 (`POST kiosk-checkin`)

요청: `{ phone, type: "checkin"|"checkout", registrationId?, mode?: "once"|"every" }`

1. **빠른 경로:** 오늘 준비가 있고, 그 등록의 오늘 출석 페이지가 준비 표에 있고, 전화번호 해시가 맞으면 Notion 조회 없이 그 출석 페이지에 시각을 기록합니다.
2. **일반 경로:** 준비가 없거나 맞지 않으면 등록 ID 힌트를 서버에서 다시 검증(등록 DB 소속, 수강 중, 학생 연락처 일치)하고 오늘 출석을 찾아 기록합니다. 오늘 출석이 없으면 `🔵 보강` 출석을 새로 만듭니다. 힌트가 맞지 않으면 출결을 바꾸지 않고 409(`refresh`)를 돌려주고, 화면은 목록을 갱신해 다시 고르게 합니다.
3. **체크 방식(`kioskPolicy.ts`):**
   - `once`(1일 1회, 기본): 이미 시각이 있으면 덮어쓰지 않고 "이미 처리"로 안내합니다. 준비 표가 "이미 처리"라고 하면 Notion 출석을 한 번 더 읽어 확인합니다(Notion에서 지웠으면 다시 기록).
   - `every`(매번 기록): 누를 때마다 새 시각으로 기록하고 알림톡을 보냅니다.
   - 두 방식 모두 같은 버튼을 2분 안에 다시 누르면 무시합니다(`recent`, 알림톡 없음).
4. 기록하면 `🟢 출석`으로 바꾸되 `🔵 보강`은 유지합니다. 어느 경로로 기록하든 준비 표의 시각·출석 페이지를 함께 맞춥니다.
5. **알림톡은 응답 뒤에 보냅니다**(v2.5.36, `EdgeRuntime.waitUntil`). 학생 화면은 기록이 끝나면 바로 결과를 보여 줍니다. 알림톡 결과는 자동화 로그 DB에 `출결 구분`(등원/하원)과 함께 남습니다(v2.5.3).
6. 단계별 시간은 함수 로그 `[kiosk-checkin timing]`과 응답 헤더 `Server-Timing`에 남습니다(v2.5.35).

## 4. 화면 동작

- 숫자판과 키보드 모두 입력할 수 있습니다. 11자리가 되면 등원이 골라지고 ←/→로 바꾸며 Enter로 처리합니다. 같은 번호에 학생이 여럿이면 선택 화면에서 ↑/↓/Enter/Esc를 씁니다. 처리 중이거나 설정 창이 열려 있으면 키 입력을 받지 않습니다.
- 설정(톱니): 체크 방식(기기별 저장, localStorage `kiosk_check_mode`), 지금 동기화, 로그아웃. 체크 방식 변경과 지금 동기화는 관리자 비밀번호를 한 번 더 확인합니다.

## 5. 관리자 참고

- `list-students`의 일반 응답(키오스크가 아닌 경우)은 그대로입니다. 키오스크 로그인으로는 부를 수 없습니다.
- Notion 자동화·버튼 연결은 필요 없습니다. DB 스키마 변경도 없습니다(서버 표만 사용).
- 문제가 생기면: 키오스크 로그인 상태 → 설정 창의 마지막 동기화 시각(오늘 날짜인지) → 연락처 일치 → 수강 중 등록 → 오늘 출석 → 자동화 로그 순으로 봅니다.
