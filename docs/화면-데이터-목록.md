# 화면 → 데이터 목록 (수업 관리)

수업 관리(`class_room.html`) 화면마다 서버 함수 `class-room`의 어떤 동작을 부르고, 그 동작이 Notion에서 무엇을 읽는지 정리한다. "화면에 보이지 않는 정보는 서버도 읽지 않는다"는 원칙으로 읽기를 점검할 때 쓴다.

- 기준 코드: `class_room.js`(화면), `supabase/functions/_shared/classRoom.ts`(서버)
- 읽기 방식 표기: **질의** = Notion DB 검색(`queryAllPages`, 100개씩 여러 번일 수 있음) / **낱장** = 페이지 하나씩 읽기(`getPages`, 동시 6개, 페이지 수만큼 호출) / **본문** = 페이지 본문 블록 읽기(`readPageBodyBlocks`, 페이지마다 1회 이상)
- 실제 호출 시간은 `class_room.html?timing=1`로 잰다.

## 1. 화면 → 동작

| 화면 | 열 때 부르는 동작 | 다시 부르는 때 |
| --- | --- | --- |
| 첫 화면(강사·클래스·통합 시간표) | `teachers`, `classes`, `day` | 강사 바꾸기, 새로고침 |
| 반 상세 열기(모든 탭 공통) | `session` + `class-sessions`(동시), 날짜가 바뀌면 `day` | 같은 반 다른 수업으로 이동할 때마다 |
| 홈 탭 | (`session` 결과) + `books`(교재 진도) | |
| 교재 탭·교재 상세 | `books`, 교재 상세는 `class-records` | |
| 캘린더 탭 | (`class-sessions` 결과), 다른 달로 가면 `class-sessions(around)` | 날짜를 누르면 `session` |
| 캘린더 날짜 [학습 기록] | `class-records`(마감 과제 카드 보강) | |
| 학습기록 탭 | `class-records` | 기록을 만들거나 고치면 다시 |
| 학생 탭 | `roster`, `class-stats` | |
| 기록 화면 | `activities`, `books` | 저장 후 `activities`, `session` |
| 저장·만들기 | `save-attendance`, `save-activities`, `create-records`, `update-record`, `create-activities`, `create-makeup-session`, `delete-makeup-session` | 저장 뒤 보통 `session`을 다시 읽음 |

화면이 부르지 않는 서버 동작: `days`, `student`, `unlink-makeup` — 지금 화면에서 쓰지 않는다(정리 후보).

## 2. 동작 → 읽는 곳

| 동작 | `CLASS_ROOM_SOURCE=copy`일 때 | 그 밖 |
| --- | --- | --- |
| `day`, `days`, `classes`, `session`, `class-sessions`, `class-records`, `class-stats` | Supabase 복사본(`cr_*`). 복사본에 없거나 읽기에 실패하면 그 요청만 Notion | Notion |
| `teachers`, `roster`, `books`, `activities`, `record-body`, `student`, 모든 저장 | Notion | Notion |

복사본 구조·맞추는 방법·비상 실행은 [수업 관리 Supabase 복사본](설계-수업관리-복사본.md).
